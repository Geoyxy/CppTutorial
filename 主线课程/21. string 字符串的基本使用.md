# std::string 字符串的基本使用

`std::string` 是 C++ 标准库中表示**可变字符序列**的类，定义在 `<string>` 头文件中。它不是基本类型，而是 `std::basic_string<char>` 的模板特化，支持动态内存管理。

---

## 1. 可变性

`std::string` 的最大特点：**内容可原地修改**。修改操作不会重新分配整个对象，而是直接在已有内存空间上操作。

```cpp
#include <string>
#include <iostream>

std::string s = "Hello";
std::cout << &s[0] << std::endl;  // 输出地址（示例）

s += " World";       // 原地修改，不产生新对象
std::cout << s << std::endl;      // "Hello World"
std::cout << &s[0] << std::endl;  // 可能相同地址（容量足够时）

s[0] = 'h';          // 直接修改字符
std::cout << s << std::endl;      // "hello World"
```

> [!WARNING] **注意**：
> `std::string` 的可变性意味着**传递值时会深拷贝**。需要避免拷贝开销时，应传入 `const std::string&`。

---

## 2. 创建方式

```cpp
#include <string>

// 默认构造 - 空字符串
std::string s1;

// 从 C 字符串构造
std::string s2 = "hello";
std::string s3("world");

// 拷贝构造
std::string s4(s2);

// 重复字符
std::string s5(5, 'A');         // "AAAAA"

// 从子串构造（C字符串的前 n 个字符）
std::string s6("abcdef", 3);    // "abc"

// 从迭代器范围构造
std::string s7(s2.begin(), s2.end());

// 移动构造（C++11）
std::string s8(std::move(s2));  // s2 变为未指定状态

// 初始化列表（C++11）
std::string s9 = {'a', 'b', 'c'};  // "abc"
```

| 方式  | 示例                             | 适用场景               |
| --- | ------------------------------ | ------------------ |
| 默认  | `std::string s;`               | 空字符串，后续赋值          |
| 字面量 | `std::string s = "text";`      | 日常使用，最常用           |
| 重复  | `std::string s(10, 'x');`      | 预分配已知大小的字符串        |
| 拷贝  | `std::string t(s);`            | 需要独立副本             |
| 移动  | `std::string t(std::move(s));` | 转移所有权，避免拷贝（将在以后学习） |

## 3. 内存管理

### 3.1 容量与大小

`std::string` 类似我们之前学的动态数组，维护三个内部值：大小（size）、容量（capacity）、数据指针。

```cpp
std::string s = "Hello";
std::cout << s.size() << std::endl;       // 5（字符数）
std::cout << s.length() << std::endl;     // 5（同 size()）
std::cout << s.capacity() << std::endl;   // 至少 15（实现相关）
std::cout << s.empty() << std::endl;      // false（是否为空）

// 预分配空间
s.reserve(100);           // 确保 capacity >= 100
std::cout << s.capacity() << std::endl;   // >= 100
```

### 3.2扩容策略

当通过 `+=`、`append()`、`push_back()` 等操作导致 `size > capacity` 时，`std::string` 自动扩容：

- 通常采用**指数增长策略**（如每次翻倍，具体实现相关）
- 减少频繁分配的次数
- 可使用 `reserve()` 预分配，避免多次扩容

```cpp
std::string s;
std::cout << s.capacity() << std::endl;   // 0（可能）

s = "Hello";
std::cout << s.capacity() << std::endl;   // 至少 5

for (int i = 0; i < 100; ++i) {
    s += "x";
    // capacity 会跳跃性增长，不是每次循环都变
}
```

> [!TIP]
> 如果预先知道最终长度（如拼接多个字符串、读取文件），使用 `reserve()` 预分配可提升性能，避免多次重分配。

## 4. 常用方法

### 4.1 查询与判断

| 方法                    | 说明         | 示例                        |
| --------------------- | ---------- | ------------------------- |
| `size()` / `length()` | 返回字符数      | `s.size()`                |
| `empty()`             | 是否为空       | `if (s.empty())`          |
| `capacity()`          | 当前已分配的存储容量 | `s.capacity()`            |
| `max_size()`          | 理论最大长度     | `s.max_size()`            |
| `at(size_t pos)`      | 带边界检查的访问   | `s.at(3)`（抛异常）            |
| `operator[]`          | 无边界检查访问    | `s[3]`（更快）                |
| `front()`             | 第一个字符      | `s.front()`               |
| `back()`              | 最后一个字符     | `s.back()`                |
| `data()` / `c_str()`  | C 风格字符串指针  | `printf("%s", s.c_str())` |

```cpp
std::string s = "Hello";

// 边界安全访问
try {
    char ch = s.at(10);   // 抛出 std::out_of_range
} catch (const std::out_of_range& e) {
    std::cout << "Out of range!" << std::endl;
}

// 无边界检查访问（更快，但危险）
char ch = s[10];          // 未定义行为
```

### 4.2 查找与搜索

所有查找函数返回 `size_t`，未找到返回 `std::string::npos`。

| 方法                            | 说明              | 示例                           |
| ----------------------------- | --------------- | ---------------------------- |
| `find(str, pos)`              | 从左向右查找          | `s.find("abc")`              |
| `rfind(str, pos)`             | 从右向左查找          | `s.rfind('c')`               |
| `find_first_of(str, pos)`     | 查找第一个匹配字符集中的字符  | `s.find_first_of("aeiou")`   |
| `find_last_of(str, pos)`      | 查找最后一个匹配字符集中的字符 | `s.find_last_of("aeiou")`    |
| `find_first_not_of(str, pos)` | 查找第一个不在字符集中的字符  | `s.find_first_not_of(" \t")` |
| `find_last_not_of(str, pos)`  | 查找最后一个不在字符集中的字符 | `s.find_last_not_of(" \t")`  |

```cpp
std::string s = "Hello World, Hello C++";

size_t pos = s.find("Hello");           // 0
pos = s.find("Hello", 1);               // 13（从索引1开始找）
pos = s.find("XYZ");                    // std::string::npos

// 检查是否包含
if (s.find("World") != std::string::npos) {
    std::cout << "Found" << std::endl;
}

// 查找元音
pos = s.find_first_of("aeiouAEIOU");    // 1（'e'）

// 查找非字母
pos = s.find_first_not_of("abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ ");
std::cout << "First non-letter at: " << pos << std::endl;  // ',' 的位置
```

### 4.3 修改操作

| 方法                        | 说明                  | 示例                               |
| ------------------------- | ------------------- | -------------------------------- |
| `operator+=` / `append()` | 追加字符串               | `s += "abc"` 或 `s.append("abc")` |
| `push_back(char)`         | 追加一个字符              | `s.push_back('x')`               |
| `pop_back()`              | 删除最后一个字符（C++11）     | `s.pop_back()`                   |
| `insert(pos, str)`        | 在位置 pos 前插入         | `s.insert(3, "abc")`             |
| `erase(pos, len)`         | 删除从 pos 开始的 len 个字符 | `s.erase(2, 5)`                  |
| `replace(pos, len, str)`  | 替换子串                | `s.replace(0, 2, "xx")`          |
| `clear()`                 | 清空内容                | `s.clear()`                      |
| `assign()`                | 赋值（类似 operator=）    | `s.assign(10, 'A')`              |

```cpp
std::string s = "Hello";

// 追加
s.append(" World");         // "Hello World"
s += "!";                   // "Hello World!"

// 插入
s.insert(5, ",");           // "Hello, World!"
s.insert(0, "Say: ");       // "Say: Hello, World!"

// 替换
s.replace(4, 3, "!!!");     // 从索引4开始替换3个字符 -> "Say: !!!o, World!"

// 删除
s.erase(4, 3);              // 删除 "!!!" -> "Say: o, World!"
s.pop_back();               // 删除 '!' -> "Say: o, World"

// 清空
s.clear();                  // ""
```

### 4.4 子串与提取

| 方法                     | 说明          | 示例                     |
| ---------------------- | ----------- | ---------------------- |
| `substr(pos, len)`     | 提取子串（深拷贝）   | `s.substr(2, 5)`       |
| `substr(pos)`          | 提取从 pos 到结尾 | `s.substr(3)`          |
| `copy(dest, len, pos)` | 复制到字符数组     | `s.copy(buffer, 5, 0)` |

```cpp
std::string s = "Hello World";

// 提取子串
std::string sub1 = s.substr(6);        // "World"
std::string sub2 = s.substr(0, 5);     // "Hello"
std::string sub3 = s.substr(2, 3);     // "llo"

// 复制到 C 数组
char buffer[20];
size_t len = s.copy(buffer, 5, 0);     // 复制 "Hello"
buffer[len] = '\0';                    // 手动添加终止符
std::cout << buffer << std::endl;      // "Hello"
```

> [!WARNING]
> `substr()` 执行**深拷贝**，会分配新内存。频繁调用可能影响性能。只读访问应使用 [[#字符串视图\|std::string_view]]。

## 5. 运算符重载

| 运算符                  | 说明          | 示例               |
| -------------------- | ----------- | ---------------- |
| `=`                  | 赋值          | `s1 = s2`        |
| `+`                  | 连接（返回新对象）   | `s3 = s1 + s2`   |
| `+=`                 | 追加（原地）      | `s1 += s2`       |
| `==`, `!=`           | 相等性比较（内容）   | `if (s1 == s2)`  |
| `<`, `<=`, `>`, `>=` | 字典序比较       | `if (s1 < s2)`   |
| `[]`                 | 字符访问（无边界检查） | `char c = s[i]`  |
| `<<`, `>>`           | 流输入/输出      | `std::cout << s` |

```cpp
std::string s1 = "Hello";
std::string s2 = "World";

// 连接
std::string s3 = s1 + " " + s2;   // "Hello World"（多个临时对象）
std::string s4 = s1;
s4 += " ";                        // 原地修改，更高效
s4 += s2;

// 比较
if (s1 == "Hello") {              // true
    std::cout << "Equal" << std::endl;
}

if (s1 < s2) {                    // 'H' < 'W'，true
    std::cout << "Hello < World" << std::endl;
}

// 输入输出
std::cin >> s1;                   // 读取一个单词
std::getline(std::cin, s1);       // 读取一整行
```

## 6. 数值转换 (C++11/C++17)

```cpp
#include <string>

// 字符串 → 数值
int i = std::stoi("42");                    // 42
long l = std::stol("1234567890");           // 1234567890
long long ll = std::stoll("9223372036854775807");
float f = std::stof("3.14159");             // 3.14159
double d = std::stod("2.71828");            // 2.71828

// 带错误处理
std::string s = "123abc";
size_t pos;
int value = std::stoi(s, &pos);            // value = 123, pos = 3
if (pos < s.size()) {
    std::cout << "Non-numeric part: " << s.substr(pos) << std::endl;
}

// 数值 → 字符串
std::string s1 = std::to_string(42);        // "42"
std::string s2 = std::to_string(3.14159);   // "3.141590"
```

| 函数 | 转换目标 | 异常 |
|------|---------|------|
| `std::stoi` | `int` | `std::invalid_argument` / `std::out_of_range` |
| `std::stol` | `long` | 同上 |
| `std::stoll` | `long long` | 同上 |
| `std::stof` | `float` | 同上 |
| `std::stod` | `double` | 同上 |
| `std::to_string` | 任意数值 → `string` | 无（不抛异常） |

> [!TIP]
> 使用 `stoi` 系列函数时，建议传入 `pos` 参数检查是否成功转换整个字符串。
