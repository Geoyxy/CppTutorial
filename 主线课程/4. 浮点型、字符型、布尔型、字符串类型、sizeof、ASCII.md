# 浮点型、字符型、布尔型、字符串类型、sizeof

## 1. [[数据类型 Data Type#5. 浮点型（Floating-Point Types）|浮点型]]

### 1.1 浮点型的基本概念

**浮点型**在数学中对应的概念是小数，可以理解为“浮点”二字就是小数点的意思。最常用的浮点型的关键字分别为 `float`, `double` ：

| 类型       | 中文名    | 通常大小 | 精度            | 有效位数                                         |  后缀   |
| -------- | ------ | ---- | ------------- | -------------------------------------------- | :---: |
| `float`  | 单精度浮点型 | 4 字节 | 约 7 位有效数字     | $1.2\times 10^{-38}$ ~ $3.4 \times 10^{38}$  | f 或 F |
| `double` | 双精度浮点型 | 8 字节 | 约 15-16 位有效数字 | $2.2\times 10^{308}$ ~ $1.8 \times 10^{308}$ |   无   |

>[!WARNING] float 和 double 是不准确的
>这里的“精度”指的是有多少位是准确的，例如：
>```cpp
>float f = 30000000000.0f;   // 300 亿
>```
>以上代码中 `f` 在 float 的有效位数范围内（远小于$3.4 \times 10^{38}$）
>但 float 只保证约前 7 位的准确性，也就是说，`f` 实际可能的值是 `30000001024.000000` （从第 8 位开始不准确了）

因为 `float` 和 `double` 的不准确性，所以不推荐使用诸如 `flaot` 和 `double` 此类二进制浮点型存储金额等数据。

>[!EXAMPLE] 关于不准确性的更多示范代码
>```cpp
>#include <iostream>
>
>int main()
>{
>	float f = 3.14f;
>
>	double d = 3.14;
>
>	if (d == f)
>	{
>		std::cout << "f 和 d 相等\n";
>	}
>	else
>	{
>		std::cout << "f 和 d 不相等\n";
>	}
>
>	printf("f 的实际值为： %20.20f\n", f);
>	printf("d 的实际值为： %20.20f\n", d);
>
>	return 0;
>}
>```

### 1.2 `float` 的特性

```cpp
float num = 2.718;
```

为了提高精度和准确性，在定义`float`时编译器会将没有值没有 `f` 后缀的 `float` 变量隐式转换为 `double` 类型的变量。例如以上代码中的 `num` 实际为 `double` 类型。想让 `num` 为 `flaot` 类型需要为 `2.718` 加上 `f` 后缀：

```cpp
float num  = 2.718f;
```

>[!QUESTION] 何为**“隐式”**（Implicit）
>**“隐式”**在编程中指的是**编译器自动帮你做的事情**，不需要你（程序员）显式地写代码去指示。反过来，“显式”（Explicit）就是你**明确写出来**告诉编译器要做什么。
>
>|概念|意思|谁做的|代码体现|
|---|---|---|---|
|**隐式（Implicit）**|编译器**自动**帮你做|编译器|你**没有写**相关代码，但编译器执行了|
|**显式（Explicit）**|你**明确**告诉编译器做|程序员|你**亲自写**了相关代码|

## 2. [[数据类型 Data Type#3. 字符型（Character Types）|字符型]] 和 ASCII

### 2.1 字符型的基本概念

字符型是用来存储单个字符的数据类型，常用的字符型关键字为 `char` 。大小 1 字节

`char` 实际存储的是整数，例如：

```cpp
char c = 97;
```

### 2.2 ASCII

将 `char` 类型的数据中的整数映射到字符的是 [[ASCII 字符代码表.jpg|ASCII 字符代码表]]。

![[ASCII 字符代码表.jpg]]

对比 ASCII 码表可见，以上代码中的 `c` （值为 `97`）对应的字符为 `a`。

ASCII 码表的特点：

1. ASCII 码表中的一些字符无法被打印，即这些字符不可见，例如 0 - 32, 127 （十进制）对应的字符。
2. 数字、大写字母、小写字母是连续的，数字对应 48 - 57，大写字母对应 65 - 90，小写字母对应 97 - 122 。
3. 标准 ASCII 的十进制范围为 0 - 127，扩展 ASCII 的十进制范围为 0 - 255（$256 = 2^8$ 个字符）。
4. 不同字符编码的 ASCII 第 128 - 255 号字符（即扩展字符）是不一样的。

>[!EXAMPLE] 示范代码：打印第 0 ~ 255 个字符
>```cpp
>// 输出 ASCII 的所有字符
>for (int i = 0; i < 256; i++)
>{
>	char c = i;
>	std::cout << " 第" << i << " 个字符是：" << c << std::endl;
>}
>```

### 2.3 `char` 的定义方式

`char` 的定义方式有两种：

```cpp
// 第一种
char c = 48; // c 对应 '0'

// 第二种
char c = '0';
```

`''` 是单个字符的 **定界符**（分隔符），用于表示**字符字面量**Character Literal。如方法二所示，除了直接赋值整数外，C++ 还允许直接将字符字面量赋值给 `char` 类型变量。

### 2.4 `char` 和 `int` 的类型转换

```cpp
char ch = 'A';

cout << ch;
```

以上代码中，`ch` 被打印为 `A`，如果需要 `ch` 被打印为 `65`，需要将代码改为：

```cpp
char ch = 'A';

cout << (int) ch;
```

`(数据类型) 变量名` 的格式表示将 `变量名` 的所存的值的类型显示转换为 `数据类型`。

## 3. [[数据类型 Data Type#4. 布尔型（Boolean Type）|布尔型]]

### 3.1 布尔型的基本概念

**布尔型**是用来存储 **真**（true, 1） / **假**（false, 0）的数据类型，常伴随分支、循环语句出现，用于条件判断。大小 1 字节。

### 3.2 布尔型的定义

关键字为 `bool`，和 `char` 一样，有两种定义方式：

```cpp
// 第一种定义方式，用整数定义
bool is_Valid = 1; // 即 true
bool is_Exist = 0; // 即 false

// 第二种定义方式，用 true 或 false 定义
bool is_Valid = true; // 即 1
bool is_Exist = false; // 即 0
```

关于布尔型的更多内容会在以后的 **分支**、**循环** 语句讲到。

## 4. [[string 字符串类型|字符串类型]]

### 4.1 字符串的基本概念

**字符串类型**，标识符 `string`（不是关键字）， 用于存储字符串，而不像 `char` 那样只能存储单个字符。

与前面所有已学的数据类型不同，字符串类型不属于基本数据类型，位于 `<string>` 标准库中，使用 `string` 需包含此标准库头文件。

```cpp
#include <string>
```

字节大小取决于存储的字符串长短。

### 4.2 字符串的定义

```cpp
string str = "Hello, World!"
```

`""` 是**字符串字面量**（String Literal）的**定界符**（分隔符），用于表示字符串字面量。

## 5. [[sizeof() 运算符|sizeof]]

### 5.1 sizeof 的基本概念

`sizeof` 是 C++ 中的运算符，用于获取数据类型或变量在内存中占用的**字节数**，返回整型（即用整型接受 `sizeof` 的结果。

### 5.2 sizeof 的使用方法

语法：

```cpp
sizeof(数据类型)
sizeof(变量名)
```

示例：

```cpp
// sizeof(数据类型)
cout << "char 类型变量的字节大小是：" << sizeof(char) << endl;

// sizeof(变量名)
string game_name = "鸣潮";
cout << "变量 game_name 的字节大小是：" << sizeof(game_name) << endl;

// 用整型接受 sizeof 的返回值
int size = sizeof(int);
cout << "int 类型变量的字节大小是：" << size << endl;
```
