# 算术、赋值、条件运算符

![[运算符图示.png]]

## 1. 算术运算符

算术运算符主要用于**整型**和**浮点型**的运算，其种类按**操作数**（即参与运算的数）的数量分为：

1. 双目运算符：`+`, `-`, `*`, `/`, `%`
2. 单目运算符：`++`, `--`

“目”指的是一个运算符的操作数的数量。

>[!TIP] 建议
>单目运算符和操作数之间无空格，如 `i++` 。
>多目运算符和操作数之间有空格，如 `a + b` 。

### 1.1 加 `+` 减 `-` 乘 `*`

加 `+` 减 `-` 乘 `*` 的作用和数学里的加减乘一样，例如：

```cpp
int a = 2;
int b = 3;

int result = 0;

result = a + b; // 加法： result = 2 + 3 = 5
result = a - b; // 减法： result = 2 - 3 = -1
result = a * b; // 乘法： result = 2 * 3 = 6
```

### 1.2 除 `/`

除 `/` 即数学中的除法 $\div$ ，按操作数的数据类型不同分为两种情况：

1. 对于两个操作数是整型，`/` 的返回值（即结果）向零取整，例如：

```cpp
4 / 3;  // 数学运算结果是 1.333... 向零取整后为 1
-4 / 3; // 数学运算结果是 -1.333... 向零取整后为 -1
```

>[!TIP] 关于**向零取整**
>向零取整在 $> 0$ 的情况下是 **向下取整**（取最接近自己且比自己小的整数）
>向零取整在 $< 0$ 的情况下是 **向上取整**（取最接近自己且比自己大的整数）

2. 若存在一个操作数是浮点型，则`/` 的返回值（即结果）是浮点型，例如：

```cpp
4.0 / 3;    // 返回 1.33333...
4 / 3.0;    // 返回 1.33333...
4.0 / 3.0f; // 返回 1.33333...
```

### 1.3 取模（取余） `%`

取模 `%` 即数学中除法的求余数，需要注意的是，`%` 的==操作数的数据类型只能是整型==，例如：

在数学中：
$$5 \div 3 = 1 \cdots 2$$
在编程中：

```cpp
5 % 3; // 返回 2，即运算结果是 2
```

### 1.4 自增 `++` 自减 `--`

自增/自减 指的就是操作数自己给自己 $+1$ / $-1$ ，==这里的操作数只能是变量==，例如：

```cpp
int i = 0;
int j = 0;

i++;
--j;

cout << i; // 打印  1，等效于 i = i + 1
cout << j; // 打印 -1，等效于 j = j - 1
```

==重点：==

自增/减 按 **计算** 和 **返回** 这两个步骤的**先后关系**分为两种类型：前置自增/减 和 后置自增/减。

下面以自增为例，自减同理：

| 对比       | 前置自增 `++i`  | 后置自增 `i++` |
| -------- | ----------- | ---------- |
| **执行顺序** | 先自增，再返回新值   | 先返回原值，再自增  |
| **返回值**  | 自增后的值       | 自增前的值      |
| **性能**   | 一般更快        | 可能稍慢       |
| **推荐场景** | 大多数情况（性能略好） | 需要旧值时使用    |

```cpp
int i = 5;

cout << i++; // 打印 5，因为后置自增先返回原值 5 再计算
cout << ++i; // 打印 7，因为上一行结束后 i = 6，这一行在 6 的基础上先自增后再返回新值 7
```

## 2. 赋值运算符

### 2.1 赋值运算符 `=`

将 `=` 的右操作数的值赋给左操作数，例如：

```cpp
int a = 5; // 将 5 赋给 a，即 a 的值为 5
int b = a; // 将 a 的值 5 赋给 b，即 b = 5
```

### 2.2 `+=` `-=` `*=` `/=` `%=`

下面以**加法赋值运算符**`+=` 为例，其余运算符同理：

对于 `a += b` ，等效于 `a = a + b` ，即将 `a + b` 的返回值赋给 a，例如：

```cpp
int a = 5;

cout << (a += 1); // 打印 6，a += 1 等效于 a = a + 1， 
```

## 3. 条件运算符

条件运算符 `?:` 是三目运算符，涉及 3 个操作数，语法为：

```cpp
条件表达式 ? 表达式1 : 表达式2
```

| `条件表达式` 的值 | `?:` 的返回值 |
| :--------: | :-------: |
|   `true`   |  `表达式1`   |
|  `false`   |  `表达式2`   |

>[!TIP] 关于条件表达式
>`条件表达式` 的值非 0，则为真 `true`
>`条件表达式` 的值为 0，则为假 `false`
>
>也就是说 `?` 前的操作数期望的是 `bool`，而 `条件表达式` 的返回值会被隐式转换为 `bool`
>非 0 的值转换为 `bool` 为 `true`
>为 0 的值转换为 `bool` 为 `false`

例如：

```cpp
cout << 3 - 6 ? "yes" : "no"; // 打印 yes，3 - 6 返回 -3，-3 转换为 true
```

## 4. 优先级 Precedence

**优先级**决定了**当多个运算符出现在同一个表达式中时，哪个运算符先参与运算**。

![[运算符图示.png]]

由图可知，优先级：`--` > `*` > `+` > `=`

例如对于：

```cpp
int a = 5;
a = --a + 3 * 2;
```

`a = --a + 3 * 2`表达式中同时出现多个运算符，根据优先级决定运算先后，运算步骤：

1. `--a` ：返回 4，`a` 被赋值为 4
2. `3 * 2` ：返回 6
3. `4 + 6` ：返回 10
4. `a = 10` ：`a` 被赋值为 10

如果需要改变运算顺序则需要用 `()` 为表达式分组，优先执行在最内层 `()` 中的运算符，例如：

```cpp
int a = 5;
int b = -1;

cout << (b = (a = --a)) + (3 * 2) << "\n" << a << "\n" << b;

// 打印：
// 10
// 4
// 4
```

`cout << (b = (a = --a)) + (3 * 2)` 的运算步骤：

| 顺序  |                                       运算符                                       |      说明       |
| :-: | :-----------------------------------------------------------------------------: | :-----------: |
|  1  |                                      `--a`                                      | 返回 4，a 被赋值为 4 |
|  2  |                         `a = --a` $\rightarrow$ `a = 4`                         |  `a` 被赋值为 4   |
|  3  |          `b = (a = --a)` $\rightarrow$ `b = --a` $\rightarrow$ `b = 4`          |  `b` 被赋值为 4   |
|  4  |                                     `3 * 2`                                     |     返回 6      |
|  5  | `(b = (a = --a)) + (3 * 2)` $\rightarrow$ `--a + (3 * 2)` $\rightarrow$ `4 + 6` |     返回 10     |
|  6  |         `cout << (b = (a = --a)) + (3 * 2)` $\rightarrow$ `cout << 10`          | `cout` 接受到 10 |

>[!WARNING] `cout` 的陷阱 与 善用 `()`
>插入运算符/左移运算符/流输出运算符 `<<` 的优先级在 `+` `-` 和 关系运算符之间，需要注意通过加括号来表达正确逻辑，比如 2.2 中的一段代码：
>```cpp
>int a = 5;
>
cout << (a += 1); // 打印 6，a += 1 等效于 a = a + 1， 
>```
>
>在编程中遇到不确定优先级的运算符时要善用`()`

## 5. 结合方向

当多个**同级**运算符出现在同一个表达式中时，则需要根据**结合方向**决定运算顺序。
结合方向分为 **左结合** 和 **右结合**，以下先介绍左结合：

### 5.1 左结合

**左结合（Left Associative）** 的意思是：

> 当一个表达式中**出现多个相同优先级的运算符**时，**左边的运算符先与操作数结合（先分组）**。

简单来说就是先算左边的运算符

例如：

```cpp
1 + 2 - 3
```

`+` 和 `-` 同优先级，则按左结合确定运算顺序，即等效于

```cpp
(1 + 2) - 3
```

### 5.2 右结合

与左结合同理，**右结合（Right Associative）** 的意思是：

> 当一个表达式中**出现多个相同优先级的运算符**时，**右边的运算符先与操作数结合（先分组）**。

例如：

```cpp
a = b = 1 + 1;
```

1. `+` 的优先级在两个 `=` 之上， 先算 `1 + 1`，返回 2
2. 两个 `=` 同级，根据右结合决定运算顺序，即等效于：

```cpp
a = (b = 2);
```

## 6. 补充

### 6.1  整数提升 Integral Promotion

**整数提升**指的是在表达式求值中，将**宽度小于 `int`** 的整数类型（`char`、`signed char`、`unsigned char`、`short`、`bool` 等）**自动转换（即提升）为 `int` 或 `unsigned int`** 的过程。

简单来说，当 `char` `short` `bool` 作为运算符的操作数时，在运算前，这几个数据类型会被隐式转换为 `int`，例如：

```cpp
bool is_true = false; // 即 is_true = 0

1 + is_true;
```

在 `1 + is_true` 这个表达式中，`is_true` 是作为 `int` 类型参与计算的，也就是说，`is_true` 在这个表达式返回的是 `int` 类型的值。

### 6.2 寻常算术转换 Usual Arithmetic Conversions

**巡场算术转换**指的是当**两个操作数类型不同**时，**将两个操作数统一为一种“公共类型”，然后进行计算，以避免精度丢失**。

简单来说，就是编译器会按一定规则统一一个运算符的两个操作数的数据类型，规则如下：

```
long double  （最高级）
    ↑
double
    ↑
float
    ↑
unsigned long long
    ↑
long long
    ↑
unsigned long
    ↑
long
    ↑
unsigned int
    ↑
int           （最低级，但已经是整数提升后的起点）
```

（注：实际转换顺序取决于平台。例如，在 64 位 Windows 中，`long` 和 `int` 大小相同，等级相同，不会互相转换。）

例如：

```cpp
int int_num = 0;
long long_num = 0;

int_num + long_num;
```

我们注意到规则中 `long` 在 `int` 之上，所以 `int_num + long_num` 中 `int_num` 会被转换为 `long` 类型的值（只是转换 `int_num` 的返回值的类型，而非 `int_num` 本身）。

可以发现，我们之前提到的运算符 `/` 的两种情况就是由寻常算术转换造成的。

对于整型有**特殊规则**：

若两个操作数分别为 `signed` 和 `unsigned` 类型，且：

1. `signed` 能表示 `unsigned` 的所有值，则 `unsigned` 隐式转换为 `signed`
2. `signed` 不能表示 `unsigned` 的所有值，则 `signed` 隐式转换为 `unsigned`

需要尤其注意后者，因为负数可能会被转换为正数导致数据不准确。

（注：`signed` 为默认类型，一般不显式写出来，如 `int` 实际为 `signed int`）
