## 1. 析构函数 Destructor

**析构函数**是类中一种**特殊的成员函数**，它的主要作用是**在对象销毁时进行清理工作**。==当对象的生命周期结束时，析构函数会被**自动调用**==。

简单来说：**构造函数负责"出生"，析构函数负责"死亡"**。

析构函数的特点：

| 特征       | 说明                                     |
| -------- | -------------------------------------- |
| **函数名**  | `~类名`（如 `~Person()`）                   |
| **返回值**  | 不写返回值类型                                |
| **参数**   | **无参数**（不能被重载，一个类只有一个析构函数）             |
| **调用时机** | 对象销毁时**自动调用**（如栈对象离开作用域、堆对象被 `delete`） |
| **默认行为** | 如果没定义，编译器会生成一个**隐式析构函数**（函数体为空）        |

析构函数主要用来释放资源（比如堆区内存），例如：

```cpp
// 注意：此示例仅用于演示析构函数的调用时机。
// age_ 指向的必须是堆内存，否则 delete 会导致未定义行为。
// 实际开发中，一般直接用 int age_ 存储年龄，而非指针
class Person
{
private:
    string name_;
    int* age_; // 堆区对象

public:
    // 构造函数
    Person(const string& name, int* age)
        : name_(name), age_(age)
    {
        cout << "构造函数被调用" << endl;
    }

    // 析构函数
    ~Person()
    {
	    delete age_; // 在析构函数释放堆区内存(资源)
        cout << "析构函数被调用" << endl;
    }
};

int main()
{
    Person p("Steve", new int(25));  // 构造函数被调用
    // ... 做些什么
    return 0;                 // 离开作用域，p 被销毁，析构函数被调用
}
```

输出：

```txt
构造函数被调用
析构函数被调用
```

>[!NOTE] 概念：资源 Resource
>在 C++（以及计算机科学）中，**资源** 就是任何**需要从操作系统“申请/获取”，并在用完后必须“归还/释放”的东西**。
>如果光申请不归还，就会出问题（比如内存泄漏、文件句柄耗尽）。
>
>常见的 C++ 资源包括：
>
>- **内存**（堆内存）：用 `new` 或 `malloc` 申请的内存（最典型的资源）。
>- **文件句柄**：用 `fopen` 或 `std::fstream` 打开的文件。
>- **网络连接/Socket**：建立的 TCP 连接。
>- **互斥锁（Mutex）**：多线程中用于同步的锁（`std::mutex`）。
>- **显卡纹理/GPU 缓冲区**：OpenGL 或 DirectX 中的句柄。

与构造函数一样，析构函数也有：

1. **隐式默认析构函数**：如果类中没有定义任何析构函数，编译器会自动生成一个。它的函数体为空，用来逐个销毁成员变量。
2. **显式默认化的析构函数**：我们也可以主动用 `= default` 让编译器生成这个默认行为。这和“显式默认化的默认构造函数”在语法逻辑上完全一致。

显示默认化的析构函数例如：

```cpp
class Person {
public:
    // 显式默认化的析构函数（与编译器生成的隐式版本行为完全相同）
    ~Person() = default;
};
```

析构函数的作用将在 [[#3. RAII]] 中学到。

## 2. 拷贝构造函数 Copy Constructor

### 2.1 拷贝构造函数的基本概念

**拷贝构造函数**是一种特殊的构造函数，它的参数是**当前类类型的 const 引用**，==用于**用一个已有的对象来初始化一个新对象**==。

例如：

```cpp
class Person
{
public:
    string name_;
    int age_;
    
    // 拷贝构造函数，拷贝 other 的数据成员来初始化一个新对象
    Person(const Person& other)
        : name_(other.name_), age_(other.age_)
    {
        cout << "拷贝构造函数被调用" << endl;
    }
};
```

>[!WARNING] 注意：构造函数的参数
>拷贝构造函数的第一个参数必须是 `const 类名&` 或 `类名&`，否则会被编译器识别为普通的带参构造函数而非拷贝构造函数。

拷贝构造函数的常见调用时机：

| 场景                | 示例                            | 说明           |
| ----------------- | ----------------------------- | ------------ |
| **用一个对象初始化另一个对象** | `Person p2(p1);`              | 直接初始化        |
| **复制初始化**         | `Person p2 = p1;`             | 用 `=` 初始化    |
| **函数传参（按值传递）**    | `void func(Person p);`        | 实参拷贝给形参      |
| **函数返回值（按值返回）**   | `Person func() { return p; }` | 返回时拷贝（可能有优化） |

### 2.2 隐式拷贝构造函数

如果类中没有定义拷贝构造函数，编译器会**自动生成一个隐式拷贝构造函数**。自定义非拷贝的构造函数**不会阻止**编译器生成隐式拷贝构造函数。

它的行为是：逐个拷贝每个数据成员。

例如：

```cpp
class Person
{
private:
    string name_;
    int age_;

public:
    Person(const string& name, int age) : name_(name), age_(age) {}
    // 没有写拷贝构造函数，编译器会生成一个
};

int main()
{
    Person p1("赵六", 66);
    Person p2(p1);  // 调用编译器生成的隐式拷贝构造函数
    // p2.name_ == "赵六"，p2.age_ == 66
    return 0;
}
```

隐式拷贝构造函数属于浅拷贝。

### 2.3 浅拷贝 Shallow Copy

**浅拷贝**：在拷贝对象时，**只复制数据成员的值**，而不复制数据成员所指向的底层资源。

例如：

```cpp
class ShallowExample
{
public:
    int* data_;  // 指针成员
    int size_;

    // 带参构造函数：分配资源
    ShallowExample(int size) : size_(size)
    {
        data_ = new int[size_];
    }
	// 拷贝构造函数（浅拷贝）
	ShallowExample(const ShallowExample& se)
	    : data_(se.data_), size_(se.size_)
	{}
	// 析构函数：释放资源
	~ShallowExample()
	{
		delete[] data_;
	}
};

int main()
{
    ShallowExample a(10);
    ShallowExample b(a);  // 这是浅拷贝

    // a.data_ 和 b.data_ 指向同一块内存
    // 析构时，同一块内存被释放两次 → 程序崩溃
    return 0;
}
```

我们知道浅拷贝只复制数据成员的值，因为 `a.data_` 的值是一个堆区内存的地址，所以 `b.data_` 的值也是同一个堆区内存的地址，也就是说 `a.data_` 和 `b.data_` 都指向同一个堆区内存，这就导致了：

| 问题                         | 说明                      | 后果           |
| -------------------------- | ----------------------- | ------------ |
| **双重释放（Double Free）**      | 两个对象的指针指向同一块内存，析构时都尝试释放 | ==未定义行为==    |
| **悬空指针（Dangling Pointer）** | 一个对象释放了内存，另一个对象的指针仍然指向它 | 易引发==未定义行为== |

解决这个问题，需要使用深拷贝。

### 2.4 深拷贝  Deep Copy

**深拷贝**：不仅复制指针本身，还**重新分配新的堆内存**，并复制指针指向的内容。

例如：

```cpp
class GoodArray
{
private:
    int* data_;
    int size_;

public:
    // 构造函数
    GoodArray(int size) : size_(size)
    {
        data_ = new int[size_];
        for (int i = 0; i < size_; i++) {
            data_[i] = i;
        }
        cout << "分配内存，地址：" << data_ << endl;
    }

    // 拷贝构造函数（深拷贝）
    GoodArray(const GoodArray& other) : size_(other.size_)
    {
        // 1. 重新分配自己的内存
        data_ = new int[size_];

        // 2. 复制数据内容
        for (int i = 0; i < size_; i++) {
            data_[i] = other.data_[i];
        }
        cout << "深拷贝，新地址：" << data_ << endl;
    }

    ~GoodArray()
    {
        cout << "释放内存，地址：" << data_ << endl;
        delete[] data_;
    }
};

int main()
{
    GoodArray arr1(10);
    GoodArray arr2(arr1);  // 深拷贝
    // arr1.data_ 和 arr2.data_ 指向不同的内存块
    // 各自释放自己的内存，安全
    return 0;
}
```

输出示例：

```text
分配内存，地址：01204458
深拷贝，新地址：01204148
释放内存，地址：01204148
释放内存，地址：01204458
```

>[!NOTE] 概念：三法则 Rule of Three
> 如果自定义了下面**任意一个**，那么通常就应当**全部自定义另外两个**：
>
>1. 析构函数 `~T()`
>2. 拷贝构造函数 `T(const T&)`
>3. 拷贝赋值运算符 `T& operator=(const T&)`
>
>因为当你手写析构函数释放堆资源（`delete`），说明这个类在管理资源。编译器自动生成的拷贝构造、拷贝赋值只会做**浅拷贝**。

>[!NOTE] 概念：五法则 Rule of Five（这里仅作了解）
>如果你自定义了三法则的三者之一，一般也应当显式定义这两个移动成员：
>
> 1. 移动构造函数 `T(T&&)`
> 2. 移动赋值运算符 `T& operator=(T&&)`
>
>完整五个特殊成员：析构、拷贝构造、拷贝赋值、移动构造、移动赋值。

>[!NOTE] 概念：零法则 Rule of Zero（这里仅作了解）
**尽量不要手写上面 5 个拷贝‑控制成员当中任何一个**。
>
>资源交给 RAII 类型（`std::string`、`std::unique_ptr`）管理，编译器自动生成的 5 个特殊成员就都是正确可用的，你不用动手写任何一个。

## 3. RAII

**RAII** 是 C++ 中最重要的编程思想之一，它的全称是 **Resource Acquisition Is Initialization**，翻译过来就是 **“资源获取即初始化”**。

这个名词听起来很唬人，但它的核心思想极其简单：**将资源的生命周期与对象的生命周期绑定。**

RAII 的核心原则只有两条：

1. **获取资源**：在对象的**构造函数**中获取资源（分配内存、打开文件、加锁等）。
2. **释放资源**：在对象的**析构函数**中释放资源（释放内存、关闭文件、解锁等）。

**结果**：当对象存活时，资源一定有效；当对象被销毁时，资源一定被释放。**资源管理变成了对象管理，程序员不再需要手动调用 `delete` / `fclose` / `unlock`。**

例如：

```cpp
class RAIIArray {
private:
    int* data_;
    int size_;
public:
    // 构造函数：获取资源
    RAIIArray(int size) : size_(size) {
        data_ = new int[size_];
        cout << "资源已分配" << endl;
    }
    
    // 析构函数：释放资源
    ~RAIIArray() {
        delete[] data_;
        cout << "资源已释放" << endl;
    }
    
    // 简单使用
    void Set(int index, int value) {
        if (index >= 0 && index < size_) {
            data_[index] = value;
        }
    }
};

void Example() {
    RAIIArray arr(100);  // 构造时自动分配内存
    
    if (some_condition) {
        return;  // 返回时 arr 被销毁，析构函数自动释放内存
    }
    
    // 不需要手动 delete，无论怎么退出，内存都会被释放
}
```

**关键点**：无论函数是正常返回、提前返回，C++ 都会保证**栈上对象的析构函数一定会被调用**。

## 4. 转换构造函数 Converting Constructor

### 4.1 转换构造函数的定义

**转换构造函数**是指：**可以用一个参数调用的构造函数**。它允许编译器在需要时，**自动将其他类型的值隐式转换为当前类类型**。

例如：

```cpp
class Person
{
private:
    string name_;
    int age_;

public:
    // 转换构造函数：可以用一个 string 参数调用
    Person(const string& name) : name_(name), age_(0)
    {
        cout << "转换构造：string → Person" << endl;
    }

    // 转换构造函数：可以用一个 int 参数调用
    Person(int age) : name_("无名"), age_(age)
    {
        cout << "转换构造：int → Person" << endl;
    }
};
```

乍一看，好像转换构造函数和带参构造函数没有区别，但我们只需要注意“转换构造函数是可以用一个参数调用的构造函数”。

一个类 `A` 定义了转换构造函数后，如果转换构造函数的参数类型是 `T` ，编译器会尝试把 `T` 类型转换为 `A` 类型。转换构造函数允许隐式类型转换也是其与带参构造函数的区别。

```cpp
void PrintPerson(const Person& p) { ... }

int main()
{
    // 直接传入一个 string → 将 string 隐式转换为 Person
    PrintPerson("Geoyxy");  // 等价于 PrintPerson(Person("Geoyxy"))

    // 直接传入一个 int → 将 int 隐式转换为 Person
    PrintPerson(20);         // 等价于 PrintPerson(Person(20))

    return 0;
}
```

如果构造函数有多个参数，但每个参数都有默认值，也可以作为转换构造：

```cpp
class Person
{
public:
    // 多参数，但都有默认值 → 也属于转换构造（可以无参调用）
    Person(const string& name = "无名", int age = 0)
        : name_(name), age_(age) {}
};

int main()
{
    PrintPerson("Geoyxy");   // string 隐式转换为 Person
    PrintPerson(20);         // int 隐式转换为 Person
    PrintPerson();           // 无参数调用（使用默认值），不属于转换构造
    return 0;
}
```

### 4.2 explicit 说明符

虽然转换构造很便利，但有时它会带来意想不到的错误。用 `explicit` 可以**禁止隐式转换**，只允许**显式构造**。

`explicit` 说明符是一种**函数说明符**（Function Specifier），它的作用是==**禁止单参数构造函数的隐式类型转换**==。

例如：

```cpp
class Person
{
private:
    string name_;
    int age_;

public:
    Person() = default;
    // explicit 禁止隐式转换
    explicit Person(const string& name) : name_(name), age_(0) {}
    explicit Person(int age) : name_("无名"), age_(age) {}
};

void PrintPerson(const Person& p) {}

int main()
{
    // ❌ 错误：不能隐式转换（被 explicit 禁止）
    PrintPerson("Mizuki");     // 编译报错！（函数传参，隐式转换）
    PrintPerson(0);            // 编译报错！（函数传参，隐式转换）
    // 复制初始化（=）也被禁止
    Person p1 = "and...";      // ❌ 编译报错！（复制初始化，隐式转换）
    Person p2 = {0};           // ❌ 编译报错！（复制初始化 + 列表初始化）

    // ✅ 必须显式构造
    PrintPerson(Person("Goldenglow"));   // 显式构造
    PrintPerson(Person(0));              // 显式构造
    PrintPerson(Person{"Pepe"});         // 显式构造（C++11 列表初始化）
    
    // 以下写法是显式构造临时对象，不会被 explicit 阻止
    PrintPerson(Person());               // ✅ 显式调用默认构造（如果默认构造存在且可用）

    return 0;
}
```

## 5. this 指针

### 5.1 this 指针的基本概念

`this` 是 C++ 中一个**隐式的指针**，它指向**当前正在调用成员函数的对象本身**。

简单来说：**在一个类的成员函数内，`this`指向这个类的对象**.

例如：

```cpp
class Person
{
private:
    string name_;

public:
    void SetName(const string& name)
    {
        // this 指向调用该函数的对象
        this->name_ = name;  // 等价于 name_ = name;
    }
};

int main()
{
    Person p1;
    Person p2;
    
    p1.SetName("Closure");  // 在 SetName 内部，this 指向 p1
    p2.SetName("Amiya");    // 在 SetName 内部，this 指向 p2
    
    return 0;
}
```

**`this` 是成员函数的一个隐藏参数**，当我们调用 `p1.SetName("Closure")` 时，编译器实际上把它翻译成：

```cpp
SetName(&p1, "Closure");  // this 就是 &p1
```

所以 `this` 的类型是 `Person* const`（指向 `Person` 的 const pointer ——指针本身不可修改，但指向的内容可以修改）。

在 `const` 成员函数中，`this` 的类型是 `const Person* const`（指向的内容也不可修改）。

### 5.2 常见使用场景

#### 5.2.1 成员变量和参数同名

```cpp
class Person
{
private:
    string name;

public:
    // 参数名和成员名相同
    void SetName2(const string& name)
    {
        this->name = name; // 必须用 this 区分
    }
};
```

#### 5.2.2 返回当前对象自身（链式调用）

```cpp
class Person
{
private:
    string name_;
    int age_;

public:
    Person& SetName(const string& name)
    {
        name_ = name;
        return *this;  // 返回当前对象
    }

    Person& SetAge(int age)
    {
        age_ = age;
        return *this;
    }

    void Print() const
    {
        cout << name_ << " (" << age_ << "岁)" << endl;
    }
};

int main()
{
    Person p;
    p.SetName("缺省").SetAge(0).Print(); 
    // 输出：缺省 (0岁)
    return 0;
}
```

## 6. 运算符重载 Operator Overloading

### 6.1 运算符重载的基本概念

你之前是否写过类似这样的代码？

```cpp
struct Student
{
	string name_;
};

int main()
{
	Student stu {"LiHua"};
	cout << stu; // ❌ 报错
}
```

这个代码会在第 9 行报错“没有与这些操作数匹配的 "<<" 运算符”。正确的写法应该是：

```cpp
cout << stu.name_;
```

如果我们想不写 `.name_` 就能使用 `cout <<` 打印的话就需要运算符重载，运算符重载允许**自定义类型也能像内置类型一样使用运算符**。

运算符重载允许我们为自定义类型（如类、结构体）定义运算符的行为，让它们像内置类型一样使用 `+`、`-`、`==` 等运算符。

实际上，运算符作为一种语法糖，其本质是函数，我们能在运算符上看到一些和函数相似的特征：

| 运算符  | 函数  |
| :--: | :-: |
| 操作数  | 参数  |
| 运算结果 | 返回值 |

也就是说运算符重载的本质就是函数重载。

若不了解函数重载，请回顾 [[8. 函数、return、参数、函数签名#3. 函数重载 Function Overloading|8-3. 函数重载 Function Overloading]] 。

不同运算符的推荐重载作用域：

| 运算符                   | 建议使用的形式    | 原因                                 |
| --------------------- | ---------- | ---------------------------------- |
| `=`（赋值）               | **必须为成员**  | 隐式生成的赋值运算符是成员，自定义也必须用成员            |
| `[]`（下标）              | **必须为成员**  | 左操作数必须是类对象                         |
| `()`（函数调用）            | **必须为成员**  | 左操作数必须是类对象                         |
| `->`（成员访问）            | **必须为成员**  | 左操作数必须是类对象                         |
| `+=` `-=`（复合赋值）       | **成员**（推荐） | 修改左操作数本身                           |
| `++` `--`（自增/自减）      | **成员**（推荐） | 修改左操作数本身                           |
| `+` `-` `*`（二元算术）     | **全局**（推荐） | 支持左操作数为内置类型（如 `2 * vec`）           |
| `==` `!=` `<` `>`（比较） | **全局**（推荐） | 保证对称性（`a == b` 和 `b == a` 一致）      |
| `<<` `>>`（流操作）        | **必须为全局**  | 左操作数是 `ostream`/`istream`，不能修改标准库类 |

### 6.2 全局运算符重载

#### 6.2.1 全局运算符重载语法

全局（作用域下的）运算符重载语法：

```cpp
返回类型 operator运算符(参数列表)
{
    // 实现逻辑
}
```

例如，重载 `+` 运算符：

```cpp
// 二维向量结构体
struct Vector2
{
    double x_; // x 坐标
    double y_; // y 坐标
};

// 全局 operator+：两个 Vector2 相加
Vector2 operator+(const Vector2& left, const Vector2& right)
{
    Vector2 result;
    result.x_ = left.x_ + right.x_;
    result.y_ = left.y_ + right.y_;
    return result;
}

int main()
{
    Vector2 a{3.0, 4.0};
    Vector2 b{1.0, 2.0};
    
    Vector2 c = a + b;  // 等价于 operator+(a, b)
    cout << c.x_ << ", " << c.y_ << endl;  // 输出：4, 6
    
    return 0;
}
```

常见的运算符和参数的对应：

| 运算符表达式     | 对应的函数调用            | 说明               |
| ---------- | ------------------ | ---------------- |
| `a + b`    | `operator+(a, b)`  | 左操作数 `a` → 第一个参数 |
| `a - b`    | `operator-(a, b)`  | 右操作数 `b` → 第二个参数 |
| `-a`（一元负号） | `operator-(a)`     | 只有一个参数           |
| `a == b`   | `operator==(a, b)` | 两个参数             |
| `a << b`   | `operator<<(a, b)` | 流插入运算符（通常全局重载）   |

C++ 中大多数运算符都可以重载，但也有例外：

| 类别        | 运算符                                                                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **可以重载**  | `+` `-` `*` `/` `%` `^` `&` `\|` `~` `!` `=` `<` `>` `+=` `-=` `<<` `>>` `==` `!=` `&&` `\|` `++` `--` `->` `*`（解引用） `()`（函数调用） `[]`（下标） `,`（逗号） |
| **不可以重载** | `::`（作用域解析） `.?`（成员访问） `.*`（成员指针解引用） `sizeof` `typeid` `static_cast` `const_cast` 等                                                              |

>[!WARNING] 注意：不要手动调用 `operator运算符`
>不能像调用普通函数那样调用 `operator运算符`，因为它是一种语法层面的特殊标记，只能由编译器在解析表达式时进行匹配和调用。
>
>例如不能这样写：
>
>```cpp
>int sum = operator+(1, 2);  // ❌ 编译报错
>```

#### 6.2.2 +, -, * 运算符重载示例：

```cpp
Vector2 operator+(const Vector2& left, const Vector2& right)
{
    return Vector2{left.x_ + right.x_, left.y_ + right.y_};
}

Vector2 operator-(const Vector2& left, const Vector2& right)
{
    return Vector2{left.x_ - right.x_, left.y_ - right.y_};
}

// 向量乘以标量（注意参数顺序）
Vector2 operator*(const Vector2& vec, double scalar)
{
    return Vector2{vec.x_ * scalar, vec.y_ * scalar};
}

// 标量乘以向量（支持 2 * vec）
Vector2 operator*(double scalar, const Vector2& vec)
{
    return Vector2{vec.x_ * scalar, vec.y_ * scalar};
}
```

#### 6.2.3 \==, != 运算符重载示例：

```cpp
bool operator==(const Vector2& left, const Vector2& right)
{
    return left.x_ == right.x_ && left.y_ == right.y_;
}

bool operator!=(const Vector2& left, const Vector2& right)
{
    return !(left == right);  // 复用 operator==
}

int main()
{
    Vector2 a{3.0, 4.0};
    Vector2 b{3.0, 4.0};
    Vector2 c{1.0, 2.0};
    
    cout << (a == b) << endl;  // 输出：1（true）
    cout << (a == c) << endl;  // 输出：0（false）
    return 0;
}
```

#### 6.2.4 `<<` 运算符重载示例

这是全局运算符重载最经典的场景——支持使用 `cout` 打印自定义类型：

```cpp
// 重载 << 运算符，支持 cout << Vector2
ostream& operator<<(ostream& os, const Vector2& vec)
{
    os << "(" << vec.x_ << ", " << vec.y_ << ")";
    return os;  // 返回 ostream 引用以支持链式调用
}

int main()
{
    Vector2 a{3.0, 4.0};
    cout << a << endl;          // 输出：(3, 4)
    cout << a << " 是向量" << endl;  // 链式调用，等效于以下代码
    // operator<<(operator<<(operator<<(cout, a), " 是向量"), endl);
    return 0;
}
```

>[!TIP] 提示：`ostream` 和 `cout` 的关系
>**`cout` 是标准库在 `<iostream>` 头文件中声明的 `ostream` 类型的全局对象。`<iostream>` 内部包含了 `<ostream>`，因此 `ostream` 类的完整定义对 `cout` 可用。**
>
>**`operator<<` 被重载为接受 `ostream&` 作为左操作数的全局函数，因此 `cout << value` 的写法是合法的，且支持链式调用。**

>[!TIP] 提示：访问权限与友元 Friden
> 当全局运算符函数需要访问类的 `private` 成员时（比如实现 `operator<<` 打印内部状态），会因为访问权限报错，这时就需要“**友元**”。
> 
> 友元是 C++ 的一种访问授权机制，**打破类的封装**，允许一个外部函数 / 另一个类，访问本类所有成员（包括 `private`、`protected` 私有成员）。
> 
> 关于友元的更多内容会在下一节 [[15. const、constexpr、多文件编程、友元#4. 友元 Friend]] 学到。

### 6.3 成员运算符重载

#### 6.3.1 成员运算符重载语法

成员运算符重载是**将运算符定义为类的成员函数**。它的语法如下：

```cpp
// 语法
class 类名
{
public:
    返回类型 operator运算符(参数列表)
    {
        // 实现逻辑
    }
};
```

成员运算符函数的**第一个参数是隐式的 `this` 指针**，指向调用该运算符的左操作数。因此，成员运算符函数的**参数数量比运算符的操作数少一个**。

例如：

```cpp
// 二维向量类
class Vector2
{
public:
    double x_;
    double y_;
    
    Vector2(double x_ = 0, double y_ = 0) : x_(x_), y_(y_) {}

    // 成员 operator+：左操作数是 this，右操作数是 other
    Vector2 operator+(const Vector2& other) const
    {
        return Vector2(x_ + other.x_, y_ + other.y_);
    }

    // 成员 operator-：左操作数是 this，右操作数是 other
    Vector2 operator-(const Vector2& other) const
    {
        return Vector2(x_ - other.x_, y_ - other.y_);
    }

    // 成员 operator==：左操作数是 this，右操作数是 other
    bool operator==(const Vector2& other) const
    {
        return x_ == other.x_ && y_ == other.y_;
    }

    // 打印函数
    void Print() const
    {
        cout << "(" << x_ << ", " << y_ << ")" << endl;
    }
};

int main()
{
    Vector2 a(3.0, 4.0);
    Vector2 b(1.0, 2.0);

    Vector2 c = a + b;  // 等价于 a.operator+(b)
    c.Print();          // 输出：(4, 6)

    Vector2 d = a - b;  // 等价于 a.operator-(b)
    d.Print();          // 输出：(2, 2)

    cout << (a == b) << endl;  // 输出：0（false）

    return 0;
}
```

>[!TIP] 提示：`const` 限定成员函数
>`const` 限定符限定成员函数的大致作用是：约定该函数不会修改对象的数据成员。

#### 6.3.2 复合赋值运算符重载

复合赋值运算符（如 `+=`、`-=`、`*=`）**通常定义为成员函数**，因为它们会修改左操作数本身。

```cpp
class Vector2
{
public:
    double x_;
    double y_;
    
    Vector2(double x_ = 0, double y_ = 0) : x_(x_), y_(y_) {}

    // += 运算符：修改自身，返回自身引用
    Vector2& operator+=(const Vector2& other)
    {
        x_ += other.x_;
        y_ += other.y_;
        return *this;
    }

    // -= 运算符
    Vector2& operator-=(const Vector2& other)
    {
        x_ -= other.x_;
        y_ -= other.y_;
        return *this;
    }

    // *= 运算符（向量乘以标量）
    Vector2& operator*=(double scalar)
    {
        x_ *= scalar;
        y_ *= scalar;
        return *this;
    }

    void Print() const
    {
        cout << "(" << x_ << ", " << y_ << ")" << endl;
    }
};

int main()
{
    Vector2 a(3.0, 4.0);
    Vector2 b(1.0, 2.0);

    a += b;   // 等价于 a.operator+=(b)
    a.Print(); // 输出：(4, 6)

    a *= 2;   // 等价于 a.operator*=(2)
    a.Print(); // 输出：(8, 12)

    return 0;
}
```

#### 6.3.3 下标运算符重载

下标运算符 `[]` **必须定义为成员函数**。

```cpp
class DynamicArray
{
public:
    int* data_; // 数组元素
    int size_;  // 数组大小
    
    DynamicArray(int size) : size_(size)
    {
        data_ = new int[size_];
    }

    ~DynamicArray()
    {
        delete[] data_;
    }

    // 非 const 版本：可读写
    int& operator[](int index)
    {
        if (index < 0 || index >= size_) {
            throw std::out_of_range("索引越界");
        }
        return data_[index];
    }

    // const 版本：只读（当对象被 const 限定时调用此版本）
    const int& operator[](int index) const
    {
        if (index < 0 || index >= size_) {
            throw std::out_of_range("索引越界");
        }
        return data_[index];
    }

    int Size() const { return size_; }
};

int main()
{
    DynamicArray arr(5);
    
    arr[0] = 10;   // 调用非 const 版本，返回 int&
    arr[1] = 20;
    
    cout << arr[0] << endl;  // 输出：10
    
    const DynamicArray& constArr = arr;
    cout << constArr[0] << endl;  // 调用 const 版本
    
    return 0;
}
```

>[!QUESTION] **问题**：为什么需要 const 重载？
>
>- 非 const 版本返回 `int&`，允许修改数组元素。
>- const 版本返回 `const int&`，只允许读取，防止 const 对象被意外修改。

#### 6.3.4 函数调用运算符重载

函数调用运算符 `()` **必须定义为成员函数**。它允许对象像函数一样被调用，这种对象称为**仿函数（Functor）**。

```cpp
// 加法器类
class Adder
{
private:
    int offset_; // 偏移量（加数）

public:
    Adder(int offset) : offset_(offset) {}

    // 函数调用运算符重载
    int operator()(int value_) const
    {
        return value_ + offset_;
    }

    // 多参数版本也可以
    int operator()(int value1_, int value2_) const
    {
        return value1_ + value2_ + offset_;
    }
};

int main()
{
    Adder add5(5);
    
    cout << add5(10) << endl;       // 输出：15（10 + 5）
    cout << add5(3, 7) << endl;     // 输出：15（3 + 7 + 5）
    
    return 0;
}
```

### 6.4 占位参数 Placeholder Parameter

**占位参数**是指在函数声明或定义中，**只写类型，不写参数名**的参数。

调用函数时，若参数列表有占位参数，则必须传入占位参数的实参，即使占位参数没有被使用。

例如：

```cpp
// 占位参数：只有类型，没有名字
void GetHello(int) { return "hello"; }

int main()
{
	cout << Func(1); // 调用时必须传入参数
	return 0;
}
```

占位参数通常用来重载后置 `++`, `--` 运算符：

```cpp
class Counter
{
private:
    int count_ = 0;

public:
    // 前置 ++：返回引用
    Counter& operator++()
    {
        ++count_;
        return *this;
    }

    // 后置 ++：返回旧值，用 int 占位参数区分
    Counter operator++(int)  // ← int 是占位参数，没有名字
    {
        Counter old = *this;
        ++count_;
        return old;
    }
};

int main()
{
    Counter c;
    ++c;   // 调用前置版本：operator++()
    c++;   // 调用后置版本：operator++(int)
    return 0;
}
```

因为前置和后置的 `++` 运算符，函数名和操作数数量都相同（都是一元运算符）。如果两个版本写成 `operator++()` 和 `operator++()`，编译器无法区分。所以 C++ 规定：**后置版本用 `int` 占位参数来区分**。
