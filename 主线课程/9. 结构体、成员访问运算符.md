# 结构体、成员访问运算符、goto

## 1. 结构体 Struct

### 1.1 结构体的基本概念

试想，我们要写一个处理学生信息的程序，一个学生包括 4 个属性：

1. 学号（`sno`）
2. 姓名（`name`）
3. 性别（`gender`）
4. 成绩（`score`）

若要定义 3 个学生，就得定义 $3 \times 4=12$ 个变量，若还要增加学生信息的属性个数和学生个数，代码量会剧烈增长，不易维护。如果我们可以定义一个变量，这个变量里可以包含若干个子变量作为一个学生的信息，例如：

```cpp
变量名：student
{
	// student 包含以下变量
	string sno;    // 学号
	string name;   // 姓名
	string gender; // 性别
	double score;  // 成绩
}

int main()
{
	student1: "001", "张三", "女", 99.0;
	student2: "002", "李四", "男", 91.8;
	student3: "003", "王五", "女", 84.5;
}
```

那么代码量会少很多，这个包含多个变量的变量就是结构体。

**结构体**（Struct）是 C++ 中一种**自定义数据类型**，允许你将**多个不同类型的变量**组合成一个整体。
简单来说：结构体就是**把一组相关的数据装进一个盒子里**。

### 1.2 结构体的定义

定义语法：

```cpp
struct 结构体类型名 
{
    数据类型 成员名1;
    数据类型 成员名2;
    ...
}; // 注意这里有分号 ;
```

其中的成员叫作**数据成员**或**成员变量**，和数组一样，结构体的成员在内存中是连续的，关于“内存中连续”这个概念，我们会在下节课中学到

例如：

```cpp
struct Student {
	string sno = "";    // 学号
	string name = "";   // 姓名
	string gender = ""; // 性别
	double score = 0.0;  // 成绩
};
```

这个定义相当于创造了一个新的**数据类型** `Student`，它内部包含了四个**成员变量**。

### 1.3 结构体变量的声明及初始化

#### 1.3.1 结构体变量的声明

结构体变量的声明语法：

```cpp
结构体类型名 结构体变量名;
```

例如：

```cpp
Student student1;
```

#### 1.3.2 使用 `{}` 列表初始化（C++11 起）

按照结构体成员**定义的顺序**，依次传入值：

```cpp
Student s1 = {"2024001", "Alice", "女", 95.5};
// 或省略等号
Student s2{"2024002", "Bob", "男", 88.0};
```

这是最常用、最推荐的初始化方式。

#### 1.3.3 指定成员名初始化（C++20 起）

可以指定成员名，**不依赖顺序**：

```cpp
Student s1 = {
    .name = "Alice",
    .sno = "2024001",
    .score = 95.5,
    .gender = "女"
};
```

#### 1.3.4 使用 `{}` 全部初始化为空

```cpp
Student s1 = {};  // 所有成员被初始化为 0 或空字符串
Student s2{};     // 同样效果
```

#### 1.3.5 部分初始化

如果 `{}` 中提供的值少于成员数量，**剩余成员会被默认初始化为 0 或空字符串**。

```cpp
Student s1 = {"2024001", "Alice"};  
// s1.sno = "2024001"
// s1.name = "Alice"
// s1.gender = ""   （空字符串）
// s1.score = 0.0   （自动为 0）
```

**注意**：部分初始化只能从**第一个成员开始**连续提供值，不能跳过前面的成员。

#### 1.3.6 结构体数组的初始化

```cpp
// 方式 1：列表初始化整个数组
Student classRoom[3] = {
    {"2024001", "Alice", "女", 95.5},
    {"2024002", "Bob", "男", 88.0},
    {"2024003", "Charlie", "男", 92.5}
};

// 方式 2：全部初始化为 0
Student classRoom[3] = {};
```

### 1.4 结构体成员的访问

访问结构体要使用**成员访问运算符**（Member Access Operator）`.` ，`.` 属于双目运算符，它的两个操作数：

1. 左操作数：结构体变量
2. 右操作数：成员

`.` 的作用是返回结构体变量的成员，例如

```cpp
Student student1;
student1.name = "张三";
cout << student1.name;
```

输出：

```
张三
```

>[!WARNING] 注意
>避免直接对结构体变量使用 `<<` ，例如：
>```cpp
>Student s {"2024001", "Alice", "女", 95.5};
>cout << s;
>```
> 编译器并不知道如何打印结构体变量，会出现语法错误。

## 2. goto 语句

### 2.1 goto 的基本概念

之前我们学过了以下三种跳转语句：

| 对比维度       | `break`       | `continue`    | `return`          |
| ---------- | ------------- | ------------- | ----------------- |
| **作用范围**   | 循环 / `switch` | 循环            | 整个函数              |
| **是否退出循环** | ✅ 退出整个循环      | ❌ 不退出，进入下一次迭代 | ✅ 退出整个函数（含循环）     |
| **是否退出函数** | ❌ 不退出         | ❌ 不退出         | ✅ 退出函数            |
| **能否带值**   | ❌ 不能          | ❌ 不能          | ✅ 可以（非 `void` 函数） |

C++ 标准只承认了四种跳转语句，除了以上三种以外，剩下的则是 `goto` 语句。
`goto` 是 C++ 中的一种**无条件跳转语句**，它允许程序直接跳转到函数内标记好的位置（标签）继续执行。

### 2.2 goto 的使用

你需要使用**标签**才可以用 `goto` 在函数内进行跳转，当程序（[[8. 函数、return、参数、函数签名#^7640ca|执行流]]）执行到 `goto 标签` 时会直接跳转到函数内的 `标签:` 处继续执行。

例如：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "1. 开始" << endl;
    
    goto skip;  // 跳转到 skip 标签
    
    cout << "2. 这行被跳过" << endl;
    
skip:
    cout << "3. 跳转到这里" << endl;
    
    return 0;
}
```

输出：

```text
1.开始
3.跳转到这里
```

### 2.3 为什么 goto 被强烈不推荐？

| 问题             | 说明                                              |
| -------------- | ----------------------------------------------- |
| **破坏结构化编程**    | 程序不再是“顺序、分支、循环”三种结构的组合，变得像意大利面条一样混乱             |
| **难以阅读和维护**    | 跳来跳去，后人无法直观理解代码的执行路径                            |
| **容易出错**       | 跳过变量初始化、跳过资源释放，极易导致==未定义行为==                    |
| **被大多数编码规范禁止** | Google、MISRA、C++ Core Guidelines 都明确禁止使用 `goto` |
| **调试困难**       | 断点无法清楚定位跳转前后的执行顺序                               |

虽然 99% 的情况下不推荐，但在极少数底层场景中仍有使用价值：

| 场景                 | 说明                                   |
| ------------------ | ------------------------------------ |
| **释放资源（C 语言风格）**   | C 代码中没有 RAII，用 `goto` 集中处理错误退出前的资源释放 |
| **跳出多层循环（无其他手段时）** | 当嵌套太深且无法用 `return` 或 `break` 替代时     |
| **状态机实现**          | 某些底层驱动状态机用 `goto` 实现更简洁              |
| **与 C 代码兼容的遗留项目**  | 已有代码用 `goto`，维护时保持风格一致               |

>[!WARNING] 注意
>除非你的项目规范允许使用 `goto` ，否则本教程仍然**强烈不推荐使用 `goto` 语句**。

### 2.4 跳转语句对比表

|对比维度|`break`|`continue`|`return`|`goto`|
|---|---|---|---|---|
|**作用范围**|循环 / `switch`|循环|整个函数|函数内任意位置|
|**是否退出循环**|✅ 退出整个循环|❌ 不退出，进入下一次迭代|✅ 退出整个函数（含循环）|❌ 不退出，跳到别处|
|**是否退出函数**|❌ 不退出|❌ 不退出|✅ 退出函数|❌ 不退出|
|**能否带值**|❌ 不能|❌ 不能|✅ 可以（非 `void` 函数）|❌ 不能|
|**可读性**|✅ 好|✅ 好|✅ 好|❌ 极差|
|**推荐使用**|✅ 推荐|✅ 推荐|✅ 推荐|❌ 不推荐|
