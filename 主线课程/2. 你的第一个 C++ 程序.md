# 你的第一个 C++ 程序

## 完整代码示范

```cpp
#include <iostream>
using namespace std;

int main()
{
	cout << "Hello, World!" << endl;
	
	return 0;
}
```

## 学习要点

本节课只需掌握 3 件事，其余概念简单过目即可，复杂内容后面课程会详细讲解：

1. 掌握 `cout` 的基础用法，学会在终端显示文本。
2. `{ ... }` 的末尾建议（也应该）加 `return 0;`（ISO）
3. 剩余代码是固定格式的模板，先记住写法，不用深究底层原理。

## 代码讲解

### 1. 预处理指令

```cpp
#include <iostream>
```

`#include` 是一个预处理指令，用于在编译前将头文件的内容地**包含**到源文件中，从而引入函数、类、变量等的**声明**，使得编译器能识别它们。

`<iostream>` ：`iostream` 是标准库中的头文件，包含用于输出的 `cout` 和用于输入的 `cin` 两个对象。`<...>` 用于查找标准库头文件。

### 2. 编译指令

```cpp
using namespace std;
```

`using` 是一个**编译指令**（或称为**命名空间指令**），用于**声明**要使用某个命名空间中的标识符，从而使得该命名空间中的名称在当前作用域中**可以直接使用**，而无需加上命名空间前缀。

`namespace std` ：`std` 是C++标准库的**命名空间**（namespace），它包含了所有标准库组件（如 `cout`、`cin`、`vector`、`string` 等）的声明。

`using namespace std;` 的作用是将 `std` 命名空间中的所有名称引入当前作用域，之后代码中就可以直接写 `cout` 而不是 `std::cout`。

### 3. 主函数

```cpp
int main() {...}
```

`int` 是C++中的 **基本**[[数据类型 Data Type|数据类型]]，表示**整数类型**（integer）。在这里，它指定了 `main` 函数的**返回值类型**为整数，用于向操作系统返回程序的退出状态码。按照惯例，返回 `0` 表示程序成功执行，返回非零值表示出现错误。

`main` 是C++程序的**入口函数**（entry point），操作系统在启动程序时会首先调用 `main` 函数。每个C++程序**必须有且仅有一个**名为 `main` 的函数，否则程序无法链接和运行。

`()` 是**函数参数列表**的标识符，用于声明函数接收的参数。`main` 函数可以有两种合法形式：
1.  **无参数**：`int main()`，不接受任何命令行参数。
2. **带参数**：`int main(int argc, char* argv[])`，用于接收命令行传入的参数（`argc` 表示参数个数，`argv` 存储参数字符串数组）。


`{...}` 是**函数体**（function body），用一对花括号包围，其中包含函数执行的所有语句。程序的实际逻辑就写在这一对花括号内部。

### 4. cout 输出语句

```cpp
cout << "Hello, World!" << endl;
```

`cout` 是C++标准库中的**输出对象**（属于 `std::ostream` 类），用于向**控制台**（显示程序结果的地方）发送数据。可以把它理解为程序与屏幕之间的"输出管道"。

`<<` 是 [[插入运算符]]（或称为**流输出运算符**），作用是将右侧的内容"插入"到左侧的输出流中。在这里，它把字符串 `"Hello, World!"` 和换行符发送到 `cout`，从而显示在屏幕上。

`"Hello, World!"` 是一个**字符串[[字面量 Literal|字面量]]**（string literal），即用双引号括起来的一串字符，它是程序要输出的实际内容。

`endl` 是C++标准库中的**操纵符**（manipulator），全称是 "end line"，作用有两个：

1. **换行**：在输出流中插入一个换行符（类似 `\n`），将光标移到下一行。
2. **刷新输出缓冲区**：强制将缓冲区中的内容立即输出到屏幕，确保用户能及时看到。

### 5. 返回值

```cpp
return 0;
```

`return` 是C++中的**跳转语句**，用于**从当前函数中返回**，并将控制权交还给调用者。在 `main` 函数中，它表示将控制权交还给操作系统。

`0` 是返回给操作系统的**退出状态码**（exit status code）。按照惯例，`0` 表示程序**成功执行**，没有任何错误；非零值（如 `1`、`-1` 等）表示程序因某种错误而异常终止。
