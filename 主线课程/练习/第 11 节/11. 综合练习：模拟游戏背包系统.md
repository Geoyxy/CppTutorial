# 综合练习：模拟游戏背包系统

> 这道题综合了本节课所学的：生命周期、栈区与堆区、`new`/`delete` 动态内存分配与释放、悬空指针、内存泄漏等知识点。


## 一、结构体定义

```cpp
struct Item {
    int id = 0;          // 物品ID
    string name = "";    // 物品名称
    int value = 0;       // 物品价值
};
```


## 二、题目要求

### 第 1 问：栈区 vs 堆区

在 `main` 函数中：

1. 在**栈区**创建一个 `Item` 变量 `sword`，初始化为 `{1, "铁剑", 100}`。
2. 在**堆区**创建一个 `Item` 变量 `potion`，初始化为 `{2, "生命药水", 50}`。
3. 分别打印 `sword` 和 `potion` 的地址，观察它们在内存中的位置差异。
4. 用 `delete` 释放 `potion` 的内存。

### 第 2 问：动态数组

1. 用户输入一个整数 `n`，表示背包中物品的数量。
2. 在堆上动态创建一个 `Item` 数组，长度为 `n`。
3. 用循环让用户依次输入每个物品的 `id`、`name`、`value`。
4. 遍历数组，打印所有物品的信息。
5. 释放数组内存。

### 第 3 问：模拟背包扩容

1. 初始时，背包有 **2 个物品**（用动态数组存储，数据自定）。
2. 编写一个函数 `void AddItem(Item*& arr, int& size, Item newItem)`，实现：
   - 创建一个**新数组**，长度为 `size + 1`
   - 把旧数组的所有物品复制到新数组
   - 把新物品放入新数组的最后一个位置
   - 释放旧数组内存
   - 让 `arr` 指向新数组，`size` 加 1
3. 在 `main` 中调用 `AddItem` 添加一个物品，遍历打印所有物品。
4. 释放数组内存。

### 第 4 问：观察内存泄漏（思考题，不要求写代码）

```cpp
while (true) {
    Item* p = new Item{1, "金币", 10};
}
```

1. 这段代码存在什么问题？
2. 如果运行它，会发生什么？
3. 如何修复？

## 三、参考思路

```text
1. 第 1 问：栈区变量直接用 Item sword = {1, "铁剑", 100}; 堆区用 Item* potion = new Item{2, "生命药水", 50}; 打印地址用 &sword 和 potion（注意：potion 本身就是地址）
2. 第 2 问：用 new Item[n] 创建数组，用循环 cin 输入，用 delete[] 释放
3. 第 3 问：先创建旧数组并赋值，AddItem 里用 new Item[newSize] 创建新数组，复制旧数据，添加新数据，delete[] 旧数组，修改指针指向
4. 第 4 问：new 了但没 delete，无限循环导致内存泄漏，最终程序崩溃。修复：在循环内加上 delete p;
```


## 四、提示

| 知识点 | 关键代码 |
| :--- | :--- |
| 栈区变量 | `Item sword{1, "铁剑", 100};` |
| 堆区变量 | `Item* potion = new Item{2, "生命药水", 50};` |
| 动态数组 | `Item* arr = new Item[n];` |
| 释放数组 | `delete[] arr;` |
| 引用指针参数 | `Item*& arr`（让函数可以修改指针本身） |

## 五、参考答案

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Item {
    int id = 0;
    string name = "";
    int value = 0;
};

// ==================== 第 3 问 ====================

void AddItem(Item*& arr, int& size, Item newItem) {
    int newSize = size + 1;
    Item* newArr = new Item[newSize];

    // 复制旧数据
    for (int i = 0; i < size; i++) {
        newArr[i] = arr[i];
    }

    // 添加新物品
    newArr[size] = newItem;

    // 释放旧数组
    delete[] arr;

    // 指向新数组
    arr = newArr;
    size = newSize;
}

// ==================== main ====================

int main() {
    // ===== 第 1 问 =====
    cout << "=== 第 1 问：栈区 vs 堆区 ===" << endl;

    Item sword{1, "铁剑", 100};          // 栈区
    Item* potion = new Item{2, "生命药水", 50}; // 堆区

    cout << "sword（栈）地址：" << &sword << endl;
    cout << "potion（堆）地址：" << potion << endl;
    cout << endl;

    delete potion;   // 手动释放堆内存
    potion = nullptr;

    // ===== 第 2 问 =====
    cout << "=== 第 2 问：动态数组 ===" << endl;

    int n;
    cout << "请输入物品数量：";
    cin >> n;

    Item* bag = new Item[n];

    for (int i = 0; i < n; i++) {
        cout << "请输入第 " << i + 1 << " 个物品的 id、名称、价值：";
        cin >> bag[i].id >> bag[i].name >> bag[i].value;
    }

    cout << "\n背包物品：" << endl;
    for (int i = 0; i < n; i++) {
        cout << bag[i].id << " " << bag[i].name << " " << bag[i].value << endl;
    }
    cout << endl;

    delete[] bag;
    bag = nullptr;

    // ===== 第 3 问 =====
    cout << "=== 第 3 问：背包扩容 ===" << endl;

    int size = 2;
    Item* bag2 = new Item[size]{
        {1, "长剑", 120},
        {2, "盾牌", 80}
    };

    cout << "扩容前：" << endl;
    for (int i = 0; i < size; i++) {
        cout << bag2[i].id << " " << bag2[i].name << " " << bag2[i].value << endl;
    }

    Item newItem{3, "头盔", 60};
    AddItem(bag2, size, newItem);

    cout << "\n扩容后：" << endl;
    for (int i = 0; i < size; i++) {
        cout << bag2[i].id << " " << bag2[i].name << " " << bag2[i].value << endl;
    }

    delete[] bag2;
    bag2 = nullptr;

    // ===== 第 4 问 =====
    cout << "\n=== 第 4 问：思考题 ===" << endl;
    cout << "代码 while(true) { Item* p = new Item{1, \"金币\", 10}; }" << endl;
    cout << "问题：无限分配堆内存且从不释放，导致内存泄漏，最终程序因内存耗尽而崩溃。" << endl;
    cout << "修复：在循环内添加 delete p; 或使用智能指针。" << endl;

    return 0;
}
```
