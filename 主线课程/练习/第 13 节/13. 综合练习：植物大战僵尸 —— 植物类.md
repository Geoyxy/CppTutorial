# 综合练习：植物大战僵尸 —— 植物类

> 本次练习综合了本章所学的：类与对象、数据成员与成员函数、构造函数、访问说明符（封装）等知识点。

## 一、背景说明

你正在开发一款塔防游戏。每种植物都有生命值、攻击力、攻击间隔等属性，并能执行一些操作（攻击、被攻击、检查存活等）。

你的任务是设计一个 `Plant` 类，封装一种植物的数据和操作。

## 二、类设计

### 数据成员（私有）

| 变量名                | 类型       | 说明       | 初始值       |
| :----------------- | :------- | :------- | :-------- |
| `name_`            | `string` | 植物名称     | 由构造函数传入   |
| `hp_`              | `int`    | 当前生命值    | `max_hp_` |
| `max_hp_`          | `int`    | 最大生命值    | 由构造函数传入   |
| `attack_`          | `int`    | 攻击力      | 由构造函数传入   |
| `attack_interval_` | `int`    | 攻击间隔（帧数） | 由构造函数传入   |
| `cooldown_`        | `int`    | 当前冷却剩余帧数 | 0（初始可以攻击） |

### 成员函数（公有）

| 函数 | 参数 | 返回值 | 功能 |
| :--- | :--- | :--- | :--- |
| **构造函数** | `name`, `max_hp`, `attack`, `attack_interval` | — | 初始化植物 |
| **`IsAlive`** | 无 | `bool` | 返回是否存活（`hp_ > 0`） |
| **`TakeDamage`** | `damage` | `void` | 承受伤害 |
| **`CanAttack`** | 无 | `bool` | 返回 `cooldown_ == 0`（可以攻击） |
| **`Attack`** | 无 | `int` | 返回 `attack_`，并重置 `cooldown_` 为 `attack_interval_` |
| **`Update`** | 无 | `void` | 每帧调用，`cooldown_` 减 1（不低于 0） |
| **`PrintStatus`** | 无 | `void` | 打印植物状态 |

## 三、题目要求

### 第 1 问：实现 `Plant` 类（核心）

在 `main.cpp` 中直接完成：

1. 定义 `Plant` 类，所有成员变量为 `private`。
2. 实现构造函数，使用**初始化列表**。
3. 按表格实现所有成员函数。
4. `PrintStatus` 格式：`"[植物名] HP:当前/最大 ATK:攻击力 冷却:剩余冷却"`

### 第 2 问：测试

在 `main` 函数中模拟一局植物与僵尸的战斗：

1. 创建一株 `豌豆射手`（`max_hp = 100`, `attack = 20`, `attack_interval = 3`）。
2. 创建一个 `普通僵尸`（`hp = 50`，只需要一个 `int` 变量存血量，不用写成类）。
3. 模拟 10 帧的战斗：
   - 每帧调用植物的 `Update`
   - 如果植物可以攻击（`CanAttack`）且僵尸还活着，调用 `Attack` 扣减僵尸血量
   - 如果僵尸还活着，每帧对植物造成 5 点伤害（调用 `TakeDamage`）
   - 打印每帧双方状态
4. 输出最终结果（谁赢了）。

## 四、提示

| 知识点 | 关键代码 |
| :--- | :--- |
| 初始化列表 | `Plant(...) : name_(name), max_hp_(max_hp), hp_(max_hp), ... {}` |
| `const` 成员函数 | `bool IsAlive() const { return hp_ > 0; }` |
| 帧更新逻辑 | `if (cooldown_ > 0) cooldown_--;` |

## 五、参考答案

```cpp
#include <iostream>
#include <string>
using namespace std;

class Plant {
private:
    string name_;
    int hp_;
    int max_hp_;
    int attack_;
    int attack_interval_;
    int cooldown_;

public:
    // 构造函数
    Plant(const string& name, int max_hp, int attack, int attack_interval)
        : name_(name), max_hp_(max_hp), hp_(max_hp),
          attack_(attack), attack_interval_(attack_interval), cooldown_(0) {}

    bool IsAlive() const {
        return hp_ > 0;
    }

    void TakeDamage(int damage) {
        if (!IsAlive()) return;
        hp_ -= damage;
        if (hp_ < 0) hp_ = 0;
        cout << name_ << " 受到 " << damage << " 点伤害，剩余 HP：" << hp_ << endl;
    }

    bool CanAttack() const {
        return IsAlive() && cooldown_ == 0;
    }

    int Attack() {
        if (!CanAttack()) return 0;
        cooldown_ = attack_interval_;
        cout << name_ << " 攻击！造成 " << attack_ << " 点伤害" << endl;
        return attack_;
    }

    void Update() {
        if (!IsAlive()) return;
        if (cooldown_ > 0) {
            cooldown_--;
        }
    }

    void PrintStatus() const {
        cout << "【" << name_ << "】HP:" << hp_ << "/" << max_hp_
             << " ATK:" << attack_ << " 冷却:" << cooldown_ << endl;
    }
};

int main() {
    Plant peashooter("豌豆射手", 100, 20, 3);
    int zombieHp = 50;
    int frame = 0;

    cout << "=== 战斗开始 ===" << endl;
    peashooter.PrintStatus();
    cout << "僵尸 HP：" << zombieHp << endl;

    while (peashooter.IsAlive() && zombieHp > 0) {
        frame++;
        cout << "\n=== 第 " << frame << " 帧 ===" << endl;

        // 植物更新冷却
        peashooter.Update();

        // 植物攻击
        if (peashooter.CanAttack()) {
            zombieHp -= peashooter.Attack();
            if (zombieHp < 0) zombieHp = 0;
            cout << "僵尸剩余 HP：" << zombieHp << endl;
        }

        // 僵尸攻击
        if (zombieHp > 0 && peashooter.IsAlive()) {
            peashooter.TakeDamage(5);
        }

        peashooter.PrintStatus();
        cout << "僵尸 HP：" << zombieHp << endl;
    }

    cout << "\n=== 战斗结束 ===" << endl;
    if (peashooter.IsAlive()) {
        cout << "豌豆射手 获胜！" << endl;
    } else {
        cout << "僵尸 获胜！" << endl;
    }

    return 0;
}
```
