# 综合练习：迷你游戏角色战斗系统

> 本次练习综合了结构体、数组、函数、指针、引用、动态内存、`const` 限定符等核心知识点。

## 一、结构体定义

```cpp
struct Character {
    string name = "";
    int hp = 0;
    int attack = 0;
    int defense = 0;
};
```

## 二、题目要求

### 第 1 问：初始化与打印（结构体 + `const` 引用）

1. 在 `main` 中创建两个 `Character` 变量（玩家和敌人），用列表初始化赋初值。
2. 编写函数 `void Print(const Character& c)`，用 `const` 引用接收角色，打印其所有属性。
3. 调用 `Print` 打印两个角色。

### 第 2 问：攻击逻辑（引用传递）

编写函数 `void Attack(Character& attacker, Character& defender)`：
- 伤害 = `attacker.attack - defender.defense`，最低为 1
- 从 `defender.hp` 中扣除伤害
- 在 `main` 中让玩家攻击敌人一次，打印双方血量验证。

### 第 3 问：自动战斗（循环 + 引用）

编写函数 `void AutoBattle(Character& player, Character& enemy)`：
- **玩家先手**，轮流攻击
- 每回合打印攻击结果
- 一方 `hp ≤ 0` 时战斗结束，打印胜利者
- 在 `main` 中调用，观察完整战斗过程。

### 第 4 问：动态创建敌人（动态内存 + 指针）

编写函数 `Character* CreateEnemy(int level)`：
- `hp = 50 + level * 10`
- `attack = 10 + level * 3`
- `defense = level * 2`
- 返回堆上创建的敌人指针

在 `main` 中：
- 调用 `CreateEnemy(3)` 创建敌人
- 战斗结束后释放内存，指针置空

### 第 5 问：代码审查（找错误）

找出以下代码中的 **至少 3 处** 问题：

```cpp
void DoBattle(const Character* player, Character* enemy) {
    while (true) {
        if (enemy->hp <= 0) break;
        Attack(*player, *enemy);
        if (player->hp <= 0) break;
        Attack(*enemy, *player);
    }
}
```

## 三、提示

| 知识点 | 关键代码 |
| :--- | :--- |
| `const` 引用参数 | `void Print(const Character& c)` |
| 引用传递 | `void Attack(Character& a, Character& d)` |
| 动态分配 | `Character* e = CreateEnemy(3);` |
| 释放内存 | `delete e; e = nullptr;` |
| 返回 `const` 指针 | 用于只读访问 |

## 四、完整参考答案

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Character {
    string name = "";
    int hp = 0;
    int attack = 0;
    int defense = 0;
};

// ===== 第 1 问 =====
void Print(const Character& c) {
    cout << "【" << c.name << "】HP:" << c.hp
         << " ATK:" << c.attack << " DEF:" << c.defense << endl;
}

// ===== 第 2 问 =====
void Attack(Character& attacker, Character& defender) {
    int damage = attacker.attack - defender.defense;
    if (damage < 1) damage = 1;
    defender.hp -= damage;
    cout << attacker.name << " 造成 " << damage << " 点伤害" << endl;
}

// ===== 第 3 问 =====
void AutoBattle(Character& player, Character& enemy) {
    int round = 0;
    while (player.hp > 0 && enemy.hp > 0) {
        round++;
        cout << "\n=== 第 " << round << " 回合 ===" << endl;

        Attack(player, enemy);
        if (enemy.hp <= 0) {
            cout << player.name << " 获胜！" << endl;
            break;
        }

        Attack(enemy, player);
        if (player.hp <= 0) {
            cout << enemy.name << " 获胜！" << endl;
            break;
        }

        Print(player);
        Print(enemy);
    }
}

// ===== 第 4 问 =====
Character* CreateEnemy(int level) {
    return new Character{
        "怪物 Lv." + to_string(level),
        50 + level * 10,
        10 + level * 3,
        level * 2
    };
}

// ===== 第 5 问 =====
void ReviewCode() {
    cout << "\n=== 代码审查 ===" << endl;
    cout << "问题1：player 是 const 指针，不能传给 Attack 的引用参数" << endl;
    cout << "问题2：没有检查 player 和 enemy 是否为 nullptr" << endl;
    cout << "问题3：敌人被打败后，循环又尝试让敌人攻击（逻辑顺序错误）" << endl;
}

// ===== main =====
int main() {
    Character player{"勇者", 100, 20, 5};
    Character enemy{"哥布林", 60, 12, 2};

    cout << "=== 第 1 问 ===" << endl;
    Print(player);
    Print(enemy);

    cout << "\n=== 第 2 问 ===" << endl;
    Attack(player, enemy);
    Print(enemy);

    cout << "\n=== 第 3 问 ===" << endl;
    player.hp = 100;
    enemy.hp = 60;
    AutoBattle(player, enemy);

    cout << "\n=== 第 4 问 ===" << endl;
    Character* boss = CreateEnemy(3);
    Print(*boss);
    delete boss;
    boss = nullptr;

    ReviewCode();
    return 0;
}
```
