# 综合练习：学生成绩统计

## 题目描述

编写一个程序，用结构体存储学生信息，实现以下功能：

1. 定义结构体 `Student`，包含：
   - `sno`（学号，字符串）
   - `name`（姓名，字符串）
   - `score`（成绩，浮点数）

2. 在 `main` 函数中：
   - 创建一个包含 **5 个学生** 的结构体数组，并**用列表初始化**赋初值（数据自定）
   - 编写一个函数 `void PrintStudents(const Student students[], int count)`，打印所有学生的信息
   - 编写一个函数 `double AverageScore(const Student students[], int count)`，计算并返回所有学生的平均分
   - 编写一个函数 `Student FindHighest(const Student students[], int count)`，返回成绩最高的学生
   - 在 `main` 中调用以上三个函数，输出：
     - 所有学生信息
     - 平均分
     - 最高分学生的姓名和成绩

## 示例输出

```
=== 学生信息 ===
2024001  Alice  95.5
2024002  Bob    88.0
2024003  Charlie 92.5
2024004  Diana  78.5
2024005  Eve    85.0

平均分：87.9

最高分：Alice（95.5）
```

---

## 参考答案

```cpp
#include <iostream>
#include <string>
using namespace std;

// 定义结构体
struct Student {
    string sno = "";
    string name = "";
    double score = 0.0;
};

// 打印所有学生信息
void PrintStudents(const Student students[], int count) {
    cout << "=== 学生信息 ===" << endl;
    for (int i = 0; i < count; i++) {
        cout << students[i].sno << "  "
             << students[i].name << "  "
             << students[i].score << endl;
    }
}

// 计算平均分
double AverageScore(const Student students[], int count) {
    double sum = 0.0;
    for (int i = 0; i < count; i++) {
        sum += students[i].score;
    }
    return sum / count;
}

// 查找最高分学生
Student FindHighest(const Student students[], int count) {
    int maxIndex = 0;
    for (int i = 1; i < count; i++) {
        if (students[i].score > students[maxIndex].score) {
            maxIndex = i;
        }
    }
    return students[maxIndex];  // 返回整个结构体
}

int main() {
    // 列表初始化结构体数组
    Student students[5] = {
        {"2024001", "Alice", 95.5},
        {"2024002", "Bob", 88.0},
        {"2024003", "Charlie", 92.5},
        {"2024004", "Diana", 78.5},
        {"2024005", "Eve", 85.0}
    };

    // 1. 打印所有学生信息
    PrintStudents(students, 5);

    // 2. 计算并输出平均分
    double avg = AverageScore(students, 5);
    cout << "\n平均分：" << avg << endl;

    // 3. 查找并输出最高分学生
    Student top = FindHighest(students, 5);
    cout << "\n最高分：" << top.name << "（" << top.score << "）" << endl;

    return 0;
}
```
