# 课堂练习：打印不同类型的数据

> **目标**：练习定义带参数的函数，并感受“功能相同但参数类型不同”时带来的不便。

## 任务

编写三个函数，分别用于打印 `int`、`double` 和 `string` 类型的数据，并加上一段描述文字，格式为 `"数据：xxx"`。

例如，打印整数 `42` 时输出：

```
数据：42
```

## 具体要求

1. 定义一个函数，用于打印 `int` 类型的值。
2. 定义一个函数，用于打印 `double` 类型的值。
3. 定义一个函数，用于打印 `string` 类型的值。
4. 每个函数都接收一个参数（对应的类型），并在函数内部输出 `"数据：" + 参数值`。
5. 在 `main` 函数中依次调用这三个函数，分别传入：
   - 整数 `42`
   - 浮点数 `3.14`
   - 字符串 `"Hello"`

## 示例输出

```
数据：42
数据：3.14
数据：Hello
```

## 思考

完成以上代码后，请思考以下问题：

1. 这三个函数的功能是什么？它们之间有什么共同点？
2. 这三个函数的名字分别是什么？它们有什么不同？
3. 如果将来还需要打印 `char`、`bool` 等其他类型，需要怎么做？
4. 这些函数的功能相同，但函数名却不同，你觉得这样有什么不方便的地方吗？

---

## 参考答案

```cpp
#include <iostream>
#include <string>
using namespace std;

// 打印 int 类型的数据
void PrintInt(int value) {
    cout << "数据：" << value << endl;
}

// 打印 double 类型的数据
void PrintDouble(double value) {
    cout << "数据：" << value << endl;
}

// 打印 string 类型的数据
void PrintString(string value) {
    cout << "数据：" << value << endl;
}

int main() {
    PrintInt(42);
    PrintDouble(3.14);
    PrintString("Hello");
    return 0;
}
```
