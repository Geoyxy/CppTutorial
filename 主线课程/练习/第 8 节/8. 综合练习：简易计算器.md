# 综合练习：简易计算器

## 题目描述

编写一个计算器程序，将加减乘除功能封装成函数，通过菜单循环调用。

### 一、需要实现的函数

#### 1. `int Add(int a, int b)` 及其 double 类型的重载
- 返回 `a + b`

#### 2. `int Sub(int a, int b)` 及其 double 类型的重载
- 返回 `a - b`

#### 3. `int Mul(int a, int b)` 及其 double 类型的重载
- 返回 `a * b`

#### 4. `double Div(int a, int b)` 及其 double 类型的重载
- 返回 `a / b`
- 如果 `b == 0`，打印 `"除数不能为0"` 并返回 `0`

#### 5. `void ShowMenu()`
- 打印菜单，无返回值

### 二、主程序逻辑

1. 显示菜单：
```
=== 简易计算器 ===
1. 加法
2. 减法
3. 乘法
4. 除法
5. 退出
请选择（1-5）：
```

2. 用户选择 1~4 时，输入两个整数，调用对应函数并输出结果
3. 选择 5 时退出程序
4. 输入无效时提示 `"无效输入"`

### 三、运行示例

```
=== 简易计算器 ===
1. 加法
2. 减法
3. 乘法
4. 除法
5. 退出
请选择（1-5）：1
请输入两个整数：10 3
10 + 3 = 13

=== 简易计算器 ===
1. 加法
2. 减法
3. 乘法
4. 除法
5. 退出
请选择（1-5）：4
请输入两个整数：10 0
除数不能为0
10 / 0 = 0

=== 简易计算器 ===
1. 加法
2. 减法
3. 乘法
4. 除法
5. 退出
请选择（1-5）：5
程序已退出
```

### 四、要求

1. 加减乘除各封装成一个独立函数
2. 函数命名采用大驼峰（PascalCase）
3. 可以含其他函数（例如输入合法性检查）

## 参考答案

```cpp
#include <iostream>
using namespace std;

// ==================== 函数声明 ====================

int Add(int a, int b);
double Add(double a, double b);

int Sub(int a, int b);
double Sub(double a, double b);

int Mul(int a, int b);
double Mul(double a, double b);

double Div(int a, int b);
double Div(double a, double b);

void ShowMenu();
void ProcessChoice(int choice);

// ==================== 函数定义 ====================

// 加法（int 版本）
int Add(int a, int b) {
    return a + b;
}

// 加法（double 版本）
double Add(double a, double b) {
    return a + b;
}

// 减法（int 版本）
int Sub(int a, int b) {
    return a - b;
}

// 减法（double 版本）
double Sub(double a, double b) {
    return a - b;
}

// 乘法（int 版本）
int Mul(int a, int b) {
    return a * b;
}

// 乘法（double 版本）
double Mul(double a, double b) {
    return a * b;
}

// 除法（int 版本）
double Div(int a, int b) {
    if (b == 0) {
        cout << "除数不能为0" << endl;
        return 0;
    }
    // 将 int 转为 double 再计算，保留小数部分
    return (double)a / b;
}

// 除法（double 版本）
double Div(double a, double b) {
    if (b == 0.0) {
        cout << "除数不能为0" << endl;
        return 0.0;
    }
    return a / b;
}

// 显示菜单
void ShowMenu() {
    cout << "\n=== 简易计算器 ===" << endl;
    cout << "1. 加法" << endl;
    cout << "2. 减法" << endl;
    cout << "3. 乘法" << endl;
    cout << "4. 除法" << endl;
    cout << "5. 退出" << endl;
    cout << "请选择（1-5）：";
}

// 处理用户选择
void ProcessChoice(int choice) {
    if (choice == 5) {
        cout << "程序已退出" << endl;
        return;
    }

    double a, b;
    cout << "请输入两个数：";
    cin >> a >> b;

    if (choice == 1) {
        cout << a << " + " << b << " = " << Add(a, b) << endl;
    } else if (choice == 2) {
        cout << a << " - " << b << " = " << Sub(a, b) << endl;
    } else if (choice == 3) {
        cout << a << " * " << b << " = " << Mul(a, b) << endl;
    } else if (choice == 4) {
        cout << a << " / " << b << " = " << Div(a, b) << endl;
    } else {
        cout << "无效输入" << endl;
    }
}

// ==================== 主函数 ====================

int main() {
    int choice;

    while (true) {
        ShowMenu();
        cin >> choice;

        if (choice == 5) {
            cout << "程序已退出" << endl;
            break;
        }

        ProcessChoice(choice);
    }

    return 0;
}
```
