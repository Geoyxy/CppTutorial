# 课堂练习：数组与指针

##  提示

**数组名是指向首元素的 const pointer。**

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;   // p 指向 arr[0]
```

## 编写程序

定义：

1. 一个长度为 `5` 的 `int` 类型数组 `arr`，元素值分别为 `10, 20, 30, 40, 50`。

然后按以下要求操作：

1. 定义指针 `p` 指向数组 `arr`。
2. 通过**下标**输出 `arr[3]`。
3. 通过**指针运算 + 解引用**输出 `arr[3]`。
4. 通过指针 `p` 遍历数组，依次修改每个元素为原来的 **2 倍**（即 `10→20, 20→40, ...`）。
5. 再次遍历数组，输出修改后的所有元素。

**思考题：**  

1. `arr` 和 `&arr[0]` 的值是否相同？它们表示什么含义？
2. 如果用 `sizeof(arr)` 和 `sizeof(p)`，输出的值会相同吗？为什么？


---

## 参考答案

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    // 1. 指针指向数组
    int* p = arr;

    // 2. 下标访问
    cout << "arr[3] = " << arr[3] << endl;   // 40

    // 3. 指针运算访问
    cout << "*(arr + 3) = " << *(arr + 3) << endl;   // 40

    // 4. 指针遍历并翻倍
    for (int i = 0; i < 5; i++) {
        *(p + i) = *(p + i) * 2;
    }

    // 5. 输出修改后的数组
    cout << "修改后的数组：";
    for (int i = 0; i < 5; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```
