# 课堂练习：指针与内存

##  内存模型参考

```
内存地址（门牌号）        存储的数据（住户）
        ┌─────────────┐
0x1000  │    10       │  ← 变量 a 存在这里
        ├─────────────┤
0x1004  │    42       │  ← 变量 b 存在这里
        ├─────────────┤
0x1008  │   3.14      │  ← 变量 c 存在这里
        ├─────────────┤
0x100C  │             │
        └─────────────┘
```

---

## 编写程序

定义：

1. 一个长度为 2 的 `int` 类型数组 `arr` ，元素的值分别为 `10`, `20`。
2. 一个 `double` 类型变量 `n` 。

然后按以下要求操作：

1. 定义指针 `ptr_arr0`, `ptr_arr1`, `ptr_n`，分别指向对应的变量。
2. 通过指针 `ptr_arr0` 将 `arr[0]` 的值改为 `100`。
3. 通过各自的指针先后打印 `arr[0]`, `arr[1]`, `n` 的内存地址。

**思考题：**  

1. 如果 `ptr_arr0` 被赋值为 `nullptr`，还能通过它访问 `arr[0]` 吗？会发生什么？

---

## 参考答案

```cpp
#include <iostream>
using namespace std;

int main() {
    // 定义变量
    int arr[2] = { 10, 20 };
    double n = 3.14;

    // 1. 定义指针并指向对应的变量
    int* ptr_arr0 = &arr[0];
    int* ptr_arr1 = &arr[1];
    double* ptr_n = &n;

    // 2. 通过 ptr_arr0 将 arr[0] 的值改为 100
    *ptr_arr0 = 100;

    // 3. 通过各自的指针打印三个变量的内存地址
    cout << "arr[0] 的地址：" << ptr_arr0 << endl;
    cout << "arr[1] 的地址：" << ptr_arr1 << endl;
    cout << "n 的地址：" << ptr_n << endl;

    // 验证 arr[0] 是否成功修改
    cout << "修改后 arr[0] = " << arr[0] << endl;

    return 0;
}
```
