# 综合练习：塔防游戏 —— 防御塔类

> 本次练习综合了本章所学的：`const` 成员函数、`constexpr`、多文件编程、友元。


## 一、类设计

### 成员变量（私有）

| 变量名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `name_` | `string` | 塔的名称 |
| `level_` | `int` | 当前等级（1~3） |
| `attack_` | `int` | 攻击力 |
| `cooldown_` | `int` | 当前冷却剩余回合数 |

### 全局编译期常量

| 常量名 | 值 | 说明 |
| :--- | :--- | :--- |
| `kMaxLevel` | 3 | 最大等级 |
| `kBaseAttack` | 15 | 1 级基础攻击力 |

**攻击力公式**：`attack_ = kBaseAttack + (level_ - 1) * 10`

### 成员函数（公有）

| 函数 | 返回值 | 功能 |
| :--- | :--- | :--- |
| **构造函数** `Tower(const string& name)` | — | 初始化塔，`level_ = 1`，`cooldown_ = 0` |
| **`GetName`** | `string` | 返回塔名（`const`） |
| **`GetLevel`** | `int` | 返回等级（`const`） |
| **`GetAttack`** | `int` | 返回攻击力（`const`） |
| **`CanAttack`** | `bool` | `cooldown_ == 0`（`const`） |
| **`Upgrade`** | `bool` | 升级（成功返回 `true`，满级返回 `false`） |
| **`Attack`** | `int` | 攻击目标，返回伤害，重置 `cooldown_ = 2` |
| **`Update`** | `void` | 冷却减 1（不低于 0） |
| **`PrintStatus`** | `void` | 打印塔的状态（`const`） |

### 友元函数

- `bool operator==(const Tower& a, const Tower& b)`：名称和等级相同则相等


## 二、题目要求

### 第 1 问：多文件实现 `Tower` 类

将 `Tower` 类拆分成三个文件：

- `tower.h`：类声明、常量声明、友元声明
- `tower.cpp`：成员函数实现、友元实现
- `main.cpp`：测试代码

**要求**：
1. 所有成员变量为 `private`。
2. 使用 `constexpr` 定义全局常量。
3. 为只读函数添加 `const` 限定。
4. 构造函数使用**初始化列表**。
5. `Upgrade` 中更新攻击力。

### 第 2 问：测试（在 `main.cpp` 中完成）

1. 创建 `Tower t1("加农炮")`，打印初始状态。
2. 升级两次（每次升级后打印状态）。
3. 攻击一个血量 `100` 的目标：
   - 用循环模拟：每回合调用 `Update()`，如果 `CanAttack()` 则调用 `Attack()`，直到目标血量 ≤ 0
4. 用 `operator==` 判断 `t1` 和 `Tower("加农炮")` 是否相同。

## 三、参考答案


### tower.h

```cpp
#pragma once
#include <string>
using namespace std;

constexpr int kMaxLevel = 3;
constexpr int kBaseAttack = 15;

class Tower {
private:
    string name_;
    int level_;
    int attack_;
    int cooldown_;

public:
    Tower(const string& name);

    string GetName() const;
    int GetLevel() const;
    int GetAttack() const;
    bool CanAttack() const;

    bool Upgrade();
    int Attack(int& target_hp);
    void Update();
    void PrintStatus() const;

    friend bool operator==(const Tower& a, const Tower& b);
};
```

### tower.cpp

```cpp
#include "tower.h"
#include <iostream>
using namespace std;

Tower::Tower(const string& name)
    : name_(name), level_(1), attack_(kBaseAttack), cooldown_(0) {}

string Tower::GetName() const { return name_; }
int Tower::GetLevel() const { return level_; }
int Tower::GetAttack() const { return attack_; }
bool Tower::CanAttack() const { return cooldown_ == 0; }

bool Tower::Upgrade() {
    if (level_ >= kMaxLevel) {
        cout << name_ << " 已达最大等级！" << endl;
        return false;
    }
    level_++;
    attack_ = kBaseAttack + (level_ - 1) * 10;
    cooldown_ = 0;
    cout << name_ << " 升级到 " << level_ << " 级！" << endl;
    return true;
}

int Tower::Attack(int& target_hp) {
    if (target_hp <= 0) return 0;
    int damage = attack_;
    target_hp -= damage;
    if (target_hp < 0) target_hp = 0;
    cooldown_ = 2;
    cout << name_ << " 造成 " << damage << " 点伤害，剩余 HP：" << target_hp << endl;
    return damage;
}

void Tower::Update() {
    if (cooldown_ > 0) {
        cooldown_--;
    }
}

void Tower::PrintStatus() const {
    cout << "【" << name_ << "】Lv." << level_ << " ATK:" << attack_
         << " 冷却:" << cooldown_ << endl;
}

bool operator==(const Tower& a, const Tower& b) {
    return a.name_ == b.name_ && a.level_ == b.level_;
}
```

### main.cpp

```cpp
#include "tower.h"
#include <iostream>
using namespace std;

int main() {
    Tower t1("加农炮");
    t1.PrintStatus();

    t1.Upgrade();
    t1.PrintStatus();
    t1.Upgrade();
    t1.PrintStatus();

    cout << "\n--- 攻击目标 ---" << endl;
    int hp = 100;
    int round = 0;
    while (hp > 0) {
        round++;
        t1.Update();
        if (t1.CanAttack()) {
            t1.Attack(hp);
        }
        cout << "第 " << round << " 回合结束" << endl;
    }

    cout << "\n--- 友元测试 ---" << endl;
    Tower t2("加农炮");
    cout << "t1 == t2：" << (t1 == t2 ? "相同" : "不同") << endl;

    return 0;
}
```
