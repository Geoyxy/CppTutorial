### 第 4 问：找错误

**错误 1：成员函数指针不能赋值给普通函数指针**

```cpp
void (*p)() = &Enemy::OnDeath;  // ❌ 类型不匹配
```

`&Enemy::OnDeath` 是成员函数指针类型 `void (Enemy::*)()`，而 `void (*)()` 是普通函数指针，两者不兼容。成员函数需要对象才能调用，普通函数不需要。

**正确写法**：

```cpp
void (Enemy::*p)() = &Enemy::OnDeath;
Enemy e;
(e.*p)();
```

---

**错误 2：不能通过基类指针访问派生类新增的成员变量**

```cpp
int offset = (int)&ptr->id_ - (int)ptr;
```

`ptr` 的类型是 `GameObject*`，只能访问 `GameObject` 中声明的成员。`id_` 是 `GameObject` 的成员，所以这个**实际上是对的**，可以访问。这是一个干扰项。但要注意：`ptr->id_` 通过基类指针访问基类成员是允许的，只要 `id_` 不是 `private`。

（此题中 `id_` 是 `public`，所以没问题。）

---

**错误 3：抽象类不能实例化**

```cpp
GameObject obj;
```

`GameObject` 有纯虚函数吗？看看类定义：`Update` 和 `Render` 都有实现体 `{ /* ... */ }`，不是 `= 0`。所以 `GameObject` **不是抽象类**，可以实例化。这也是一个干扰项。

---

**错误 4：基类指针不能直接赋值给派生类指针（向下转型不安全）**

```cpp
Enemy* p2 = ptr;  // ❌ 不能隐式转换
```

`GameObject*` 不能隐式转换为 `Enemy*`，因为 `ptr` 可能指向的不是 `Enemy` 对象。需要用 `dynamic_cast`：

```cpp
Enemy* p2 = dynamic_cast<Enemy*>(ptr);
if (p2 != nullptr) {
    // 安全使用
}
```

---

**本题实际错误只有 2 处？——是的，我故意混入了 2 个“看起来错但实际没错”的干扰项，考察你是否能准确判断。**

| 行号 | 是否正确 | 说明 |
| :--- | :--- | :--- |
| `void (*p)() = &Enemy::OnDeath;` | ❌ 错误 | 成员函数指针类型不匹配 |
| `int offset = (int)&ptr->id_ - (int)ptr;` | ✅ 正确 | 基类指针可以访问基类成员 |
| `GameObject obj;` | ✅ 正确 | 不是抽象类，可以实例化 |
| `Enemy* p2 = ptr;` | ❌ 错误 | 向下转型需要显式转换（`dynamic_cast`） |

**编译期**：

| 步骤 | 说明 |
| :--- | :--- |
| ① | 编译器为 `Base` 生成虚表，槽位 0 存 `Base::Func`，槽位 1 存 `Base::~Base` |
| ② | 编译器为 `Derived` 生成虚表，**复制** `Base` 的虚表，然后用 `Derived::Func` **覆盖**槽位 0，槽位 1 存 `Derived::~Derived` |
| ③ | 编译器看到 `ptr->Func()`，查询 `Base` 虚表布局，记录 `Func` 在**槽位 0** |
| ④ | 编译器检查赋值 `Base* ptr = &d;` 是否合法（`Derived` 是 `Base` 的派生类，合法） |

**运行期**：

| 步骤 | 说明 |
| :--- | :--- |
| ① | 构造 `Derived` 对象时，vptr 被设置为指向 `Derived` 的虚表 |
