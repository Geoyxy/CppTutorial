# 课堂练习：资源管理类（RAII + 深拷贝）

> 此练习综合了本节前 3 节的核心知识点：**析构函数、拷贝构造函数（深拷贝）、RAII**。请独立完成，不要看参考答案。

## 一、题目描述

实现一个 `IntArray` 类，它封装了一个动态 `int` 数组，并使用 RAII 管理堆内存。

### 需求

| 功能             | 说明                                                         |
| :------------- | :--------------------------------------------------------- |
| **构造函数**       | 接收一个 `int` 参数 `size`，分配 `size` 个 `int` 的堆内存，并将所有元素初始化为 `0` |
| **析构函数**       | 释放堆内存，并输出 `"资源已释放"`                                        |
| **拷贝构造函数**     | 实现**深拷贝**，复制整个数组的内容                                        |
| **`Set` 方法**   | `void Set(int index, int value)`：设置指定索引对应元素的值（假设索引有效）      |
| **`Get` 方法**   | `int Get(int index) const`：获取指定索引对应元素的值（假设索引有效）            |
| **`Print` 方法** | `void Print() const`：打印数组所有元素，格式为 `[1, 2, 3, 4, 5]`        |

### 在 `main` 中完成以下测试

1. 创建 `IntArray a(5)`，用 `Set` 设置值为 `10, 20, 30, 40, 50`，调用 `Print` 打印。
2. 用 `a` 拷贝构造 `IntArray b(a)`，调用 `b.Print()` 验证内容一致。
3. 修改 `a` 的某个元素，再次打印 `a` 和 `b`，验证深拷贝（`b` 不受影响）。

## 二、预期输出

```
a: [10, 20, 30, 40, 50]
b: [10, 20, 30, 40, 50]
修改 a[2] = 999
a: [10, 20, 999, 40, 50]
b: [10, 20, 30, 40, 50]
资源已释放
资源已释放
```

## 三、参考答案

```cpp
#include <iostream>
using namespace std;

class IntArray {
private:
    int* data_;
    int size_;

public:
    // 构造函数：分配资源
    IntArray(int size) : size_(size) {
        data_ = new int[size_];
        for (int i = 0; i < size_; i++) {
            data_[i] = 0;
        }
        cout << "构造 IntArray，大小：" << size_ << endl;
    }

    // 析构函数：释放资源
    ~IntArray() {
        delete[] data_;
        cout << "资源已释放" << endl;
    }

    // 拷贝构造函数：深拷贝
    IntArray(const IntArray& other) : size_(other.size_) {
        data_ = new int[size_];
        for (int i = 0; i < size_; i++) {
            data_[i] = other.data_[i];
        }
        cout << "深拷贝构造" << endl;
    }

    void Set(int index, int value) {
        if (index >= 0 && index < size_) {
            data_[index] = value;
        }
    }

    int Get(int index) const {
        if (index >= 0 && index < size_) {
            return data_[index];
        }
        return -1;
    }

    void Print() const {
        cout << "[";
        for (int i = 0; i < size_; i++) {
            cout << data_[i];
            if (i < size_ - 1) cout << ", ";
        }
        cout << "]" << endl;
    }
};

int main() {
    IntArray a(5);
    a.Set(0, 10);
    a.Set(1, 20);
    a.Set(2, 30);
    a.Set(3, 40);
    a.Set(4, 50);

    cout << "a: ";
    a.Print();

    IntArray b(a);  // 调用拷贝构造
    cout << "b: ";
    b.Print();

    cout << "修改 a[2] = 999" << endl;
    a.Set(2, 999);

    cout << "a: ";
    a.Print();
    cout << "b: ";
    b.Print();

    return 0;
}
```
