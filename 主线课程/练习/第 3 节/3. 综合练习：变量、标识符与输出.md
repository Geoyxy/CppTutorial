# 综合练习：变量、标识符与输出

> 练习 `int`、变量的定义与使用、标识符命名规则、`cout` 输出。

---

## 第 1 问：找错误

以下代码存在 **至少 5 处** 错误，请指出并说明原因。

```cpp
#include <iostream>
using namespace std;

int main()
{
	int 1st_player = 10;
	int player_hp;
	int PlayerScore = 100;
	int int = 50;
	int max_hp = 200
	int max_hp = 300;

	cout << "玩家血量：" << player_hp << endl；
	cout << "玩家分数：" << PlayerScore

	return 0;
}
```

**提示**：可以从「标识符命名规则」「关键字」「分号」「全半角字符」「重复定义」「初始化」这几个角度检查。

## 第 2 问：写程序

写一个程序，输出以下玩家信息：

```
=== 玩家信息 ===
名称: rover
等级: 1
血量: 100
攻击力: 25
```

**要求**：

1. 使用**变量**存储这四项数据（名称的数据类型是 `string`，它的值应该用 `""` 包围起来）。
2. 名称的变量命名为 `player_name`，等级为 `player_level`，血量为 `player_hp`，攻击力为 `player_attack`。
3. 定义时**顺便初始化**。
4. 用 `cout` 按上面的格式输出。

**提示**：`string` 类型需要 `#include <string>`。

## 参考答案

### 第 1 问

| 行号 | 错误代码 | 原因 |
| :--- | :--- | :--- |
| `int 1st_player = 10;` | 标识符以数字开头 | 标识符不能以数字开头 |
| `int int = 50;` | 使用了关键字 `int` | 关键字不能作为标识符 |
| `int max_hp = 200` | 末尾缺少分号 | 语句末尾必须有 `;` |
| `int max_hp = 300;` | 重复定义 | 同一作用域不能重复定义同名标识符 |
| `cout << ... << endl；` | 使用了中文分号 `；` | 语法结构必须用半角字符 |
| `cout << "玩家分数：" << PlayerScore` | 末尾缺少分号 | 语句末尾必须有 `;` |
| `int player_hp;` | 未初始化 | 使用前未初始化，会产生未定义行为（应初始化，如 `int player_hp = 0;`） |

> **注意**：`PlayerScore` 虽然是大驼峰命名（不符合本课程的 snake_case 风格），但**不违反语法规则**，程序能编译通过。命名风格是「风格问题」，不是「错误」。

### 第 2 问

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
	string player_name = "rover";
	int player_level = 1;
	int player_hp = 100;
	int player_attack = 25;

	cout << "=== 玩家信息 ===" << endl;
	cout << "名称: " << player_name << endl;
	cout << "等级: " << player_level << endl;
	cout << "血量: " << player_hp << endl;
	cout << "攻击力: " << player_attack << endl;

	return 0;
}
```

**预期输出**：

```
=== 玩家信息 ===
名称: rover
等级: 1
血量: 100
攻击力: 25
```
