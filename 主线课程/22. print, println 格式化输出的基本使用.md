
# std::print, std::println 格式化输出的基本使用

## 1. std::print 与 std::println 格式化输出

`std::print` 和 `std::println` 是 C++23 标准库中新增的**格式化输出函数**，定义在 `<print>` 头文件中。它们基于 C++20 的 `std::format` 格式化引擎，提供了更现代、更安全、更高效的文本输出方式。

```cpp
#include <print>    // C++23

std::println("Hello, World!");
std::print("Hello, {}!", "C++23");
```

输出：

```text
Hello, World!（注意这里有换行）
Hello, C++23!（注意这里没换行）
```

## 2. 与 printf / cout 的对比

| 特性 | `std::print` | `std::printf` | `std::cout` |
|------|--------------|---------------|-------------|
| 类型安全 | ✅ 编译期检查 | ❌ 格式字符串与参数不匹配时未定义行为 | ✅ 类型安全 |
| 性能 | 高（直接写入缓冲区） | 中等 | 默认较慢（但可优化） |
| 语法简洁性 | 高（`{}` 占位符） | 低（需要记忆格式说明符） | 中等（`<<` 链式调用） |
| 支持自定义类型 | ✅ 通过 `std::formatter` | ❌ | ✅ 通过 `operator<<` |
| 多语言支持 | 困难（格式字符串固定） | 困难 | 困难 |
| 自动换行 | `println()` 提供 | ❌ 需手动 `\n` | ❌ 需手动 `\n` |
| Unicode 支持 | 好（依赖编译器和终端） | 一般 | 好 |
| 编译时格式检查 | ✅ 格式字符串在编译期解析 | ❌ | 不适用 |
| 缓冲区控制 | `std::out` 默认带缓冲 | 默认带缓冲 | 默认带缓冲 |

```cpp
// 传统 C 风格 - 类型不安全
printf("Value: %s", 42);   // 未定义行为

// C++ ostream 风格 - 冗长
std::cout << "Value: " << 42 << "\n";

// C++23 print - 简洁且安全
std::println("Value: {}", 42);
```

## 2. 基础用法

### 2.1 基本输出

```cpp
#include <print>

// 输出并换行
std::println("Hello, World!");

// 输出不换行
std::print("Hello, ");
std::print("World!");

// 空行
std::println();
```

输出：

```text
Hello, World!
Hello, World!
（空行）
```

### 2.2. 占位符与参数

使用 `{}` 作为占位符，参数按顺序替换：

```cpp
std::println("{} + {} = {}", 1, 2, 3);     // "1 + 2 = 3"
std::println("{}, {}!", "Hello", "World"); // "Hello, World!"

// 索引占位符（可重复使用参数）
std::println("{0} {1} {0}", "a", "b");     // "a b a"
```

输出：

```text
1 + 2 = 3
Hello, World!
a b a
```

## 3. 替换域 Replacement Field

**替换域**指的是 `{...}`，`std::print` 使用与 `std::format` 相同的替换域语法。

### 3.1 基本语法

替换域：

```cpp
{[参数索引][:格式规约]}
```

参数索引（argument index）就是不为负数的整数。

格式规约（format specification）：

```cpp
:[[填充]对齐][符号][#][0][宽度][.精度][类型]
```

以上 `[]` 中的内容表示可选，比如：

```cpp
{参数索引}
{参数索引:类型}
{:填充对齐宽度} // 注意“填充”在嵌套[]内，所以要写“填充”就必须先写“对齐”
```

### 3.2 参数索引

对于：

```cpp
std::print("...", 参数0, 参数1, 参数2, ...); // 可以有无限多个参数
```

`{n}` 表示将 `参数n` 隐式转换为字符串类型并替换 `{n}`：

```cpp
std::print("{2} {0} {0} {1}", 3, "yes", 'c'); // 输出：c 3 3 yes 
```

> [!WARNING] **注意**：不要混合使用有参数索引和无参数索引
> ```cpp
> // ❌ 错误：有无索引不能混用不能混用
> std::println("{} {1}", "a", "b");   // 编译错误！
> 
> // ✅ 正确：全部有索引
> std::println("{0} {1}", "a", "b");  // "a b"
> 
> // ✅ 正确：全部无索引
> std::println("{} {}", "a", "b");    // "a b"
> ```

### 3.3 格式规约

**格式规约**就是冒号 `:` 后面的部分，控制**如何显示**替换的内容。

```cpp
[[填充]对齐][符号][#][0][宽度][.精度][类型]
```

#### 3.3.1 宽度

宽度指的是字符的数量，若：

1. 指定的实参的字符数量 > 宽度，则无视宽度规则。
2. 指定的实参的字符数量 < 宽度，则用空格 ` ` 填充。

（为了使效果更直观，以下输出的空格均用 `*` 代替）

```cpp
std::print("{:3}, {:5}", 1, 3.14);    // 输出：**3, *3.14
std::print("{:5}, {:5}", "2", "123"); // 输出：****2, 123**，字符串默认左对齐
```

#### 3.3.2 精度

精度指的是输出的精细程度，比如小数部分的位数，精度的效果因类型而异：

(对于类型 `f`, `e`, `E`, `g`, `G`, `s`，这里仅先了解有这么些类型)

| 类型                  | 精度的含义           |
| ------------------- | --------------- |
| 浮点数 (`f`, `e`, `E`) | 小数点后位数          |
| 浮点数 (`g`, `G`)      | 有效数字位数          |
| 字符串 (`s` 或默认)       | 最大输出字符数（截断）     |
| 整数                  | **不支持精度**（编译错误） |

```cpp
std::println("{:.3s}", "hello"); // 输出：hel
std::println("{:.3f}, {:.3f}", 0.1, 1.2366); // 输出 0.100, 1.237
```

> **注意**：浮点数因为精度而截取时是用的是四舍五入。

#### 1.3.2 整数格式

| 说明符 | 含义 | 示例 | 输出 |
|--------|------|------|------|
| 无 | 默认十进制 | `std::println("{:d}", 42)` | `42` |
| `b` | 二进制 | `std::println("{:b}", 42)` | `101010` |
| `B` | 二进制（带前缀） | `std::println("{:#B}", 42)` | `0B101010` |
| `o` | 八进制 | `std::println("{:o}", 42)` | `52` |
| `x` | 十六进制（小写） | `std::println("{:x}", 42)` | `2a` |
| `X` | 十六进制（大写） | `std::println("{:X}", 42)` | `2A` |
| `#` | 添加前缀 | `std::println("{:#x}", 42)` | `0x2a` |

```cpp
std::println("dec: {}", 42);        // "dec: 42"
std::println("hex: {:x}", 42);      // "hex: 2a"
std::println("HEX: {:X}", 42);      // "HEX: 2A"
std::println("bin: {:b}", 42);      // "bin: 101010"
std::println("oct: {:o}", 42);      // "oct: 52"
std::println("with prefix: {:#X}", 42); // "with prefix: 0X2A"
```

#### 1.3.3 浮点数格式

| 说明符 | 含义 | 示例 | 输出 |
|--------|------|------|------|
| 无 | 默认（最短表示） | `std::println("{:}", 3.14)` | `3.14` |
| `f` | 固定小数 | `std::println("{:.2f}", 3.14159)` | `3.14` |
| `e` | 科学计数法（小写） | `std::println("{:e}", 3.14)` | `3.140000e+00` |
| `E` | 科学计数法（大写） | `std::println("{:E}", 3.14)` | `3.140000E+00` |
| `g` | 通用（自动选择） | `std::println("{:g}", 3.14)` | `3.14` |
| `a` | 十六进制浮点 | `std::println("{:a}", 3.14)` | `0x1.91eb86p+1` |

```cpp
std::println("{:.2f}", 3.14159);    // "3.14"
std::println("{:.3f}", 3.14159);    // "3.142"（四舍五入）
std::println("{:e}", 12345.67);     // "1.234567e+04"
std::println("{:.2e}", 12345.67);   // "1.23e+04"
std::println("{:g}", 0.0001234);    // "0.0001234"（自动选择）
```

#### 1.3.4 字符串格式

| 说明符 | 含义 | 示例 | 输出 |
|--------|------|------|------|
| 无 | 原样输出 | `std::println("{}", "hello")` | `hello` |
| `s` | 字符串（默认） | `std::println("{:s}", "hello")` | `hello` |
| 宽度与填充 | 指定最小宽度 | `std::println("{:10}", "hi")` | `"hi        "` |
| 左/右/中对齐 | `<`, `>`, `^` | `std::println("{:^10}", "hi")` | `"    hi    "` |

```cpp
std::println("{:10}", "hi");        // "hi        "（右对齐，默认）
std::println("{:<10}", "hi");       // "hi        "（左对齐）
std::println("{:>10}", "hi");       // "        hi"（右对齐）
std::println("{:^10}", "hi");       // "    hi    "（居中对齐）
std::println("{:*^10}", "hi");      // "****hi****"（填充）
```

#### 1.3.5 宽度、精度与对齐

（为了使效果更直观，以下输出的空格均用 `*` 代替）

```cpp
// 宽度
std::println("{:5}", 42);           // "***42"（默认右对齐）
std::println("{:<5}", 42);          // "42***"（左对齐）
std::println("{:05}", 42);          // "00042"（0填充）

// 精度（浮点数）
std::println("{:.2f}", 3.14159);    // "3.14"

// 宽度 + 精度
std::println("{:8.2f}", 3.14159);   // "    3.14"

// 动态宽度/精度
int width = 10;
int precision = 3;
std::println("{:{}.{}f}", 3.14159, width, precision); // "     3.142"
```

### 1.4 多参数与复杂输出

```cpp
// 多个参数
std::println("Name: {}, Age: {}, Score: {:.2f}", "Alice", 25, 95.5);
// "Name: Alice, Age: 25, Score: 95.50"

// 索引占位符
std::println("{1} is {0} years old", 25, "Bob");    // "Bob is 25 years old"
std::println("{0} + {0} = {1}", 2, 4);              // "2 + 2 = 4"

// 嵌套格式化（打印容器）
std::vector<int> v = {1, 2, 3};
std::println("{}", fmt::join(v, ", "));  // "1, 2, 3"（需要 fmt 库或 C++23 的 std::print 支持）
```

> [!WARNING]
> `std::print` 目前**不直接支持**打印容器（如 `std::vector`）。需要配合 `std::format` 的自定义格式化器，或使用第三方库如 `fmt`。C++26 可能加入更完善的容器支持。

### 1.5 与 `std::format` 的关系

`std::print` 本质上是 `std::format` 的输出版本：

```cpp
#include <print>
#include <format>

// std::format 返回字符串
std::string msg = std::format("Value: {}", 42);
std::println("{}", msg);    // 等价于下面

// std::print 直接输出
std::println("Value: {}", 42);
```

| 函数 | 作用 | 返回值 |
|------|------|--------|
| `std::format` | 格式化字符串 | `std::string` |
| `std::format_to` | 格式化到迭代器 | 输出迭代器 |
| `std::print` | 格式化并输出到 `stdout` | `void` |
| `std::println` | 格式化并输出到 `stdout`（追加换行） | `void` |
| `std::vprint` | 使用 `std::format_args` 输出（非类型安全版本） | `void` |

### 1.6 错误处理

与 `std::format` 相同，格式字符串在**编译期**检查：

```cpp
// ✅ 编译通过 - 类型匹配
std::println("{}", 42);

// ❌ 编译错误 - 参数数量不匹配
std::println("{} {}", 42);    // 编译错误：参数不足

// ❌ 编译错误 - 格式说明符与类型不匹配
std::println("{:f}", 42);     // 编译错误：整数不能用浮点数格式
```

> [!NOTE]
> 格式字符串的检查发生在**编译期**，这意味着不会出现 `printf` 那种运行时崩溃或未定义行为。异常只会发生在动态内容（如 `std::format` 传入错误的参数类型，但通常也是编译期检查）。

### 1.7 性能考虑

`std::print` 的设计目标之一就是高性能：

```cpp
#include <print>
#include <chrono>

// 比 cout 更高效（直接写入缓冲区，减少虚函数调用）
auto start = std::chrono::steady_clock::now();
for (int i = 0; i < 100000; ++i) {
    std::println("{}", i);    // 高效
}
auto end = std::chrono::steady_clock::now();
```

> [!TIP]
> `std::print` 内部直接操作 `stdout` 缓冲区，避免了 `std::cout` 的虚函数调用和同步开销。但实际性能提升依赖于实现，通常比 `std::cout` 快，但可能与 `printf` 相当或略快。

## 2. 常用函数速查表

| 函数                               | 头文件        | 说明                       | 示例                                       |
| -------------------------------- | ---------- | ------------------------ | ---------------------------------------- |
| `std::print(args...)`            | `<print>`  | 格式化输出（不换行）               | `std::print("x = {}", 5);`               |
| `std::println(args...)`          | `<print>`  | 格式化输出（换行）                | `std::println("x = {}", 5);`             |
| `std::println()`                 | `<print>`  | 仅输出换行                    | `std::println();`                        |
| `std::print(stream, args...)`    | `<print>`  | 输出到指定流（不换行）              | `std::print(std::cerr, "err");`          |
| `std::println(stream, args...)`  | `<print>`  | 输出到指定流（换行）               | `std::println(std::cerr, "err");`        |
| `std::format(args...)`           | `<format>` | 格式化到字符串                  | `std::string s = std::format("{}", 42);` |
| `std::vprint(stream, fmt, args)` | `<print>`  | 使用 `std::format_args` 输出 | （高级用法，略）                                 |

## 3. 与 C++20 / C++17 的兼容性

如果编译器不支持 C++23，可使用第三方库 `{fmt}`：

```cpp
#include <fmt/core.h>   // fmt 库

fmt::print("Hello, {}!\n", "C++20");    // 与 std::print 语法相同
fmt::println("Hello, {}!", "C++20");    // C++20 可用（fmt 库提供）
```

`{fmt}` 库是 `std::format` 和 `std::print` 的原型实现，API 基本一致。

|--------|----------|----------|
| GCC | 14+ | 完整支持 `<print>` |

### 4.2 常见问题

```cpp
// ❌ 错误：不支持直接打印容器
std::vector<int> v = {1, 2, 3};
std::println("{}", v);     // 编译错误：没有为 vector 定义的 formatter

// ✅ 正确：自定义格式化（需要自己实现 std::formatter）
// 或使用第三方库如 fmt::join

// ❌ 错误：与 C 风格 printf 混合使用时注意缓冲区
std::print("Hello");
printf(" World");          // 输出顺序可能不确定（缓冲区不同）

// ✅ 正确：统一使用 std::print
std::print("Hello");
std::print(" World");      // "Hello World"

// ❌ 错误：格式字符串不匹配
std::println("{:.2f}", "hello");    // 编译错误：类型不匹配
```

### 4.3 何时使用 `std::print` vs `std::cout`

| 场景 | 推荐 |
|------|------|
| 新代码（C++23 可用） | `std::print` / `std::println` |
| 需要兼容 C++20 或更早 | `std::cout` 或 `fmt` 库 |
| 需要格式化复杂对象 | 自定义 `std::formatter` 或重载 `operator<<` |
| 需要输出到 `std::ostringstream` | `std::format` + 流，或继续使用 `std::cout` |
| 性能要求高 | `std::print`（通常比 `std::cout` 快） |
