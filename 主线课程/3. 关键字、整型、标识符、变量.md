# 整型、标识符、变量

## 1. 关键字

**关键字**（Keyword）是 C++ 语言中**预先定义**的、具有**特殊含义**的标识符。它们构成了 C++ 语法的基础，**不能**被用作变量名、函数名、类名等普通标识符。

例如我们之前接触到的 `using` `namespace` `return`

---

## 2. 整型

整型是一种数据类型，对应数学中的整数。最常用的整型变量的关键字为 `int` 。`int` 数据类型一般为 4 字节（Byte）大小，取值范围 $-2,147,483,648$ ~ $2,147,483,647$ 即 $-2^{31}$ ~ $2^{31} - 1$ 。

---

## 3. 变量和标识符

### 3.1 变量的基本概念

**变量**（Variable）是程序中的**基本存储单元**，用于在内存中存储数据。变量有三个核心要素：

| 要素       | 说明             | 示例                      |
| -------- | -------------- | ----------------------- |
| **变量名**  | 变量的标识符，用于引用数据  | `age`、`score`、`name`    |
| **数据类型** | 决定变量存储的数据类型和大小 | `int`、`double`、`string` |
| **值**    | 变量实际存储的数据      | `25`、`3.14`、`"Hello"`   |

### 3.2 语法

在 C++ 中，声明和定义变量的语法分别为：

声明：

```
数据类型 标识符(即变量名);
```

定义：

```
数据类型 标识符(即变量名) = 值；
```

例如：

```cpp
// 声明一个叫 val 的变量
int val;

// 定义一个叫 num 的变量
int num = 114514;
```

| 概念     | 含义                       | 分配内存？ | 可多次出现？             |
| ------ | ------------------------ | ----- | ------------------ |
| **声明** | 告诉编译器**存在**某个名字和类型       | ❌ 不分配 | ✅ 可以多次             |
| **定义** | 告诉编译器**创建**某个实体（分配内存/实现） | ✅ 分配  | ❌ 只能一次（单一定义规则 ODR） |

### 3.3 标识符的命名

**标识符**（Identifier）是程序中用来命名**变量**、**函数**、**类**、**结构体**、**枚举**等实体的名称。

命名的规则如下：

1. 不能以数字开头，例如 `int 3val` 错误。
2. “只能”（部分编译器支持更多字符，但为了兼容性，这里用“只能”）包含英文字母 a~z A~Z、数字0~9、下划线 _ 这三种字符，例如`student3_score` 。
3. 不能以双下划线 __ 或 单下划线 + 大写字母 开头，例如 `__val` `_Val` 错误。

### 3.4 注意事项

#### 3.4.1 声明后（在同一作用域内）不能再声明或定义

```cpp
int val; // 声明变量 val

int val; // ❌ 编译错误，val 标识符已被声明
int val = 0; // ❌ 编译错误，val 标识符已被声明

// 如果要再对 val 进行赋值，应该直接用赋值运算符：
val = 0; // ✅
```

#### 3.4.2 变量名（标识符）不能为关键字或已存在的标识符

```cpp
int return = 0; // ❌ 编译错误，return 是关键字，不能作为

struct Person {...}; // 定义了一个结构 Person，Person 是标识符

int Person; // ❌ 编译错误，Person 标识符已被声明
```

#### 3.4.3 声明时尽量初始化

初始化变量的意思是给变量赋初始值，例如：

```cpp
int val = 0; // 给 val 变量赋初始值为 0
```

如果使用没有被赋值的变量，可能会导致 **未定义行为**。

>[!WARNING] 未定义行为（Undefined Behavior，简称 UB）
>
>**未定义行为**是指 C++ 标准**没有规定**程序应该如何处理的情况。发生 UB 时，编译器**不做任何保证**，程序可能：
>
>- ✅ 看起来“正常工作”
>- ❌ 崩溃（段错误）
>- ❌ 输出错误结果
>- ❌ 行为随机（每次运行不同）
>- ❌ 出现安全漏洞
>- ❌ 时空回溯（时间旅行 bug）
>
>未定义行为是 C++ 中**很危险**的情况。也是常见的运行时错误来源，难以调错（debug），应通过防御性编程等手段极力避免 UB。  

例如：

```cpp
int score; // 声明了一个变量 score（分数），没有赋初始值

int new_score = score + 1; // 使用了未初始化的变量，程序出现 未定义行为
```

# 4. 补充

对于整型，若存储的值超过取值范围的最大值则会变成取值范围的最小值，例如：

```cpp
int val = 2147483647;

val = val + 1; // 此时 val = -2147483648
```

反之亦然：

```cpp
int val = -2147483648;

val = val - 1; // 此时 val = 2147483647
```

（注： `int` 的取值范围：$-2,147,483,648$ ~ $2,147,483,647$ ）
