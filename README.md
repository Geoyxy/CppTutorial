# C++ 教程

---

## 1. 这是什么教程？

这是一套**面向零基础**且**循序渐进**的 C++ 系统入门课程，同时也是一份文档式教程，以 Obsidian 笔记库的形式组织，配合 Visual Studio 2026 使用。

它不是一本“看完就完”的电子书，而是一个**持续更新的课程体系**：主线课程会从最基础的安装配置一路推进到 C++ 进阶内容（移动语义、STL、Lambda 等），分支课程则围绕主线中出现的重点、难点做深入展开。

整套教程的目标是：**让学习者不仅知道“怎么写”，还知道“为什么这么写”。**

---

## 2. 适合我吗？

**零基础学习者**：本教程从搭建开发环境开始，不要求任何编程经验。你只需要一台能装 Visual Studio 2026 的电脑，就可以从第 1 节开始，一步步写出自己的 C++ 程序。

**有其他语言经验的学习者**：如果你学过 C、Java、Python 等语言，可以通过前几章快速过渡到 C++，把主要精力放在 C++ 特有的概念上（如指针、引用、对象内存模型、RAII 等）。

**需要查阅特定知识点的开发者**：如果你已经会写 C++，但想深入某个主题（如多态、虚函数、constexpr、内存模型），可以按主线编号或分支课程的主题分类直接定位，不必从头读起。

## 3. 快速开始

1. **准备学习环境**：按照 [[快速上手 Obsidian.md]]（文件见根目录/快速开始/）或 [[快速上手 Obsidian.pdf]]（文件见根目录）完成学习环境配置。
2. **准备开发环境**：按照 [[1. 安装配置 Visual Studio 2026]]（文件见根目录/主线课程/）完成开发环境配置。
3. **按顺序学习**：从第 1 节开始，按主线编号顺序推进；遇到链接时，可以跳转到对应分支课程深入阅读。
4. **完成练习**：每学完一节，完成对应的课堂练习（学习中完成）和综合练习，巩固所学内容。

## 4. 我能学到什么？

学完本教程的主线内容，你将能够：

- **独立编写、编译、调试 C++ 程序**：从安装配置 Visual Studio 开始，掌握变量、运算符、分支、循环、数组、函数、结构体等基础语法，能写出完整可运行的控制台程序。
- **理解并使用指针、引用和动态内存**：掌握计算机存储模型、内存五区、生命周期、`new`/`delete`、悬空指针与野指针的成因，能安全地管理内存资源。
- **用面向对象的方式组织代码**：掌握类与对象、访问说明符、构造与析构、拷贝构造、RAII、运算符重载、继承、多态、虚函数、抽象类等核心机制，能设计出结构清晰、职责分明的类体系。
- **理解 C++ 的底层行为**：掌握对象内存模型、虚表与动态多态原理、构建过程、链接属性、`extern`/`inline`/`static` 的作用，知道代码在编译、链接、运行时发生了什么。
- **使用现代 C++ 的常用工具**：掌握 `const`/`constexpr`、命名空间、枚举、`std::string`、`std::print`/`std::println` 等特性，为学习 STL 和更现代的 C++ 打下基础。
- **为进阶主题做好准备**：主线会持续更新，后续将覆盖移动语义、STL、Lambda 等进阶内容；分支课程还会深入底层内存、数据结构与算法、工程实践等专题。

## 5. 我需要注意什么？

### 5.1 关于学习方式

==**不要跳过练习**==。C++ 的很多坑——未定义行为、悬空指针、内存泄漏、对象切片——只有在**亲手写代码**时才会真正暴露出来。教程中的课堂练习和综合练习**不是可选项**，而是理解知识点的**重要环节**。

==**不要只读不写**==。看懂代码和写出代码是两回事。建议每学完一节，至少**把示例代码亲手敲一遍**，再尝试自己改一改、跑一跑，观察输出是否符合预期。

==**不要死磕暂时看不懂的内容**==。教程中有一些概念（如对象内存模型、虚表、链接属性）会在不同章节反复出现，**第一次看不懂是正常的**。可以先标记，继续往后学，等学到相关章节时**再回头精读**。教程中大量使用了“链接”和“学习向导”，就是为这种回顾式学习准备的。

==**善用 AI 辅助学习**==。本教程是“**静态教程**”，受篇幅和更新节奏限制，难免有覆盖不到的知识点。当你遇到教程中没有涉及的概念、想验证自己的理解是否正确，或想快速了解某个语法点的更多用法时，可以向 AI 提问。

==**不要过度依赖 AI**==。AI 可以帮你快速找到答案，但它不能替代你自己理解和练习的过程——不要遇到问题第一反应就是问 AI，而不是先回顾教程、查资料、动手试。更合理的做法是先尝试自己解决，把 AI 当作验证或补充的“第二意见”，并且不要让 AI 替你写练习。

### 5.2 关于教程本身

**教程会持续更新**。主线会继续推进到移动语义、STL、Lambda 等进阶内容，分支课程也会不断补充新主题。如果你在阅读时发现某处链接指向尚不存在的笔记，说明该内容还在规划或编写中。

**教程不是 C++ 标准的完整复刻**。它以“**构建清晰、准确、可查阅的知识体系**”为目标组织内容，不会为了求全而堆砌冷门语法。如果你想查阅某个具体语法点的完整定义，建议配合 [cppreference](https://zh.cppreference.com/) 使用。

**教程中的代码以教学清晰为优先**。部分示例为了突出某个概念，会简化错误处理、省略边界检查，或在注释中说明“实际开发中不推荐这样写”。**阅读时请留意这些提示**，不要把教学代码直接当成工程代码使用。

**教程使用 Visual Studio 2026 和 Windows 平台**。“1. 安装配置 Visual Studio 2026” 一节基于 Windows 11 + Visual Studio Community 2026 编写。如果你使用其他操作系统或 IDE，部分步骤需要自行调整，但 C++ 语言本身的知识不受影响。

### 5.3 关于反馈与纠错

**发现错误请通过 `issue` 机制反馈**。教程中的笔记**采用审核工作流**，每篇笔记的 frontmatter 中都有 `受审状态` 标签。如果你在学习过程中发现错误、有疑问，或希望补充某个主题，可以在对应笔记中**标记 `#issue`，或在 [GitHub Issues](https://github.com/Geoyxy/CppTutorial/issues) **提出**。

### 5.4 关于分支课程

**分支课程可以独立阅读，但建议先看主线**。分支课程中的很多内容（如底层内存、数据结构与算法）以主线知识为基础。如果你直接跳到分支课程遇到看不懂的概念，建议先回到主线学习对应章节。

### 5.5 关于游戏开发线索

**不需要游戏开发经验**。教程以游戏开发为线索组织部分主线和练习，但游戏场景只是用来**让抽象的 C++ 概念变得具体可见**——比如用角色属性讲结构体，用技能系统讲继承和多态，用卡牌体系讲类设计。**你不需要预先了解任何游戏开发知识，也不会因为不熟悉游戏而影响对 C++ 本身的学习**。

**游戏场景是线索，不是目的**。教程的重点始终是 C++ 语言本身，游戏场景只是辅助理解的手段。如果你对游戏开发感兴趣，可以把它当作一个自然的起点；如果你不感兴趣，完全可以只关注其中的 C++ 知识。
