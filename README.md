# 课程总说明

---

## 1. 课程介绍

这是一套**面向零基础**且**循序渐进**的 C++ 系统入门课程，同时也是一份文档式教程，从开发环境搭建开始，覆盖语法基础、内存模型、面向对象编程到工程化基础，兼顾语法使用规则与底层原理讲解。

---

## 2. 前置要求

1. **编程经验**：本教程面向**零基础**学习者，会从搭建开发环境开始讲解。如果你已有其他语言（如 C、Java、Python）的经验，可以通过前几章快速过渡到 C++。
2. **学习方式**：内容按**由浅入深**的顺序组织，建议初学者按章节顺序学习。对于有经验的开发者，可利用**目录索引**直接查阅特定语法或特性（如“多态”、“智能指针”）。
3. **核心目标**：本教程致力于构建**清晰、准确、可查阅**的 C++ 知识体系。它既是一本**入门指南**，也是一份可随时翻阅的**语法参考**。
4. **面向场景**：
    - **自学**：提供完整的代码示例和关键概念讲解。
    - **课堂辅助**：配合高校 C++ 课程，作为课后复习和补充材料。
    - **工作查阅**：针对特定语法点或特性（如 `constexpr`、RAII），提供简洁的文档式说明。
