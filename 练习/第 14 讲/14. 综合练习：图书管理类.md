# 综合练习：图书管理类

> 本次练习综合了本章所学的：析构函数、拷贝构造函数（深拷贝）、转换构造函数、`explicit`、`this` 指针、运算符重载等知识点。

## 一、类设计

设计一个 `Book` 类，表示一本图书。图书包含以下信息：

- **书名**（`string title_`）
- **作者**（`string author_`）
- **出版年份**（`int year_`）
- **价格**（`double price_`）


## 二、题目要求

### 第 1 问：实现 `Book` 类的基本功能

1. **成员变量**：全部为 `private`。
2. **构造函数**：
   - 默认构造函数：书名 `"未知"`，作者 `"未知"`，年份 `2000`，价格 `0.0`。
   - 带参构造函数：使用**初始化列表**初始化所有成员。
   - 转换构造函数：支持从 `string` 隐式转换为 `Book`（书名设为该字符串，其他为默认值）。
   - 使用 `explicit` 禁止从 `int` 隐式转换为 `Book`。
3. **析构函数**：打印 `"《书名》被销毁"`（用于观察生命周期）。
4. **成员函数**：
   - `void Print() const`：打印图书信息，格式：`《书名》 作者：XXX，年份：XXXX，价格：¥XXX`
   - `string GetTitle() const`：返回书名。
   - `double GetPrice() const`：返回价格。

### 第 2 问：运算符重载

1. **`operator==`**（全局函数）：判断两本书是否相同（书名、作者、年份都相等）。
2. **`operator<`**（全局函数）：按**价格**比较两本书（价格低的更小）。
3. **`operator+`**（成员函数）：返回一本新书，书名为 `"《书名1》&《书名2》"`，作者为两人合作，年份取较新的，价格为两本书价格之和。

### 第 3 问：测试（在 `main` 中完成）

1. 创建三本书：
   - `book1`：`"C++ Primer"`，`"Lippman"`，`2012`，`99.0`
   - `book2`：`"Effective C++"`，`"Meyers"`，`2005`，`89.0`
   - `book3`：从字符串 `"Clean Code"` 隐式转换（观察转换构造函数的调用）
2. 打印三本书的信息。
3. 比较 `book1` 和 `book2` 是否相等，以及它们的价格大小关系。
4. 用 `book1 + book2` 创建 `book4`，打印 `book4` 的信息。
5. 检查是否可以从 `int` 隐式构造 `Book`（应被 `explicit` 阻止）。


## 三、提示

| 知识点             | 关键代码                                                                                    |
| :-------------- | :-------------------------------------------------------------------------------------- |
| 转换构造函数          | `Book(const string& title) : title_(title), author_("未知"), year_(2000), price_(0.0) {}` |
| `explicit`      | `explicit Book(int year);`（禁止从 int 隐式转换）                                                |
| 全局 `operator==` | `bool operator==(const Book& a, const Book& b)`                                         |
| 成员 `operator+`  | `Book operator+(const Book& other) const`                                               |


> [!TIP] 提示：`string` 类型作为转换构造函数的参数
> `string` 类型作为转换构造函数的参数时，实参不应该直接写字符串字面量，而是显示调用 `string` 的构造函数：
> 
> ```cpp
> Book book3 = string("Clean Code");
> ```
> 
> 因为字符串字面量本质是 `const char[]` 类型，有时候它会经过两次隐式转换：`const char[]` → `const char*` → `string`：
> 
>```cpp
>void func2(const string& str) { ... }
>// ⚠️ 隐式转换：const char[6] → const char* → string（临时对象）
>func2("Hello");  // 这是通过 string 的构造函数完成的
>```
>
>其中第一次转换是数组退化（标准转换），第二次转换是调用了 `string` 类的转换构造函数（用户自定义转换）。而 VS 的 MSVC 编译器不允许连续两次用户自定义转换，所以我们这里需要显式调用 `string` 类的构造函数，减少一次自定义转换。

## 四、参考答案

```cpp
#include <iostream>
#include <string>
using namespace std;

class Book {
private:
    string title_;
    string author_;
    int year_;
    double price_;

public:
    // 默认构造函数
    Book() : title_("未知"), author_("未知"), year_(2000), price_(0.0) {}

    // 带参构造函数（初始化列表）
    Book(const string& title, const string& author, int year, double price)
        : title_(title), author_(author), year_(year), price_(price) {}

    // 转换构造函数：从 string 隐式转换
    Book(const string& title)
        : title_(title), author_("未知"), year_(2000), price_(0.0) {}

    // explicit 禁止从 int 隐式转换
    explicit Book(int year)
        : title_("未知"), author_("未知"), year_(year), price_(0.0) {}

    // 析构函数
    ~Book() {
        cout << "《" << title_ << "》被销毁" << endl;
    }

    // 成员函数
    void Print() const {
        cout << "《" << title_ << "》 作者：" << author_
             << "，年份：" << year_ << "，价格：¥" << price_ << endl;
    }

    string GetTitle() const { return title_; }
    double GetPrice() const { return price_; }

    // 成员 operator+：组合两本书
    Book operator+(const Book& other) const {
        string combinedTitle = "《" + title_ + "》&《" + other.title_ + "》";
        string combinedAuthor = author_ + " & " + other.author_;
        int combinedYear = (year_ > other.year_) ? year_ : other.year_;
        double combinedPrice = price_ + other.price_;
        return Book(combinedTitle, combinedAuthor, combinedYear, combinedPrice);
    }
};

// ===== 全局运算符重载 =====

bool operator==(const Book& a, const Book& b) {
    return a.GetTitle() == b.GetTitle()
        && a.GetTitle() == b.GetTitle()  // 书名
        && a.GetTitle() == b.GetTitle(); // 作者
}

bool operator<(const Book& a, const Book& b) {
    return a.GetPrice() < b.GetPrice();
}

// ===== main =====

int main() {
    Book book1("C++ Primer", "Lippman", 2012, 99.0);
    Book book2("Effective C++", "Meyers", 2005, 89.0);
    Book book3 = string("Clean Code");  // 隐式调用转换构造函数

    cout << "=== 图书信息 ===" << endl;
    book1.Print();
    book2.Print();
    book3.Print();

    cout << "\n=== 比较 ===" << endl;
    cout << "book1 == book2: " << (book1 == book2 ? "相等" : "不相等") << endl;
    cout << "book1 < book2: " << (book1 < book2 ? "book1更便宜" : "book2更便宜") << endl;

    cout << "\n=== 组合 ===" << endl;
    Book book4 = book1 + book2;
    book4.Print();

    cout << "\n=== explicit 测试 ===" << endl;
    // Book book5 = 2020;  // ❌ 编译报错！explicit 禁止从 int 隐式转换
    // Book book6(2020);   // 此构造函数未定义，仅演示 explicit 用法

    cout << "\n=== 程序结束，观察析构顺序 ===" << endl;
    return 0;
}
```
