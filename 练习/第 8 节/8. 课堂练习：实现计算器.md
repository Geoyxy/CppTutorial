# 课堂练习：实现计算器

> **目的**：巩固函数的定义和 `return` 语句，并通过实践感受“没有参数”时的局限性，为下一章“参数列表”做铺垫。

## 任务

你需要编写一个程序，其中包含若干函数，用于完成以下计算：

1. 计算 `123 + 456` 的结果并输出。
2. 计算 `123 * 456` 的结果并输出。
3. 计算 `1 + 2`、`100 + 200`、`999 + 888` 的结果并分别输出。
4. 计算 `3 * 7`、`12 * 34` 的结果并分别输出。

## 要求

- 每个计算都必须通过**函数**来完成。
- 函数的**返回类型**和**返回值**必须匹配。
- 函数名应能清晰表达其功能。

## 思考

完成上述任务后，请思考以下问题：

- 如果要计算 `1000 + 2000`，需要额外做什么？
- 如果计算结果要由用户通过 `cin` 在程序运行时输入决定，当前的做法还能满足需求吗？
- 如果加法逻辑发生变化（例如改成加完后再加 1），需要修改几处代码？

---

## 答案

```cpp
#include <iostream>
using namespace std;

// 1. 计算 123 + 456
int Add123() {
    return 123 + 456;
}

// 2. 计算 123 * 456
int Multiply123() {
    return 123 * 456;
}

// 3. 三个加法函数
int Add1() {
    return 1 + 2;
}

int Add100() {
    return 100 + 200;
}

int Add999() {
    return 999 + 888;
}

// 4. 两个乘法函数
int Multiply3() {
    return 3 * 7;
}

int Multiply12() {
    return 12 * 34;
}

int main() {
    cout << "123 + 456 = " << Add123() << endl;
    cout << "123 * 456 = " << Multiply123() << endl;

    cout << "1 + 2 = " << Add1() << endl;
    cout << "100 + 200 = " << Add100() << endl;
    cout << "999 + 888 = " << Add999() << endl;

    cout << "3 * 7 = " << Multiply3() << endl;
    cout << "12 * 34 = " << Multiply12() << endl;

    return 0;
}
```
