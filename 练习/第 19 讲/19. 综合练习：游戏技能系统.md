# 综合练习：游戏技能系统

> 练习虚函数、`override`、抽象类和纯抽象类。

## 一、背景说明

你正在开发一款游戏，需要设计技能系统。所有技能都能**释放**和**冷却**，但不同技能的行为完全不同。

此外，有些技能附带**视觉特效**。

## 二、题目要求

| 函数 | 返回值 | 功能 |

### 第 2 问：具体技能 `Fireball`

`Fireball`（火球术）：

| 数据成员 | 类型 | 初始值 | 说明 |
| :--- | :--- | :--- | :--- |
| `cooldown_` | `int` | `0` | 当前冷却 |

| :--- | :--- |

## 三、参考实现

### skill.h

```cpp
#pragma once
#include <iostream>

class Skill {
public:
    virtual void Cast() = 0;
    virtual bool IsReady() const = 0;
    virtual int GetCooldown() const = 0;

    void PrintReady() const {
        std::cout << "技能就绪: " << (IsReady() ? "是" : "否") << std::endl;
    }

    virtual ~Skill() = default;
};
```

### fireball.h

```cpp
#pragma once
#include "skill.h"

class Fireball : public Skill {
private:
    int cooldown_;
    int max_cooldown_;

public:
    Fireball() : cooldown_(0), max_cooldown_(5) {}

    void Cast() override {
        if (IsReady()) {
            std::cout << "🔥 释放火球术！" << std::endl;
            cooldown_ = max_cooldown_;
        } else {
            std::cout << "火球术冷却中..." << std::endl;
        }
    }

    bool IsReady() const override {
        return cooldown_ == 0;
    }

    int GetCooldown() const override {
        return max_cooldown_;
    }

    void Update(int seconds) {
        cooldown_ -= seconds;
        if (cooldown_ < 0) cooldown_ = 0;
    }
};
```

### effects.h

```cpp
#pragma once
#include <iostream>

class VisualEffect {
public:
    virtual void PlayEffect() const = 0;
    virtual ~VisualEffect() = default;
};
```

### visual_fireball.h

```cpp
#pragma once
#include "fireball.h"
#include "effects.h"

class VisualFireball : public Fireball, public VisualEffect {
public:
    void PlayEffect() const override {
        std::cout << "✨ 火球特效！" << std::endl;
    }
};
```

### main.cpp

```cpp
#include "visual_fireball.h"

int main() {
    std::cout << "=== 火球术 ===" << std::endl;
    VisualFireball vf;

    vf.Cast();           // 释放
    vf.PrintReady();     // 就绪？否
    vf.PlayEffect();     // 特效

    std::cout << "\n等待 3 秒..." << std::endl;
    vf.Update(3);

    std::cout << "\n3 秒后：" << std::endl;
    vf.Cast();           // 还在冷却
    vf.PrintReady();

    return 0;
}
```
