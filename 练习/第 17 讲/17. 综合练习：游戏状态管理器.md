# 综合练习：游戏状态管理器

> 练习 `static`、命名空间、`enum class` 的核心用法。

## 一、文件结构

```
game/
├── game_state.h      # 状态管理
├── game_state.cpp
├── logger.h          # 日志工具
└── main.cpp
```

## 二、题目要求

### 第 1 问：状态枚举（`enum class` + 命名空间）

在 `game_state.h` 中：

1. 定义命名空间 `state`。
2. 在命名空间内定义有作用域枚举 `State`：
   - `kMenu`、`kPlaying`、`kPaused`、`kGameOver`
3. 声明 `extern State g_current;`（定义放在 `game_state.cpp`）
4. 声明 `const char* ToString(State s);`（在 `.cpp` 中实现）

### 第 2 问：日志工具（匿名命名空间）

在 `logger.h` 中：

1. 使用**匿名命名空间**定义：
   - `int s_log_count = 0;`
   - `void Log(const char* msg)`：打印 `[日志 #n] msg`
2. 在 `main.cpp` 和 `game_state.cpp` 中分别包含并调用 `Log`，验证 `s_log_count` 各自独立。

### 第 3 问：静态成员（类的 `static`）

在 `game_state.h` 中定义 `StateManager` 类：

| 静态成员 | 说明 |
| :--- | :--- |
| `static inline int s_transition_count = 0;` | 状态切换次数 |
| `static void SwitchTo(State new_state);` | 切换状态，次数+1，打印日志 |

**要求**：`SwitchTo` 中调用 `Log` 记录切换。

### 第 4 问：主程序

在 `main.cpp` 中：

1. 打印初始状态。
2. 依次切换到 `kPlaying` → `kPaused` → `kPlaying` → `kGameOver`。
3. 打印 `StateManager::s_transition_count`。

## 三、参考实现

### game_state.h

```cpp
#pragma once

namespace state {

enum class State {
    kMenu,
    kPlaying,
    kPaused,
    kGameOver
};

extern State g_current;
const char* ToString(State s);

class StateManager {
public:
    static inline int s_transition_count = 0;
    static void SwitchTo(State new_state);
};

}  // namespace state
```

### game_state.cpp

```cpp
#include "game_state.h"
#include "logger.h"

namespace state {

State g_current = State::kMenu;

const char* ToString(State s) {
    switch (s) {
        case State::kMenu:     return "菜单";
        case State::kPlaying:  return "游戏中";
        case State::kPaused:   return "暂停";
        case State::kGameOver: return "游戏结束";
        default:               return "未知";
    }
}

void StateManager::SwitchTo(State new_state) {
    if (g_current == new_state) return;
    Log("状态切换: ");
    Log(ToString(g_current));
    Log(" → ");
    Log(ToString(new_state));
    g_current = new_state;
    s_transition_count++;
}

}  // namespace state
```

### logger.h

```cpp
#pragma once
#include <iostream>

namespace {
    int s_log_count = 0;
    void Log(const char* msg) {
        s_log_count++;
        std::cout << "[日志 #" << s_log_count << "] " << msg << std::endl;
    }
}
```

### main.cpp

```cpp
#include "game_state.h"
#include "logger.h"

int main() {
    using namespace state;
    
    std::cout << "初始状态: " << ToString(g_current) << std::endl;
    
    StateManager::SwitchTo(State::kPlaying);
    StateManager::SwitchTo(State::kPaused);
    StateManager::SwitchTo(State::kPlaying);
    StateManager::SwitchTo(State::kGameOver);
    
    std::cout << "\n共切换 " << StateManager::s_transition_count << " 次" << std::endl;
    
    return 0;
}
```
