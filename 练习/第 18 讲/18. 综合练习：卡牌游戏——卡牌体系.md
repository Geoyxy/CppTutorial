# 综合练习：卡牌游戏——卡牌体系

> 练习 `public` 继承、构造/析构顺序、名字隐藏。

---

## 一、背景说明

你正在开发一款卡牌对战游戏。所有卡牌都有**共通属性**（名称、费用、稀有度）和**共通接口**（打出、显示信息）。不同卡牌类型（随从牌、法术牌）有**自己的行为**和**特有的属性**（随从有攻击力/血量，法术有效果描述）。

用继承来消除重复代码。

## 二、题目要求

## 三、参考实现

### card.h

```cpp
#pragma once
#include <iostream>
#include <string>

class Card {
protected:
    std::string name_;
    int cost_;
    std::string rarity_;

public:
    Card(const std::string& name, int cost, const std::string& rarity);
    void PrintInfo() const;
    virtual void Play() const;
    virtual ~Card() = default;
};
```

### card.cpp

```cpp
#include "card.h"

Card::Card(const std::string& name, int cost, const std::string& rarity)
    : name_(name), cost_(cost), rarity_(rarity) {}

void Card::PrintInfo() const {
    std::cout << "[" << rarity_ << "] " << name_ << " (费用: " << cost_ << ")" << std::endl;
}

void Card::Play() const {
    std::cout << "打出了一张卡牌" << std::endl;
}
```

### minion_card.h

```cpp
#pragma once
#include "card.h"

class MinionCard : public Card {
private:
    int attack_;
    int hp_;

public:
    MinionCard(const std::string& name, int cost, const std::string& rarity,
               int attack, int hp);
    void Play() const override;
    void TakeDamage(int dmg);
};
```

### minion_card.cpp

```cpp
#include "minion_card.h"

MinionCard::MinionCard(const std::string& name, int cost, const std::string& rarity,
                       int attack, int hp)
    : Card(name, cost, rarity), attack_(attack), hp_(hp) {
    std::cout << "随从牌 [" << name_ << "] 构造完成" << std::endl;
}

void MinionCard::Play() const {
    std::cout << "召唤了 " << name_ << "（" << attack_ << "/" << hp_ << "）" << std::endl;
}

void MinionCard::TakeDamage(int dmg) {
    hp_ -= dmg;
    if (hp_ < 0) hp_ = 0;
    std::cout << name_ << " 受到 " << dmg << " 点伤害，剩余血量：" << hp_ << std::endl;
}
```

### spell_card.h

```cpp
#pragma once
#include "card.h"

class SpellCard : public Card {
private:
    std::string effect_;

public:
    SpellCard(const std::string& name, int cost, const std::string& rarity,
              const std::string& effect);
    void Play() const override;
};
```

### spell_card.cpp

```cpp
#include "spell_card.h"

SpellCard::SpellCard(const std::string& name, int cost, const std::string& rarity,
                     const std::string& effect)
    : Card(name, cost, rarity), effect_(effect) {
    std::cout << "法术牌 [" << name_ << "] 构造完成" << std::endl;
}

void SpellCard::Play() const {
    std::cout << "释放法术：" << effect_ << std::endl;
}
```

### main.cpp

```cpp
#include "minion_card.h"
#include "spell_card.h"

int main() {
    std::cout << "=== 创建卡牌 ===" << std::endl;
    MinionCard boar("石牙野猪", 1, "普通", 1, 1);
    SpellCard fireball("火球术", 4, "稀有", "造成6点伤害");

    std::cout << "\n=== 打印信息 ===" << std::endl;
    boar.PrintInfo();
    fireball.PrintInfo();

    std::cout << "\n=== 打出卡牌 ===" << std::endl;
    boar.Play();
    fireball.Play();

    std::cout << "\n=== 随从受伤 ===" << std::endl;
    boar.TakeDamage(1);

    std::cout << "\n=== 传说卡牌 ===" << std::endl;
    MinionCard giant("熔岩巨人", 8, "传说", 8, 8);
    giant.PrintInfo();

    std::cout << "\n=== 程序结束 ===" << std::endl;
    return 0;
}
```
