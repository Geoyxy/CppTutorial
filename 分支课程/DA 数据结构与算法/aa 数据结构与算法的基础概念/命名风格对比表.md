
| 教科书风格          | STL 风格                             | 功能简述            | 备注                                |
| -------------- | ---------------------------------- | --------------- | --------------------------------- |
| `InitList`     | 构造函数 `Vector()` / `LinkedList()`   | 初始化线性表          | C++ 用构造器替代独立初始化函数                 |
| `DestroyList`  | 析构函数 `~Vector()` / `~LinkedList()` | 销毁、释放内存         | RAII，对象生命周期结束自动调用                 |
| `ClearList`    | `clear()`                          | 清空所有元素，不释放容量    | 保留底层数组空间，长度置 0                    |
| `ListEmpty`    | `empty()`                          | 判断是否为空          | 返回 bool                           |
| `ListLength`   | `size()`                           | 获取元素个数          | 返回`size_t`                        |
| `ListInsert`   | `insert(pos, val)`                 | 在 pos 位置插入元素    | STL 容器统一叫 insert                  |
| `ListDelete`   | `erase(pos)`                       | 删除 pos 位置元素     | STL 删除用 erase，不是 delete           |
| `GetElem`      | `at(pos)` / `operator[]`           | 获取 pos 位置元素     | `at`越界抛异常；`[]`不做检查                |
| `LocateElem`   | `find(val)`                        | 查找元素，返回下标 / 迭代器 | 找不到返回`size_t(-1)`或`end()`         |
| `PriorElem`    | `prev()`                           | 获取前驱元素          | 链表常用                              |
| `NextElem`     | `next()`                           | 获取后继元素          | 链表常用                              |
| `ListTraverse` | `foreach` / 范围 for 遍历              | 遍历全部元素          | C++ 直接范围 for，或提供迭代器               |
| `Push`         | `push_back(val)`                   | 尾部新增元素          | 顺序表 / 链表尾部插入                      |
| `Pop`          | `pop_back()`                       | 删除尾部元素          | 栈也可以用 pop ()（无返回值，和 STL stack 对齐） |
| `GetTop`       | `top()`                            | 获取栈顶元素          | stack::top()                      |
| `EnQueue`      | `push(val)`                        | 入队              | queue::push                       |
| `DeQueue`      | `pop()`                            | 出队              | queue::pop（不返回元素）                 |
| `GetHead`      | `front()`                          | 获取队头            | queue::front                      |
| `GetTail`      | `back()`                           | 获取队尾            | deque/vector 支持 back              |
