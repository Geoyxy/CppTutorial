# 声明与定义中的代码书写规则

这些表回答的是：**哪些代码只写在声明里，哪些在声明和定义里都要写，哪些只能写在定义里。**

---

## 1. 函数相关

| 代码段                   | 声明  | 定义  | 说明                             |
| :-------------------- | :-- | :-- | :----------------------------- |
| **返回类型**              | ✅   | ✅   | 两边必须一致                         |
| **函数名**               | ✅   | ✅   | 两边必须一致                         |
| **参数列表**              | ✅   | ✅   | 两边必须一致（参数名可省略）                 |
| **`const` 限定符**（成员函数） | ✅   | ✅   | 两边必须一致                         |
| **引用限定符**（`&` / `&&`） | ✅   | ✅   | 两边必须一致                         |
| **`noexcept`**        | ✅   | ✅   | 两边必须一致                         |
| **`virtual`**         | ✅   | ❌   | 只在声明中写                         |
| **`override`**        | ❌   | ✅   | 只在定义中写（若声明和定义分离）               |
| **`final`**           | ✅   | ✅   | 两边都可以写，但通常只在声明中写               |
| **`static`**          | ✅   | ❌   | 只在声明中写                         |
| **`inline`**          | ✅   | ✅   | 通常只在声明中写，定义中可省略                |
| **`constexpr`**       | ✅   | ✅   | 两边都要写（C++11/14）；C++17 起可只在声明中写 |
| **`explicit`**        | ✅   | ❌   | 只在声明中写（构造函数）                   |
| **`= default`**       | ❌   | ✅   | 只在定义中写                         |
| **`= delete`**        | ✅   | ❌   | 只在声明中写                         |
| **默认参数**              | ✅   | ❌   | 只在声明中写                         |
| **函数体**               | ❌   | ✅   | 只在定义中写                         |
| **初始化列表**             | ❌   | ✅   | 只在声明中写                         |

---

## 2. 变量相关

| 代码段 | 声明 | 定义 | 说明 |
| :--- | :--- | :--- | :--- |
| **类型** | ✅ | ✅ | 两边必须一致 |
| **变量名** | ✅ | ✅ | 两边必须一致 |
| **`const`** | ✅ | ✅ | 两边必须一致 |
| **`static`**（全局/局部） | ✅ | ✅ | 两边都要写（局部 `static` 只在定义中写） |
| **`extern`** | ✅ | ❌ | 只在声明中写 |
| **`inline`**（变量） | ✅ | ✅ | C++17 起，通常只在定义中写 |
| **初始化值** | ❌ | ✅ | 只在定义中写 |

---

## 3. 类相关

| 代码段 | 声明 | 定义 | 说明 |
| :--- | :--- | :--- | :--- |
| **`class` / `struct`** | ✅ | ✅ | 类定义本身就是声明+定义合一 |
| **`final`**（类） | ✅ | ❌ | 只在类定义中写 |
| **`public` / `private` / `protected`** | ✅ | ✅ | 在类定义中写 |
| **基类列表** | ✅ | ✅ | 在类定义中写 |
| **继承方式**（`public` 等） | ✅ | ✅ | 在类定义中写 |
| **成员变量** | ✅ | ✅ | 在类定义中写 |
| **成员函数声明** | ✅ | ❌ | 在类定义中写 |
| **成员函数定义**（类外） | ❌ | ✅ | 在 `.cpp` 中写 |

---

## 4. 模板相关

| 代码段 | 声明 | 定义 | 说明 |
| :--- | :--- | :--- | :--- |
| **`template <typename T>`** | ✅ | ✅ | 声明和定义都要写 |
| **模板参数列表** | ✅ | ✅ | 两边必须一致 |
| **`typename` / `class`** | ✅ | ✅ | 两边都可以用 |
| **模板特化** | ✅ | ✅ | 特化版本本身就是定义 |

---

## 5. 关键规则总结

| 规则                | 说明                                                      |
| :---------------- | :------------------------------------------------------ |
| **只在声明中写**        | `virtual`、`static`、`explicit`、`= delete`、默认参数、`extern`  |
| **只在定义中写**        | `override`、`= default`、初始化值、函数体、初始化列表                   |
| **两边都要写**         | 返回类型、函数名、参数列表、`const`、`noexcept`、`constexpr`、`template` |
| **两边都可以写但通常只写一处** | `inline`（通常声明）、`final`（通常声明）                            |
