| 声明形式                   | 链接属性                          | 说明                      |
| ---------------------- | ----------------------------- | ----------------------- |
| **全局变量**               | **外部链接**                      | 默认，跨文件可见                |
| **全局函数**               | **外部链接**                      | 默认，跨文件可见                |
| **全局 `const` 变量**      | **内部链接**                      | 默认，仅在当前文件可见             |
| **全局 `constexpr` 变量**  | **内部链接**                      | 默认，仅在当前文件可见             |
| **全局 `static` 变量**     | **内部链接**                      | 只在当前文件可见                |
| **全局 `static` 函数**     | **内部链接**                      | 只在当前文件可见                |
| **匿名命名空间中的实体**         | **内部链接**                      | 只在当前文件可见（推荐替代 `static`） |
| **局部变量**               | **无链接**                       | 只在该函数内可见                |
| **函数参数**               | **无链接**                       | 只在该函数内可见                |
| **类的静态成员**             | **外部链接**（默认）                  | 需在类外定义                  |
| **`inline` 变量**        | **外部链接（特殊）**                  | 允许跨文件重复定义，链接器合并         |
| **`inline` 函数**        | **外部链接（特殊）**                  | 允许跨文件重复定义，链接器合并         |
| **`extern` 声明**        | 不定义链接属性（仅声明）                  | 告诉编译器实体在别处定义            |
| **`extern "C"` 函数/变量** | **外部链接（无 C++ name mangling）** | 用 C 语言规则链接              |
| **模板（函数/类）**           | **外部链接**                      | 模板本身是外部链接，特化/实例化后按实体规则  |
