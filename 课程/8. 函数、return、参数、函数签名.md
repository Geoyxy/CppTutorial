# 函数、return、参数、函数签名

## 1. 函数 Function

### 1.1 函数的基本概念

**函数**（Function）是 C++ 中**组织代码的基本单位**，用于**封装一段具有特定功能的代码**，可以通过**函数名**来调用它。

>[!QUESTION] 为什么叫“函数”？
>我们最早在数学中接触“函数”这个概念，数学中函数是这样一个映射关系：
>
>从一个集合（定义域）到另一个集合（值域）的**映射**，使得定义域中的**每一个元素**都唯一对应值域中的**一个元素**。
>
>简单来说，数学中的“函数”规定了一个输入的数和哪个输出的数的对应，在编程中“函数”也具有类似的作用———每个输入的数据可能有对应的输出，因此编程中也有“函数”的概念。

>[!QUESTION] **问题**：什么是封装（Encapsulation）？
>**封装**指的是：把数据（属性）和操作数据的方法（函数）捆绑在一起，并**隐藏内部实现细节**，只**对外暴露必要的接口**。
>
>例如生活中：
>
>|场景|封装的表现|
|---|---|
|**电视遥控器**|你只需要按按钮（接口），不需要知道内部电路如何工作|
|**自动贩卖机**|你投币选商品（接口），不需要知道内部机械如何运转|
|**汽车**|你踩油门、转方向盘（接口），不需要知道发动机内部构造|
|**手机**|你点屏幕（接口），不需要知道芯片如何计算|
>
>通过这些生活中的场景我们可以观察到，封装可以：
>
>1. 不需要知道内部的实现原理（隐藏内部细节）。
>2. 使用更加简单（只对外暴露必要接口）。

^Encapsulation

### 1.2 函数的定义

语法：

```cpp
返回类型 函数名(参数列表)
{函数体}
```

| 部分                    | 作用            | 示例                    |
| --------------------- | ------------- | --------------------- |
| [[#1.2.1 返回类型\|返回类型]] | 函数返回值的类型      | `int`、`void`、`double` |
| **函数名**               | 标识函数的名称       | `add`、`printHello`    |
| **参数列表**              | 传入函数的数据（可以没有） | `(int a, int b)`、`()` |
| **函数体**               | 要执行的代码        | `{ return a + b; }`   |

>[!TIP] 函数命名建议
>函数命名建议采用“**大驼峰**”（**PascalCase**）的命名风格，具体规则：
>
>1.  一个或多个单词拼接在一起，单词间无下划线 `_`。
>2. 无前缀和后缀。
>3. 标识符的首字母大写。
>4. 每个单词的首字母大写。
>
>如： `AddElement`, `ToString`, `BtnClickEvent`, `Remove`

### 1.3 返回类型

`返回类型` 是函数的返回值的数据类型。

`函数体` 应该包含 `return 值`，比如我们常写的 `return 0;` ，并且需要注意，返回的值应该和 `返回类型` 匹配，例如：

```cpp
string GetStr() 
{
	return "返回字符串类型";
}
```

`返回类型` 除了我们之前所学的数据类型外，还可以是 `void` **空类型**（Empty Type），当 `返回类型` 是 `void` 时，可以选择性地写 `return` 语句，但是 `return` 后不能接返回值，例如：

```cpp
void Func()
{
	cout << "执行 Func 函数";
	return;
}
```

或：

```cpp
void Func()
{
	cout << "执行 Func 函数";
}
```

以上两个代码效果相同，唯一的区别是字面上有无 `return;` ，那么 `return` 的作用是什么？什么时候用 `return` ？

### 1.4 return 语句

**`return`** 和之前所学的 `break`, `continue` 一样，也是 C++ 中的一种**跳转语句**，用于：

1. **结束当前函数的执行**：[[课程/8. 函数、return、参数、函数签名#^7640ca|执行流]] 从函数中返回。

例如：

```cpp
/*
根据成绩判断考试是否通过
通过则返回 true
不通过或成绩错误则返回 false
*/
bool IsPass()
{
	int score = 50;
	
	// 成绩错误则直接返回 false 退出函数
	if (score < 0 || score > 100)
	{
		return false;
	}
	// 成绩大于等于60及格，通过考试
	else if (score >= 60)
	{
		return true;
	}
	// 成绩小于60，不及格
	else
	{
		return false;
	}
}
```

2. **向调用处传递返回值**：将 `return` 后面的值作为函数调用的结果返回。

例如：

```cpp
bool IsPass()
{
	int score = 50;
	
	// 成绩错误则直接返回 false 退出函数
	if (score < 0 || score > 100)
	{
		return false;
	}
	// 成绩大于等于60及格，通过考试
	else if (score >= 60)
	{
		return true;
	}
	// 成绩小于60，不及格
	else
	{
		return false;
	}
}

int main() 
{
	// 这里的 IsPass() 用于使用 IsPass() 函数，并在此处获取 IsPass() 函数的返回值 false
	cout << "分数50，考试" << (IsPass() ? "通过" : "不通过或分数非法");
	return 0;
}
```

所以我们需要在函数提前结束或需要返回的地方使用 `return` 语句。

>[!WARNING] 注意：缺少 `return` 可能导致未定义行为
>返回类型非空的函数的**每个执行路径都要有返回值**。
>**执行路径**（Execution Path）指的是：程序在函数体内可能走过的每一条路。
>
>例如：
>
>```cpp
>// 缺少路径 3 的返回值
>int Check(int x) {
>    if (x > 0) {
>        return 1;   // 路径 1
>    } else if (x == 0) {
>        return 0;   // 路径 2
>    }
>    // 路径 3（x < 0）：没有 return → 未定义行为！
>}
>```
>
>这种情况会导致程序运行时可能返回一个随机值，也可能崩溃。

### 1.5 函数调用

调用函数即使用函数，语法如下：

```cpp
函数名称(参数列表)
```

调用函数时，执行顺序（即执行流）：

1. 立刻从当前代码跳转到被调用的函数。
2. 函数返回或结束。
3. 当前代码尝试获取函数的返回值，再继续执行当前没执行完的代码。

例如：

```cpp
String GetStr()
{
	return "Hello, Function!"; // 2.执行到此处则跳转到 main 函数的 cout <<
}

int main()
{
	cout << /*1.执行到此处立刻执行 GetStr 函数*/ GetStr(); 
	// 3. << 获取到返回值 "Hello, Function!" 并传给 cin 打印
}
```

输出：

```
Hello, Function!
```

>[!NOTE] 概念：执行流（Flow of Execution）
>**执行流**（Flow of Execution）指的是**程序运行时，语句执行的先后顺序**。
>
>简单来说，执行流就像一条**路径**，程序从起点开始，沿着这条路径一条一条地执行代码，直到终点。执行流决定了代码的**执行顺序**，而不是代码的**书写顺序**。
>
>执行流有三种基本结构：
>
>| 结构       | 说明         | 示例                       |
>| -------- | ---------- | ------------------------ |
>| **顺序结构** | 从上到下依次执行   | 普通语句按书写顺序执行              |
>| **分支结构** | 根据条件选择执行路径 | `if`、`switch`            |
>| **循环结构** | 重复执行某段代码   | `for`、`while`、`do-while` |
>
>`break`, `continue`, `return`, `goto` 等跳转语句和函数调用都可以改变执行流。

### 1.6 参数列表

在上一节的作业中，我们为了计算不同的数值，写了大量的重复函数：

```cpp
int Add123() { return 123 + 456; }
int Add1()   { return 1 + 2; }
int Add100() { return 100 + 200; }
// ... 每来一组新数字，就要写一个新函数
```

这些函数的结构几乎一样，只是**数据不同**。如果能让函数在调用时**传入数据**，就能用一个函数解决所有类似的问题。

**参数列表**就是为了解决这个问题而存在的——它让函数能够接收外部传入的数据。

带参数的函数定义：

```cpp
返回类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) 
{函数体}
```

参数列表中的每个参数由 **参数类型** 和 **参数名** 组成，多个参数之间用逗号 `,` 分隔。

例如：

```cpp
// 带参数的加法函数
int Add(int a, int b)
{
    return a + b;
}

int main() 
{
	// 直接传入参数，不定义多个函数
    cout << Add(123, 456) << endl;   // 输出：579
    cout << Add(1, 2) << endl;       // 输出：3
    cout << Add(100, 200) << endl;   // 输出：300
    cout << Add(999, 888) << endl;   // 输出：1887
    return 0;
}
```

### 1.7 函数的声明

需要注意，只能在调用处调用此前已声明/定义的函数，否则编译器会找不到被调用的函数，例如：

```cpp
int main() 
{
	Add(10, 5); // ❌ 错误，此前未 声明/定义 Add 函数
}

int Add(int a, int b)
{
    return a + b;
}
```

若被调用函数的定义只能在被调用处的后面，则需要在调用处前声明函数，以让编译器知道被调用函数的存在。

函数声明的语法：

```cpp
返回类型 函数名(参数列表);
```

需要注意，声明中的 `返回类型`, `函数名` 和 `参数列表` 需要和定义中的相同，且末尾需要加分号 `;`，例如：

```cpp
// 函数声明
double Add(int a, int b);

// 函数定义
double Add(int a, int b)
{
    return a + b;
}
```

>[!QUESTION] 函数声明应该放哪？
> 在大型项目中，函数声明通常集中放在**头文件（`.h`）**中，而函数定义放在**源文件（`.cpp`）中。这样可以让代码结构更清晰，也方便多个文件共享同一个函数声明。
> 我们将在之后讲到多文件程序。

## 2. 参数 Parameter

### 2.1 参数的基本概念

**参数**（Parameter）是函数与外部世界沟通的**桥梁**——它允许函数在调用时接收外部传入的数据，从而使函数能够处理不同的输入，产生不同的输出。

简单来说：参数就是函数内部的“原材料入口”，调用者把数据从入口送进去，函数加工后把结果通过 `return` 送出来。

### 2.2 参数的分类

参数分为**形式参数**（简称**形参**）和**实际参数**（简称**实参**）：

| 概念  | 含义                       | 示例                                   |
| --- | ------------------------ | ------------------------------------ |
| 形参  | 函数定义时在参数列表中声明的参数，起“占位”作用 | `int Add(int a, int b)` 中的 `a` 和 `b` |
| 实参  | 调用函数时实际传入的值              | `Add(123, 456)` 中的 `123` 和 `456`     |

```cpp
// 形参：a 和 b 是形式参数，用于接收传入的值
int Add(int a, int b) {
    return a + b;
}

int main() {
    // 实参：123 和 456 是实际参数，传递给形参 a 和 b
    int result = Add(123, 456);
    return 0;
}
```

形参在函数**定义**时存在，实参在函数**调用**时传入。形参的作用域仅限于函数体内部，函数执行结束后形参即被销毁。

### 2.3 参数的传递方式

C++ 中有三种主要的参数传递方式：

| 传递方式     | 说明                 | 能否修改实参 |
| -------- | ------------------ | ------ |
| **值传递**  | 将实参的**副本**传给形参     | ❌ 不能   |
| **引用传递** | 将实参的**引用**（别名）传给形参 | ✅ 能    |
| **指针传递** | 将实参的**地址**传给形参     | ✅ 能    |

这节课我们只了解值传递，其他传递将在学习指针和引用后讲。

以值传递的方式传入实参，实参实际上只是个**副本**，即传入实参时传入的实际是另一个**和原数据有相同值的不同数据**，因此不能使用值传递的方式用其他函数修改要存储的值，例如：

```cpp
// 值传递：修改的是副本，实参不变
void ChangeByValue(int x) {
    x = 100;   // 修改的是副本
}

int main() {
    int a = 10;
    ChangeByValue(a);
    cout << a;   // 打印 10（未变）
    
    return 0;
}
```

输出：

```
10
```

因此要想修改实参，就得用指针或引用传递。

### 2.4 默认参数

可以在函数声明/定义中为参数指定默认值。调用时如果省略该参数，则使用默认值。

```cpp
// 默认参数：b 的默认值为 2
int Multiply(int a, int b = 2) {
    return a * b;
}
int main() {
    cout << Multiply(5);     // 打印 10（5 * 2，使用默认值）
    cout << Multiply(5, 3);  // 打印 15（5 * 3，使用传入的值）
    return 0;
}
```

**注意事项**：

- 参数列表中默认参数右边不能有非默认参数。
- 默认值在函数**声明**中指定（如果声明和定义分离）。

```cpp
// ✅ 正确：默认参数右边无非默认参数
int Func(int a, int b = 1, int c = 2);
// ❌ 错误：默认参数右边有非默认参数 b
int Func(int a = 1, int b, int c = 3);
```

>[!QUESTION] 为什么“默认参数右边不能有非默认参数”？
>因为调用时参数是按从左到右的顺序匹配的，例如：
>
>```cpp
>int Func(int a = 1, int b, int c = 3);
>```
>
>如果你写 `Func(4, 5)`，编译器不知道：
>
>1. 你到底想把 `4` 传给 `a` 还是 `b`。
>2. 你到底想把 `5` 传给 `b` 还是 `c`。

## 3. 函数重载 Function Overloading

### 3.1 函数重载的基本概念

在上一节的练习中，我们写了三个功能相同但参数类型不同的函数：

```cpp
void PrintInt(int value) { cout << "数据：" << value << endl; }
void PrintDouble(double value) { cout << "数据：" << value << endl; }
void PrintString(string value) { cout << "数据：" << value << endl; }
```

这三个函数做的事情完全一样——**打印数据**，却因为参数类型不同，被迫起了三个不同的名字。如果将来还要支持 `char`、`bool`、`float` 等更多类型，就需要不断增加新函数，名字越来越长，使用也越来越麻烦。

理想情况下，我们希望函数**统一用同一个名字**，比如都叫 `Print`，编译器根据传入的**参数类型**自动决定调用哪个版本：

```cpp
Print(42);       // 自动调用 Print(int)
Print(3.14);     // 自动调用 Print(double)
Print("Hello");  // 自动调用 Print(string)
```

这种“**同一个函数名，对应多个不同实现**”的机制，就是**函数重载**（Function Overloading）。

>**函数重载**：在**同一个作用域**内，可以定义**多个同名函数**，但它们的**参数列表**必须不同（参数的类型、个数或顺序不同）。

编译器会根据调用时传入的**实参类型**和**实参个数**，自动判断应该调用哪一个重载版本。

>[!WARNING] 区别于标识符的“声明后（在同一作用域内）不能再声明或定义”
>与标识符的在同一作用域不可重复的规则不同，**函数名可以重复**，因为编译器区别函数时不只是参考函数名，而是参考函数签名。

### 3.2 函数签名

试想：函数重载时，你写的是相同的函数名（标识符），编译器怎么知道你具体调用的是哪个函数？

例如，你写了：

```cpp
// 格式化打印，期望参数：字符串，拼接的字符，字符重复次数
FormatPrint("hello", 'c', 3)
```

编译器能从以上代码看出来以下信息：

1. 函数名
2. 参数列表的参数数量
3. 参数列表的参数类型
4. 参数列表的参数类型顺序

因此，编译器根据以上四个要素**判断具体重载到哪个函数**，这四个要素则合称为**函数签名**。

>**函数签名**（Function Signature）是编译器用来**唯一标识一个函数**的信息组合，通常包括：

|    要素    | 是否参与函数签名 | 说明           |
| :------: | :------: | ------------ |
| **函数名**  |   ✅ 参与   | 函数的名字        |
| **参数列表** |   ✅ 参与   | 参数的类型、个数、顺序  |
| **返回类型** |  ❌ 不参与   | 仅凭返回类型无法区分函数 |

其中“参数列表”包括：

1. 参数数量
2. 参数类型
3. 参数类型的顺序
