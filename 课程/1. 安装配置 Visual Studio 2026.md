# 安装配置 Visual Studio 2026

## 1. 关于 Visual Studio

Visual Studio 是微软出品的一款功能强大的**集成开发环境**（**IDE**），所谓集成开发环境，指的是一套覆盖编辑代码、调试、测试到最终部署的整个软件开发周期。

简单来说，Visual Studio 为我们提供了一套完整的编程工具，这也是我们本套教程使用 VS 的原因。

编写此套教程的时间是 2026-8-18 ，VS 的最新版本为 Visual Studio 2026，所以我们本套教程主要使用 Visual Studio Community 2026 来学习编程。

以下为 VS 的下载、安装、配置教程，由于 VS 软件及 VS 网站随时间推移可能会发生变化，若以下教程失效时建议查看B站较新的相关 Visual Studio 的安装配置教程。推荐使用你此时最新的 VS 版本。

## 2. 安装配置

### 2.1 从官网下载安装包

>[!TIP] 提示：本教程的环境
本教程使用的浏览器为 edge 浏览器，操作系统为 windows11。

方式一：

访问 [Visual Studio 官网下载页面](https://visualstudio.microsoft.com/zh-hans/thank-you-downloading-visual-studio/?sku=Community&channel=Stable&version=VS18&source=VSLandingPage&cid=2500&passive=false) ，此时应该发现有文件开始下载，或根据页面提示重新下载。

![[VS 重新下载.png]]

方式二：

1. 浏览器搜索“visual studio”，打开此项网站。注意网址应该为图中所示的 https://visualstudio.microsoft.com/ 。

![[VS 官网搜索结果卡片.png]]

2. 此时应该跳转到 https://visualstudio.microsoft.com/zh-hans/ 这个网址，若有误，也可以手动在地址栏（即浏览器顶部显示网址的文本框）中粘贴以上网站。

![[地址栏.png]]

3. 进入的页面如图，点击“免费下载”。

![[VS 官网页面.png]]

4. 此时应该进入如图所示的网页，并且会有文件自动开始下载。

![[VS 下载页面.png]]

若没有进入该网页，尝试在地址栏搜索：

https://visualstudio.microsoft.com/zh-hans/thank-you-downloading-visual-studio/?sku=Community&channel=Stable&version=VS18&source=VSLandingPage&cid=2500&passive=false

若没有开始下载，尝试点击页面中的“单击此处以重试”（图中红框处）。

### 2.2 安装 VS

1. 找到并打开下载的安装包，此时可能会出现一个弹窗问你“你要允许此应用对你的设备进行更改吗？”，点击“是”（windows 系统中，使用安装包安装应用一般需要管理员权限，这个操作叫作“提权”，点击“是”后，安装程序会获得修改系统目录的权限，这是正常操作，不用担心。）。

![[VS 安装包.png]]

>[!TIP] 提示：安装包的位置
若你使用的是 windows 系统的电脑，且用户文件夹和浏览器的下载设置使用的是默认配置，则此时安装包应该在 C:\Users\你的用户名\Downloads\ 下。

2. 若出现如图所示的弹窗，点击“继续”。

![[VS 安装向导弹窗.png]]

3. 等待 Visual Studio 安装程序准备完毕，此时你应该能发现如图所示的窗口，点击“可用”选项卡。

![[VS 安装窗口.png]]

若进入的是如下图所示的窗口，则先点击图中右上角红框中的“×”，此时应该就能进入上图所示的页面。

![[VS 安装配置.png]]

4. 在“可用”选项卡的页面中，点击图中 Visual Studio Community 2026 选项卡中红框中的“安装”。如果 Visual Studio Community 2026 有 stable 和 insiders 版本之分，则选择 stable。

![[VS 2026 社区版选项卡.png]]

5. 在弹出的如图所示的窗口中，在“工作负载”选项卡的页面下，勾选“使用 C++ 的桌面开发”。若有需要，也可以选择其他负载。已后也可以使用此软件为已安装的 VS 安装新的工作负载。

![[VS 工作负载.png]]

6. 继续在此窗口中选择“语言包”选项卡，确保选中“中文（简体）”，也可以额外选中“英语”。

![[VS 语言包.png]]

7. 继续在此窗口中选择“安装位置”选项卡。如果你的 C 盘空间足够大或者电脑不分系统盘、软件盘等，则可以直接安装，忽略以下关于修改安装路径的内容。

>[!TIP] 提示：软件安装路径
>我的电脑上安装软件的路径是 D:\Data\，你可以根据自己的实际情况替换以下的“D:\Data\” 为你自己的软件安装路径。
>
>比如你的电脑上软件都是安装在 E:\Software\ 下的，则可以替换 “D:\Data\VS\VS 2026 ” 为 “E:\Software\VS\VS 2026”）

产品路径，即软件本体的安装路径，图中安装路径为：D:\Data\VS\VS 2026

下载缓存，图中路径为：D:\Data\VS\Packages

>[!WARNING] 注意：建议保留下载缓存
>由于 VS 安装程序会在下载缓存记录电脑的 VS 安装情况，所以**建议此处勾选“安装后保留下载缓存”**，否则可能会导致已后 VS 安装程序无法识别电脑上已安装的 VS，导致 VS 无法更新、添加工作负载等。
>
>如果此处保留了下载缓存，也**建议不要手动删除或修改下载缓存**。

共享组件、工具和 SDK 的路径建议不要修改，保持默认即可，因为社区有反馈把此路径改到其他盘，有概率出现更新失败、个别 SDK/Windows 工具链报错。如果你无视风险执意修改，也可以修改为：D:\Data\VS\Shared 。

![[VS 安装位置.png]]

路径准备完毕后，点击右下角的“安装”，最后再等待下载、安装完成即可。
