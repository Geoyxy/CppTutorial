# 类和对象基础、访问说明符

## 1. 类 Class

### 1.1 类的基本概念

回想一下我们之前学过的结构体，结构体中有各种数据成员，例如：

```cpp
struct Student
{
	// 数据成员
	string name;  // 姓名
	int age;            // 年龄
	double sum_score;   // 总分
	double yvwen_score; // 语文成绩
	double math_score;  // 数学成绩
	double english_score; // 英语成绩
};
```

结构体允许我们把多个变量包装在一起，让变量（即数据成员）和变量之间有内在逻辑，也方便我们管理数据。但数据终归是用来操作的，比如我们需要把各科成绩相加得到总分 `sum_score`，这使得我们需要一个 计算总分的函数 `CalculateSumScore` ：

```cpp
struct Student { ... };

Student& CalculateSumScore(Student& student) { ... }
```

我们发现 `CalculateSumScore` 是只有 `Student` 才能使用的函数，也就是说这个函数和 `Student` 结构体是天然绑定的，那为什么不能把它也放入结构体中呢？

我们之前写的动态数组也是同样的问题，调用每个动态数组专用的函数都要在参数列表声明 `DynamicArray* dynamic_arr` ，还要在返回值类型也再声明一遍 `DynamicArray*`，非常麻烦，而且我们只是给函数名加 `DA_` 前缀来表示它是动态数组专用的函数，逻辑非常松散。

总的来说，结构体只封装数据，导致数据和操作分离，这会导致代码冗长、逻辑松散。要解决这个问题，把数据和操作封装在一起，就需要“**类**”。

**类（Class）** 是 C++ 中用于**封装数据和操作**的用户自定义数据类型。它是面向对象编程（OOP）的基本构建单元。

面向对象编程的三大特点是：==封装、继承、多态==

### 1.2 类的定义

语法：

```cpp
class 类名
{
访问说明符:
	数据成员1;
	数据成员2;
	...
	成员函数1;
	成员函数2;
	...
};
```

1. 其中访问说明符将在这节课的后面讲到，这里先只用知道有 `public`, `private`, `protected`。
2. `数据成员` 和 `成员函数` 和 `访问说明符` 的数量、顺序任意。

例如（先忽略代码中的访问说明符）：

```cpp
// 玩家类
class Player
{
private:
	double hp_; // 血量
	double mp_; // 魔力值
	int level_; // 等级
	double attack_;  // 攻击力
	double defence_; // 防御力
public:
	// 承受伤害
	void TakeDamage(double damage)
    {
        double actual_damage = damage - defence_; // 实际伤害
        if (actual_damage < 0) actual_damage = 0;
        hp_ -= actual_damage;
        if (hp_ < 0) hp_ = 0; // 防止血量变为负数
        // 如果血量归零，触发死亡逻辑
        if (hp_ == 0) {
            Die();
        }
    }
private:
	// 计算攻击力
	void CalcAttack()
	{
		attack_ = 10 + level_ * 2;
	}
	// 死亡
	void Die() { ... }
};
```

> [!TIP] 提示：类的命名
> 推荐类的命名采用 PascalCase（帕斯卡命名法），特点：
> 
> 1. 每个单词首尾相连。
> 2. 每个单词首字母大写。
>
>例如：`DynamicArray`, `BoxContainer`, `IdCreator`, `Enemy`

### 1.3 数据成员 Data Members

**数据成员**，也叫**成员变量**（Member Variables），在其它语言中一般被称为字段（Field），和结构体中的数据成员很相似，也是用于存储状态的变量。它们定义了类"有什么"。

>[!WARNING] 注意：“数据成员”和“成员变量”的关系
>严格来说，成员变量属于数据成员的子集。
>**数据成员**：类里面所有的非函数成员都叫数据成员。
>**成员变量**：普通可修改的数据成员。
>
>比如常量可以是数据成员，但不能是成员变量。

>[!TIP] 提示：数据成员的命名风格
对于普通数据成员，推荐命名风格为 `snake_case + _`（Google C++ 规范），`_` 用于表示这个数据属于数据成员。
>
| 数据成员            | 原有命名法                    | 示例                     |
| --------------- | ------------------------ | ---------------------- |
| 成员变量            | snake_case 蛇形命名法         | `name_`, `last_index_` |

### 1.4 成员函数 Member Function

**成员函数**，在其它语言中一般也叫**方法（Method）**，是类中定义的函数，用于操作数据成员。它们定义了类的行为和能力。

例如：

```cpp
class Person
{
private:
	string name_; // 姓名
public:
	void SetName(const string& value)
	{
		name_ = value;
	}
};
```

其中成员函数 `SetName` 操作了 数据成员 `name_`，为 `name_` 赋值。

访问成员函数的方法和数据成员一样，使用 `.` 或 `->` 运算符访问，例如：

```cpp
Person p;
p.SetName("rover");
```

>[!TIP] 提示：成员函数的命名
>建议成员函数的命名采用 PascalCase（帕斯卡命名法）。

### 1.5 对象 Object

**对象**（Object）是类的**具体实例**（Instance）。类定义了"有什么"和"能做什么"，而对象则是真正在内存中存在的实体，拥有自己的数据存储空间。

用结构体来理解的话，结构体变量是结构体的实例，对象则是类的实例。

>[!TIP] 提示：结构体变量
>关于结构体变量，回顾 [[9. 结构体、成员访问运算符#1.3 结构体变量的声明及初始化|9-1.3 结构体变量的声明及初始化]] 。

| 类型 (蓝图)    | 实例 (实体)      |
| ---------- | ------------ |
| class 类    | 对象（类实例）      |
| struct 结构体 | 结构体变量（结构体实例） |

例如：

```cpp
class Person { ... }; // Person 的定义见前一个代码块

// Person 类的对象 p1, p2
Person p1; // 这里是创建对象，后面会讲到
Person p2;
p2.SetName("李四"); // 通过成员函数设置 p2 的 name_ 为 "李四"
```

>[!NOTE] 概念：对象的**广义**和**狭义**
>1. 广义的对象指的是一块存储区域，换句话说，只要占了内存，就是对象。例如：
>
>```cpp
>struct Student { ... };
>class Persom { ... };
>
>int a;
>double* b;
>Student c;
>Person d;
>```
>
>其中 `a`, `b`, `c`, `d` 都叫做对象。
>对象的广义概念仅在 C 和 C++ 语言中存在。
>
>2. 狭义的对象指的是类的实例，比如上个代码块中的 `d` 和上上个代码块中的 `p1`, `p2`。

### 1.6 构造函数 Constructor

#### 1.6.1 构造函数的基本概念

**构造函数**是类中一种**特殊的成员函数**，它的主要作用是**初始化对象**。==当创建一个对象时，构造函数会被**自动调用**。==

简单来说，构造函数允许我们在创建对象时**为对象的数据成员赋初始值**。相应的，没有构造函数则无法创建对象。

构造函数的写法比较特殊：

1. 不写返回值类型。
2. 函数名为类名。

以下将会学习不同的构造函数

#### 1.6.2 自定义默认构造函数

自定义默认构造函数是**调用时可以不传任何参数**的构造函数，写法例如：

```cpp
class Person
{
public:
	string name_;
	int age_;
	// 自定义默认构造函数
	// 对象创建时自动为 name_ 和 age_ 赋值
	Person()
	{
		name_ = "无名氏";
		age_ = 0;
	}
};
```

#### 1.6.3 隐式默认构造函数

当一个类中==不写任何构造函数时==，编译器则会为该类隐式生成一个无参构造函数，这个函数的函数体为空。以此保证我们即使不写构造函数也能创建对象。

例如：

```cpp
class Person 
{
public:
	string name_;
	int age_;
};
```

实际上编译器会为 Person 生成一个无参构造函数，这个函数类似于

```cpp
Person() {}
```

当类中有任何自定义的构造函数时（包括后面会学的拷贝构造函数），编译器则不会再生成隐式默认构造函数。

#### 1.6.4 显式默认化的默认构造函数（了解即可）

对一个构造函数使用 `= default` 即可声明为显式默认化的默认构造函数。
显式默认化的默认构造函数是与隐式默认构造函数 **相同行为**的构造函数。

例如：

```cpp
class Person
{
public:
	Person() = default; // 显式默认化的默认构造函数
};
```

当类中自定义了构造函数但又需要隐式默认构造函数时就需要此构造函数。

#### 1.6.5 带参构造函数

带参构造函数即有参数的构造函数，可以用参数为数据成员赋初始值，例如：

```cpp
class Person
{
public:
	string name_;
	int age_;
	// 带参构造函数
	Person(const string& name, int age)
	{
		// 为数据成员赋初始值
		name_ = name;
		age_ = age;
	}
};
// 用带参构造函数为成员赋初始值
Person doctor("Kaltsit", 1000);
```

为数据成员初始化时，推荐使用**初始化列表**。初始化列表将在 1.7.3 学到。

>[!WARNING] 注意：看起来像带参构造函数的自定义默认构造函数
>
>```cpp
>Person(int age = 18)
>{
>	age_ = age;
>}
>```
>
>这是一种自定义默认构造函数，而非带参构造函数，因为自定义默认构造函数的定义是**调用时可以不传任何参数**，而代码中的构造函数确实可以不传任何参数。

### 1.7  创建对象

创建对象也叫类的实例化，需要使用类中的构造函数。

对于类：

```cpp
class Person
{
public:
    string name_;
    int age_;
    
    // 默认构造函数
    Person()
    {
	    name_ = "无名氏";
	    age_ = 0;
    }
    // 带参构造函数
    Person(const string& name, int age)
    {
	    name_ = name;
	    age_ = age;
    }
};
```

#### 1.7.1 调用默认构造函数

```cpp
Person p1; // 栈上创建
Person* p3 = new Person(); // 堆上创建
```

>[!WARNING] 注意：不要写 `Person p()`
>C++ 的语法规则中，**任何可以被解析为声明的语句，都会被视为声明**。例如：
>
>```cpp
>Person p();  // 编译器认为：这是一个函数声明，因为 p 后面跟了 ()
>
>// 你以为：用临时对象构造 p
// 实际：声明了一个返回 Person 的函数 p，参数是一个返回 Person 的函数
Person p(Person());  // 这也是函数声明
>```
>
>因此，避免写 `Person p()`，这被称为 **"C++ 中最令人费解的语法"**。
>
>若看不懂第二行代码，或不知道临时对象，可在学完 [[13. 类和对象基础、访问说明符#1.7.4 临时对象 Temporary Object| 1.7.4 临时对象]] 后回来看此处。
#### 1.7.2 调用带参构造函数

```cpp
Person p3("Kaltsit", 1000);  // 栈上创建
Person* p4 = new Person("Amiya", 14); // 堆上创建
```

>[!WARNING] 注意：创建对象时调用匹配的构造函数
>1. 如果 `Person` 没有默认构造函数，则不能 `Person p;` 和 `Person p = new Person()` 。
>2. 如果 `Person` 没有带参构造函数，则不能 `Person p("Kaltsit", 1000);` 和 `Person p = new Person("Amiya", 14)` 。

#### 1.7.3 初始化列表 Initializer List

初始化列表是构造函数的一种特殊语法，会在==构造函数的函数体**执行之前**完成数据成员的初始化==。

参数列表需要写在构造函数后，它的写法如下：

```cpp
构造函数() 
	: 数据成员1(初始值1), 数据成员2(初始值2) ... // 参数列表
{ ... }
```

初始化列表会把 `数据成员n` 赋值为 `初始值n`

例如：

```cpp
class Person
{
public:
	string name_;
    int age_ = -1;
    
	Person(const string& name)
		: name_(name), age_(0)
	{}
};

Person person("佚名");
cout << person.name_ << endl; // 打印 佚名
cout << person.age_ << endl; // 打印 0
```

相比在构造函数的函数体中赋初始值，初始化列表更加高效。

有些成员==**必须**==在初始化列表中初始化：

| 成员类型               | 原因          | 示例                |
| ------------------ | ----------- | ----------------- |
| **`const` 成员**     | 常量只能在初始化时赋值 | `const int m_id;` |
| **引用成员**           | 引用必须在初始化时绑定 | `int& m_ref;`     |
| **没有默认构造函数的类类型成员** | 只能通过有参构造初始化 | 如下                |

```cpp
// 位置类
class Position
{
public:
	const int x_;
	const int y_;
	// 带参构造函数 和 初始化列表
	// 无默认构造函数
	Position(int x, int y) : x_(x), y_(y) {}
};
// 建筑类
class Building
{
public:
	const Position& pos_; // 类类型成员，const 成员，引用成员
	// 必须使用初始化列表
	Building(Position& pos) : pos_(pos) {}
};
```

#### 1.7.4 临时对象 Temporary Object

**临时对象**，也叫**匿名对象**（Anonymous Object），因为它没有名字（标识符），所以它的生命周期较短，通常执行完当前表达式就被销毁。

它的常见出现场景如下：

1. **复制初始化**

```cpp
Person p = Person("Closure", 30);
```

其中 `Person("Closure", 30)` 返回的是一个 `Person` 类型的临时对象。

执行完此行代码（表达式），`Person("Closure", 30)` 返回的临时对象即被销毁，但此时 `p` 已拷贝此临时对象，成功赋值。

这种用 `=` 来初始化对象的写法叫作“**复制初始化**（Copy Initialization）”。

>[!TIP] 提示：编译器优化
>C++17 之后，以上写法不再发生拷贝，而是被编译器优化，效果和 `Person p("Closure", 30);` 一样，这被称为 “拷贝省略”（Copy Elision）。也就是说，复制初始化可能不发生拷贝。

2. **函数传参**

```cpp
void PrintPerson(const Person& p) {
    // ...
}

int main() {
    PrintPerson( Person("Amiya", 14) );  // 传入一个临时对象
    return 0;
}
```

这里的 `Person("Amiya", 14)` 是一个临时对象，它被传递给函数。因为函数参数是 `const Person&`（常量引用），临时对象可以绑定到常量引用上，并且它的生命周期会**延长**到函数执行结束。

>[!WARNING] 注意：仅常量引用可绑定临时对象
>如果函数参数是 `Person&`（非 const 引用），则**不能**传入临时对象，因为非 const 引用不能绑定到临时对象。这是 C++ 的一条重要规则，目的是防止意外修改临时对象。

3. 函数返回值

```cpp
Person CreatePerson() {
    return Person("Kaltsit", 1000);  // 返回一个临时对象
}
int main() {
    Person p = CreatePerson();  // 接收返回的临时对象
    return 0;
}
```

`CreatePerson` 函数返回的也是一个临时对象，然后用来初始化 `p`。

>[!NOTE] 概念：临时对象的生命周期
>```cpp
>Person p = Person("Closure", 30); // 临时对象在这里被创建
// 表达式结束后，临时对象被销毁
// 但 p（有名对象）依然存活
>```
>
>1. **默认情况**：临时对象在当前完整表达式结束时被销毁。
>2. **特殊情况**：如果临时对象被绑定到 **`const` 左值引用**或**右值引用**上，它的生命周期会延长到该引用的生命周期结束。（我们之前只学了左值引用）
>
>```cpp
>const Person& ref = Person("Amiya", 14);  // 临时对象生命周期延长到 ref 销毁时
>```
>
>关于左值和右值，回顾 [[12. 引用、const 限定符#^LvalueAndRvalue|12-1.4 概念：左值和右值 Lvalue & Rvalue]] 。

#### 1.7.5 统一初始化 Uniform Initialization

C++11 引入了**统一初始化**语法，使用花括号 `{}` 来初始化对象。它可以用于所有类型的初始化，包括基本类型、数组、结构体和类。

```cpp
// 基本类型
int a{10};           // 等价于 int a = 10;

// 数组
int arr[]{1, 2, 3};  // 初始化数组

// 类对象
Person p1{};         // 调用默认构造函数
Person p2{"Kaltsit", 1000}; // 调用带参构造函数
Person p3 = {"Closure", 30}; // 复制初始化 + 统一初始化
```

为什么推荐使用 `{}`？

| 特性                     | 说明                                                    |
| ---------------------- | ----------------------------------------------------- |
| **统一语法**               | 所有类型都可以用 `{}` 初始化，不用记不同的写法                            |
| **防止窄化转换**             | `int x{3.14};` 会报错（浮点数转整数丢失精度），而 `int x = 3.14;` 只会警告 |
| **避免 `Person p()` 陷阱** | `Person p{};` 明确是创建对象，不会被认为是函数声明                      |

>[!NOTE] 概念：窄化转换 Narrowing Conversion
**窄化转换**是指将一个值转换成另一种类型时，可能导致精度丢失或范围溢出的隐式转换。例如: 
>
>```cpp
>void func(int value) {}
>
>func(3.14); // 窄化转换，可能丢掉小数部分
>```
>
列表初始化 `{}` 会在编译期阻止窄化转换，而普通赋值 `=` 只会给出警告。

## 2. 访问说明符

**访问说明符**控制类成员（数据成员和成员函数）的**可见性**，即"谁能访问这个成员"。这是面向对象编程中**封装**（Encapsulation）的基础。

访问说明符有 `public`, `protected`, `private`。
此节课仅掌握 `public`, `private`，暂不需要掌握 `protected`。

|   访问修饰符   | 类内访问 | 类外访问 |
| :-------: | :--: | :--: |
| `public`  |  ✅   |  ✅   |
| `private` |  ✅   |  ❌   |

### 2.1 public 公有访问权限

被 `public` 说明的成员（即公有成员）可以在类的内外被访问，例如：

```cpp
// 计算器类
class Calculator
{
// 所以成员均公有成员
public:
	double num1_ = 0.0;
	double num2_ = 0.0;
	double result_ = 0.0;
	
	void SetResult(double value) 
	{ 
		result_ = value; 
	}
	double Add() 
	{ 
		SetResult(num1_ + num2_);  // ✅ 可以类内访问 SetResult
	}
};

Calculator().SetResult(100.0); // ✅ 可以类外访问 SetResult
```

其中公有成员 `SetResult` 可以在类内外被访问。`num1`, `num2`, `result`, `Add` 也一样可以。在类内外被访问（因为都是公有成员）。

### 2.2 private 私有访问权限

被 `private` 说明的成员（即私有成员）只能在类的内部被访问，例如：

```cpp
// 计算器类
class Calculator
{
	string description = "description 是默认权限";
private:
	double num1_ = 0.0;
	double num2_ = 0.0;
	double result_ = 0.0;
	
	void SetResult(double value) 
	{ 
		result_ = value; // ✅ 可以类内访问 result
	}	
	
public:
	double Add() 
	{ 
		SetResult(num1_ + num2_);  // ✅ 可以类内访问 SetResult 和 num1, num2
	}
};

Calculator* c = new Calculator();
c->Add();          // ✅ 可以类外访问 Add
c->SetResult(0.0); // ❌ 错误！不能类外访问 SetResult
```

其中 `SetResult`, `num1`, `num2`, `result` 均为私有成员，只能在类内被访问，而 `Add` 为公有访问，可以在类内外被访问。

>[!TIP] 提示：类和结构体的默认权限
>当成员不再任何权限说明符的作用范围内时，它们的权限即为默认权限。
>
>1. 类的默认权限为 `private`。
>2. 结构体的默认权限为 `public`，这也是为什么我们之前可以自由访问结构体的成员的原因。
>   
>   比如上一个代码中的 `description` 就是默认权限。

### 2.3 封装类

我们曾在 [[8. 函数、return、参数、函数签名#^Encapsulation|8-1.1 **问题**：什么是封装（Encapsulation）？]] 提到过封装这个概念，封装的核心是**隐藏内部实现细节**，只**对外暴露必要的接口**。

| 封装的概念     | 实现方法             |
| --------- | ---------------- |
| 隐藏内部实现细节  | 用 `private` 说明成员 |
| 对外暴露必要的接口 | 用 `public` 说明成员  |

实际开发中，应该：

1. 使用 `private` 说明需要隐藏的成员，防止类外直接访问成员，因为外部不应该看见和操作类内的复杂的逻辑，不然会增加开发难度，且容易出现错误。
2. 使用 `public` 说明对外暴露的成员，这些成员作为对外的接口，让外部可以轻松使用类和对象。

一般建议所有的数据成员都是 `private` 权限，若需要访问或修改数据成员，则应该使用成员函数，例如：

```cpp
class Person
{
private:
	string name_ = ""; // 私有成员
	
public:
	// 用成员函数 SetName 和 GetName 访问和修改成员
	void SetName(const string& value)
	{
		name_ = value;
	}
	
	string GetName() // 不要返回引用，避免外部意外通过引用修改私有成员
	{
		return name;
	}
};
```

成员函数视情况隐藏和暴露。

关于哪些成员应该隐藏或暴露，例如：

```cpp
class Player
{
private:
	// 隐藏数据成员
	// 隐藏理由：每个数据的修改涉及复杂的逻辑
	double hp_ = 100; // 血量
	int level_ = 1;   // 等级
	double attack_ = 10; // 攻击力
	double defence_ = 0; // 防御力
	
	// 改变血量（传入变化量）
	// 隐藏理由：血量不由外部管理，且改变血量涉及死亡、上限、改变攻击力等复杂逻辑
	void SetHp(double delta)
	{
		...
	}
	
	// 死亡
	// 隐藏理由：死亡逻辑由内部触发，外部只需要知道角色是否存活即可
	void Die()
	{
		...
	}
public:
	// 承受伤害
	// 暴露理由：让外部可以攻击玩家，且只需要传入对方自己计算好的伤害
	void TakeDamage(double damage)
	{
        // 如果已经死亡，不再承受伤害
        if (hp_ == 0) return;
        // 防御力减免伤害
        double actualDamage = damage - defence_;
        if (actualDamage < 0) {
            actualDamage = 0;
        }
        // 通过 SetHp 统一处理血量变化（负值表示扣血）
        SetHp(-actualDamage);
	}
	
	// 治疗
    // 暴露理由：让外部可以给玩家回血（如喝药水、治疗术等）
    void Heal(double amount)
    {
        // 如果已经死亡，无法治疗
        if (hp_ == 0) {
            return;
        }
        
        // 通过 SetHp 统一处理血量变化（正值表示加血）
        SetHp(amount);
    }
};
```
