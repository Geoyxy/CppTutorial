# 计算机的存储、指针

## 1. 计算机的存储

### 1.1 存储器的层级结构

计算机中的存储器按**速度**和**容量**分为多个层级，越靠近 CPU 速度越快、容量越小；越远离 CPU 速度越慢、容量越大。

```
┌─────────────────────────────────────────────────────────────┐
│                     速度 ↑  容量 ↓                           │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                    CPU 寄存器                        │    │
│  │              速度：极快（~1ns）                       │    │
│  │              容量：极小（~几百字节）                   │    │
│  └─────────────────────────────────────────────────────┘    │
│                            ↓                                │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                 高速缓存（Cache）                     │    │
│  │              速度：快（~1-10ns）                      │    │
│  │              容量：小（~几 MB）                       │    │
│  └─────────────────────────────────────────────────────┘    │
│                            ↓                                │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                    内存（RAM）                       │    │
│  │              速度：较快（~100ns）                     │    │
│  │              容量：中等（4GB ~ 128GB）                │    │
│  └─────────────────────────────────────────────────────┘    │
│                            ↓                                │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                    硬盘（外存）                       │    │
│  │              速度：慢（~10ms）                        │    │
│  │              容量：大（256GB ~ 几TB）                 │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

 **核心概念**：
 
 - **寄存器**：CPU 内部的工作台，数据在这里被直接处理
 - **Cache**：CPU 和内存之间的缓冲区，暂存频繁访问的数据
 - **内存**：程序运行时的工作区，断电后数据消失
 - **硬盘**：程序的长期仓库，断电后数据保留

变量和代码通常都存放在内存中，程序在内存中运行。

### 1.2 程序运行时的数据流向

```
硬盘（存储程序文件）
    │
    │  ① 双击运行 → 程序加载到内存
    ↓
内存（程序运行时的“主战场”）
    │
    │  ② CPU 从内存读取指令和数据
    ↓
Cache（高速缓存）
    │
    │  ③ 频繁使用的数据放入 Cache
    ↓
寄存器（CPU 内部直接处理）
```

**举例**：你双击一个 `.exe` 文件：
1. 程序从**硬盘**加载到**内存**中。
2. CPU 从**内存**读取指令和数据，放入**Cache**。
3. CPU 将需要计算的数据从 Cache 加载到**寄存器**中进行运算。
4. 运算结果写回**内存**。

### 1.3 内存

#### 1.3.1 内存的抽象模型

可以把内存想象成一条**带编号的街道**，每个门牌号（地址）对应一个住户（数据）。

```
内存地址（门牌号）        存储的数据（住户）
        ┌─────────────┐
0x1000  │    10       │  ← 变量 a 存在这里
        ├─────────────┤
0x1004  │    42       │  ← 变量 b 存在这里
        ├─────────────┤
0x1008  │   3.14      │  ← 变量 c 存在这里
        ├─────────────┤
0x100C  │             │
        └─────────────┘
```

#### 1.3.2 两个关键概念

| 概念 | 说明 | 类比 |
| :--- | :--- | :--- |
| **内存地址** | 每个字节在内存中的编号（十六进制数） | 门牌号 / 快递单号 |
| **内存内容** | 地址中存储的具体数据 | 住在房子里的人 |

```cpp
int a = 42;          // a 是一个“住户”
cout << &a;          // &a 是“门牌号”（地址）（& 是获取内存地址的运算符）
```

#### 1.3.3 内存地址的格式

内存地址通常用**十六进制**表示：

```cpp
int a = 42;
cout << &a;   // 可能输出：0x7ffd8b2c1a4c
```

- `0x` 前缀表示十六进制
- 地址值的大小取决于系统：32 位系统用 4 字节表示地址，64 位系统用 8 字节。

>[!NOTE] 16进制
>十六进制（Hexadecimal）是一种逢 16 进位的计数方式，用 `0` ~ `9` 表示 0~9，用 `A` ~ `F`（不区分大小写）表示 10~15。计算机底层以二进制运行，但二进制太长不易读写，而十六进制与
>二进制之间可以**按 4 位一组直接转换**（`0xF` = `1111`），因此非常适合用来简洁地表达内存地址、颜色值、字符编码等底层数据。
>
| 十进制 | 二进制 | 十六进制 |
| :---: | :---: | :---: |
| 0 | 0000 | 0 |
| 1 | 0001 | 1 |
| 2 | 0010 | 2 |
| 3 | 0011 | 3 |
| 4 | 0100 | 4 |
| 5 | 0101 | 5 |
| 6 | 0110 | 6 |
| 7 | 0111 | 7 |
| 8 | 1000 | 8 |
| 9 | 1001 | 9 |
| 10 | 1010 | A |
| 11 | 1011 | B |
| 12 | 1100 | C |
| 13 | 1101 | D |
| 14 | 1110 | E |
| 15 | 1111 | F |
| 16 | 10000 | 10 |
>
>```cpp
int dec = 42;        // 十进制
int hex = 0x2A;      // 十六进制（加 0x 前缀）
cout << hex << endl; // 输出 42
>```

## 2. 指针 Pointer

### 2.1 指针的基本概念

在上一章中我们知道，程序是在内存中运行的，且变量通常是存放在内存中的。因此，除了通过变量名访问变量外，理论上我们也能直接**根据内存地址访问变量**，而允许我们根据内存地址访问变量的工具就叫做“**指针**”。

<p class="definition">指针（Pointer）是 C++ 中一种<mark>专门存储内存地址</mark>的变量。</p>

普通变量存储的是**数据**（如 `10`、`'A'`、`3.14`），而指针存储的是**内存地址**（如 `0x7ffd8a1b2c3d`）。

```cpp
int a = 42;        // 普通变量：存储数据 42
int* p = &a;       // 指针变量：存储变量 a 的地址
```

简单来说：**指针就是“指向”某个内存位置的变量，它告诉你“数据存在哪里”。**

### 2.2 取址运算符 &

<p class="definition"><code>&</code> 是取址运算符，用于<mark>获取变量在内存中的地址</mark>。</p>

`&` 属于单目运算符，返回操作数的内存地址，例如：

```cpp
int x = 0;
cout << "大小: " << sizeof(&x) << " Byte\n内存地址: " << &x;
```

64 位系统输出：

```text
大小: 8 Byte
内存地址: 00000051C8B2FB64
```

32 位（x86）系统输出：

```text
大小: 4 Byte
内存地址: 006FFCD4
```

我们可以观察到：

|          |   64 位系统   |  32 位系统   |
| :------- | :--------: | :-------: |
| 内存地址大小   |   8 Byte   |  4 Byte   |
| 内存地址表现形式 | 16 位 16 进制 | 8 位 16 进制 |

### 2.3 指针的声明与初始化

声明语法：

```cpp
数据类型* 指针名;
```

`数据类型` 表示指针**指向的变量类型**，`*` 表示这是一个指针变量。

例如：

```cpp
int* p;          // 指向 int 的指针
double* p;       // 指向 double 的指针
char* p;         // 指向 char 的指针
string* p;       // 指向 string 的指针
```

指针的初始化：

```cpp
int a = 10;
int* p = &a;      // 用 & 取地址，初始化指针
```

>[!TIP] 初始化指针为空指针
>如果声明指针时无适合的初始化地址，则将指针**初始化为空指针**，例如：
>```cpp
>int* p = nullptr; // 初始化为空指针
>```
>空指针详见下一小节

### 2.4 空指针

**空指针**为不指向任何**有效地址**的指针，空指针的值可以为：

1. `nullptr` （推荐）
2. `NULL`
3. `0`

例如：

```cpp
// 初始化为空指针
int* p = nullptr;   // C++11 推荐
int* p = NULL;      // C 风格（不推荐）
int* p = 0;          // 旧式写法（不推荐）
```

>[!TIP] 指针的缩写
>指针 pointer 通常被缩写为 ptr 。

### 2.5 解引用运算符 *  与 访问地址中的数据
**解引用运算符**是 `*`，属于单目运算符，操作数是指针或地址，用于**访问指针所指向的内存地址中存储的数据**，是取址运算符 `&` 的逆运算。

简单来说：**`*` 的作用就是顺着指针这个“门牌号”，找到住在里面的“住户”。**

例如：

```cpp
int a = 42;
int* p = &a;   // p 存储了 a 的地址
cout << *p;    // 对指针 p 解引用 → 返回地址中的数据 → 输出 42
```

### 2.6 指针运算

指针支持 `+` 和 `-` 运算，但**不是普通的加减法**，而是**按指向的类型大小为步长进行“步进”**。

例如：

```cpp
int a = 0;
int b = 0;
int* p1 = &a;
int* p2 = &b;

cout << "int 的大小：" << sizeof(a);
cout << "\np1 指向的地址：" << p1;
cout << "\np2 指向的地址：" << p2;

cout << "\n\np1 + 1 指向的地址：" << p1 + 1;
cout << "\np1 - 1 指向的地址：" << p1 - 1;
cout << "\np1 - p2 指向的地址：" << p1 - p2;
```

32 位系统输出：

```text
int 的大小：4
p1 指向的地址：00FCF78C
p2 指向的地址：00FCF780

p1 + 1 指向的地址：00FCF790
p1 - 1 指向的地址：00FCF788
p1 - p2 指向的地址：3
```

可以观察到：

1. `00FCF790` 比 `00FCF78C` 大 4，说明 `+1` 表示步进 4 步长。
2. `00FCF788` 比 `00FCF78C` 小 4，说明 `-1` 表示反向步进 4 步长。
3. `00FCF78C` 和 `00FCF780` 相差 12，说明 `p1 - p2` 表示两地址的间距(至于为什么是 3 看下面)。

而 `4` 和 `12` 恰好是 `sizeof(int) = 4` 的倍数，说明步进和间距是以类型大小为单位。

|运算|含义|实际地址变化|
|---|---|---|
|`p + n`|指针向后移动 n 个元素|`p + n * sizeof(T)`|
|`p - n`|指针向前移动 n 个元素|`p - n * sizeof(T)`|
|`p - q`|两个指针之间的距离（以元素个数计）|`(p - q) / sizeof(T)`|

### 2.7 数组与指针

C++ 中，数组名实际为数组首元素的地址，例如：

```cpp
int arr[5] = {10, 20, 30, 40, 50};

cout << arr << endl; // 输出 arr[0] 的地址
cout << &arr[0];      // 与上面输出相同
```

输出：

```text
0093FC24
0093FC24
```

我们之前提到过“数组的元素在内存中**连续存放**”，例如：

```cpp
int arr[3] = {0, 1, 2};
for(int i = 0; i < 3; i++)
{
	cout << &arr[i] << endl;
}
```

输出：

```text
0113F838
0113F83C
0113F840
```

可以看出每个元素的地址是上一个元素的地址 `+1`，这说明了数组元素地址的**连续性**。

于是，访问第 `i` 个元素有以下两种方式：

| 序数  | 方式                  | 示例           |
| :-: | ------------------- | ------------ |
|  1  | 用 **下标** 进行访问       | `arr[i]`     |
|  2  | 用 **解引用+指针运算** 进行访问 | `*(arr + i)` |

数组作为函数参数时，在函数内会退化为指针，例如：

```cpp
void PrintArray(int arr[], int size) {
    // arr 实际上是指针 int*，不是数组
    cout << sizeof(arr);   // 输出指针大小（64位系统是 8 字节），不是数组大小
}
```

```cpp
int arr[5]{};

// 在 main 函数中：
cout << sizeof(arr); // 输出 20（整个数组的大小 4 * 5）

// 在 PrintArray 函数中：
cout << sizeof(arr); // 输出 8（指针的大小，64 位系统）
```

因此，数组传参时通常需要**额外传递数组长度**，例如：

```cpp
void PrintArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        cout << arr[i] << " ";
    }
}

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    PrintArray(arr, 5);   // 传数组名 + 长度
    return 0;
}
```

另外，没有退化的数组名是 const pointer，不可修改其指向，例如：

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int brr[5] = {6, 7, 8, 9, 10};

arr = brr;   // ❌ 错误！数组名是常量，不能赋值
```

常量（`const`）将在后面学到，这节课只需要了解数组名不可被赋值。

本小节总结表：

| 概念          | 说明                        | 示例                     |
| ----------- | ------------------------- | ---------------------- |
| **数组名**     | 数组首元素的地址（const pointer）   | `arr`                  |
| **通过指针访问**  | `*(p + i)` 等价于 `arr[i]`   | `*(arr + 2)`           |
| **指针与下标互换** | `arr[i]` 等价于 `*(arr + i)` | 两者可以互换使用               |
| **数组退化为指针** | 传参时数组名变成指针                | `void Func(int arr[])` |
| **数组名不可赋值** | 数组名是cinst pointer         | `arr = other;` ❌       |

### 2.8 结构体与指针

我们之前提到过“结构体的成员在内存中是连续的”，例如：

```cpp
struct Person
{
	int age = 0;
	int height = 0;
	int weight = 0;
};

int main() {
	Person person = {20, 170, 60};
	cout << &person.age << endl;
	cout << &person.height << endl;
	cout << &person.weight << endl;

    return 0;
}
```

64 位系统输出：

```text
00000043882FF5A8
00000043882FF5AC
00000043882FF5B0
```

可以发现，成员地址之间相距 `sizeof(int)` ，有和数组一样的内存地址连续性。

### 2.9 指针成员访问运算符 ->

<p class="definition"><code>-></code> 是 C++ 中的指针成员访问运算符（Arrow Operator），用于<mark>通过指针访问结构体或类的成员</mark>。</p>

这节课我们只了解用 `->` 访问结构体的成员。

例如：

```cpp
struct Student {
    string name = "";
    int age = 0;
};

Student s1 = {"Alice", 18};
Student* p = &s1;

// 两种写法等价
cout << (*p).name << endl;   // 解引用后访问（写法繁琐）
cout << p->name;             // 箭头运算符访问（推荐）
```

输出：

```text
Alice
Alice
```

`->` 与 `.` 的区别：

|运算符|名称|左操作数|示例|
|---|---|---|---|
|`.`|**成员访问运算符**|结构体变量 / 引用|`s1.name`|
|`->`|**指针成员访问运算符**|指向结构体的指针|`p->name`|

`->` 存在的意义就是代替 `(*指针).成员` 的写法，让代码更简洁、更可读。

### 2.10 指针作为函数参数

我们之前在 "[[课程/8. 函数、return、参数、函数签名]]" 一节中了解到：在 C++ 中，函数参数的**默认传递方式是值传递**——形参是实参的副本，函数内修改形参不会影响实参。

例如：

```cpp
// 交换 a 和 b 的值
void Swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 10, y = 20;
    Swap(x, y);
    cout << x << " " << y;   // 输出：10 20（未交换！）
    return 0;
}
```

**问题**：`Swap` 函数交换的是 `a` 和 `b` 的副本，`x` 和 `y` 本身没有被修改。

**解决方案**：用**指针**传递实参的**地址**，让函数通过地址直接修改实参。

例如：

```cpp
// 交换 a 和 b 的值
void Swap(int* a, int* b) {
    int temp = *a;   // *a 获取 a 指向的值（即 x）
    *a = *b;         // 修改 a 指向的变量
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    Swap(&x, &y);    // 传入 x 和 y 的地址
    cout << x << " " << y;   // 输出：20 10（成功交换！）
    return 0;
}
```

### 2.11 野指针 Wild Pointer

**野指针**（Wild Pointer）是指**指向无效内存地址的指针**——它存储了一个随机的、不确定的地址，这个地址可能：

1. 指向未分配的内存
2. 指向其他变量的内存
3. 指向一个随机值

==试图访问野指针指向的数据会导致**未定义行为**！==

下节课我们会讲解野指针造成危害的原理。

### 2.12 指针注意事项·其一==（重点）==

指针是 C++ 中最强大的工具，也是最危险的武器。核心原则只有两条：

1. 永远让指针指向已知的合法地址。
2. 解引用前确保它不是空指针。

以下是具体注意场景。

#### 2.12.1 尽量初始化指针

未初始化的指针是一个**野指针**，它指向一个**随机的内存地址**，解引用它会导致==**未定义行为**==！

```cpp
int* p;     // 未初始化，指向随机地址
*p = 10;    // ❌ 危险！未定义行为，可能覆盖重要数据或崩溃
```

#### 2.12.2 解引用前检查指针是否有效

`nullptr` 是安全的“空”值，但解引用 `nullptr` 会导致==**未定义行为**==！

```cpp
int* p = nullptr;
*p = 10;          // ❌ 崩溃！不能解引用空指针
```

**正确的写法**：

```cpp
if (p != nullptr) {
    *p = 10;      // ✅ 安全
} else {
    cout << "指针为空，无法操作" << endl;
}
```
 
#### 2.12.3 避免解引用指向越界地址的指针

指针加减运算不能超出数组范围，否则该指针会成为悬空指针，对其解引用会导致==**未定义行为**==！（除了指向数组最后一个元素之后的位置可以作为结束标志，但不能解引用）

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int* p = arr + 5;   // ✅ 可以指向数组末尾之后（作为结束标志，但不能解引用）

*p = 100;           // ❌ 错误！解引用数组末尾之后的地址 → 未定义行为
```

#### 2.12.4 指针类型必须匹配

不能把 `int*` 赋值给 `double*`，也不能解引用一个类型和指针类型不匹配的地址（除非用强制类型转换）。

```cpp
int a = 10;
double* p = &a;        // ❌ 错误！类型不匹配
cout << *p;            // 如果强行编译，解引用会读取 8 字节，但 a 只有 4 字节，数据错误
```

#### 2.12.5 不要对字面量取地址

字面量是**临时值**，没有固定的内存地址，不能取地址。

```cpp
int* p = &10;    // ❌ 错误！不能对字面量取地址
int* p = &(a + 5); // ❌ 错误！表达式结果是临时值，不能取地址
```
